#Terms 

_API_ (singkatan dari _Application Programming Interface_) adalah jembatan atau perantara perangkat lunak yang memungkinkan dua aplikasi berbeda untuk saling berkomunikasi, bertukar data, dan bekerja sama secara otomatis.

## **Cara Kerja Sederhana**:

Bayangkan seorang pelayan di restoran. Anda adalah pelanggan (aplikasi di ponsel Anda), dan dapur restoran adalah sistem server yang menyimpan semua data dan masakan. Anda tidak bisa langsung masuk ke dapur untuk mengambil makanan sendiri. Anda cukup memesan lewat pelayan (_API_), pelayan membawa pesanan Anda ke dapur, lalu pelayan kembali membawakan makanan yang Anda minta ke meja Anda.

**Contoh di Kehidupan Nyata**

- **Tombol "Login dengan Google":** Aplikasi luar menggunakan API milik Google untuk memverifikasi akun Anda tanpa aplikasi tersebut mengetahui password asli Google Anda.
    
- **Cek Ongkos Kirim di Toko Online:** Situs e-commerce menggunakan API dari pihak ekspedisi (seperti JNE atau SiCepat) untuk langsung menampilkan tarif ongkir terkini secara otomatis.
    
- **Widget Cuaca di Ponsel:** Aplikasi cuaca mengambil data suhu dan prakiraan cuaca dari server Badan Meteorologi melalui jalur API.
