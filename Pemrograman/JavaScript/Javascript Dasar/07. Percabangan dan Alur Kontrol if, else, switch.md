## Pengertian Percabangan dan Alur Kontrol

Secara normal, komputer mengeksekusi instruksi program baris demi baris dari atas ke bawah secara linier (*sequential flow*). Namun, dalam aplikasi nyata, alur eksekusi sering kali harus berbelok atau mengambil keputusan berbeda berdasarkan situasi tertentu:

- Jika kata sandi cocok, buka halaman dashboard; jika salah, tampilkan pesan peringatan.
- Jika pengguna adalah akun Premium, berikan diskon 20%; jika akun Reguler, kenakan harga penuh.

Proses pengambilan keputusan ini disebut sebagai **Percabangan (*Conditional Flow Control*)**.

## 1. Percabangan `if`, `else if`, dan `else`

### a. Pernyataan `if` Sederhana
Mengeksekusi blok kode hanya jika kondisi di dalam kurung bernilai `true` (atau bernilai *truthy*):

```javascript
const totalBelanja = 150000;

if (totalBelanja >= 100000) {
  console.log("Selamat, Anda mendapatkan voucher gratis ongkir!");
}
```

### b. Percabangan Dua Arah: `if - else`
Menyediakan jalur alternatif jika kondisi `if` tidak terpenuhi:

```javascript
const umur = 16;

if (umur >= 17) {
  console.log("Anda sudah berhak membuat KTP.");
} else {
  console.log("Maaf, usia Anda belum mencukupi untuk membuat KTP.");
}
```

### c. Percabangan Multi-Kondisi: `if - else if - else`
Digunakan ketika terdapat lebih dari dua cabang kemungkinan:

```javascript
const nilaiUjian = 82;
let grade = "";

if (nilaiUjian >= 90) {
  grade = "A";
} else if (nilaiUjian >= 80) {
  grade = "B";
} else if (nilaiUjian >= 70) {
  grade = "C";
} else if (nilaiUjian >= 60) {
  grade = "D";
} else {
  grade = "E (Tidak Lulus)";
}

console.log(`Nilai Anda: ${nilaiUjian}, Predikat: ${grade}`);
```

Peramban akan mengevaluasi kondisi dari atas ke bawah. Begitu ada satu kondisi yang terpenuhi, blok tersebut langsung dieksekusi dan seluruh cabang `else if` di bawahnya dilewati seketika.

## 2. Nilai Truthy dan Falsy dalam JavaScript

Di dalam kondisi `if (...)`, JavaScript tidak hanya menerima nilai boolean murni (`true` atau `false`). Setiap nilai dari tipe data apa pun dapat dievaluasi secara otomatis sebagai benar (*truthy*) atau salah (*falsy*).

Hanya ada **6 nilai Falsy mutlak** dalam JavaScript:
1. `false` (Nilai boolean false)
2. `0`, `-0`, dan `0n` (Angka nol)
3. `""` atau `''` (String kosong tanpa karakter)
4. `null`
5. `undefined`
6. `NaN` (*Not-a-Number*)

**Semua nilai selain keenam nilai di atas adalah TRUTHY!**

```javascript
// CONTOH JEBAKAN TRUTHY:
if ("0") {
  console.log("Teks '0' adalah TRUTHY karena bukan string kosong!");
}

if ([]) {
  console.log("Array kosong [] adalah TRUTHY karena bertipe object!");
}

if ({}) {
  console.log("Object kosong {} adalah TRUTHY!");
}
```

Penerapan praktis memeriksa keberadaan data:
```javascript
let nama = "Budi";

if (nama) {
  console.log(`Halo, ${nama}!`); // Berjalan karena nama bukan string kosong
} else {
  console.log("Nama belum diisi.");
}
```

## 3. Percabangan `switch - case`

Jika Anda perlu mencocokkan satu variabel tunggal terhadap banyak nilai diskrit yang spesifik (misalnya kode hari, status pesanan, atau menu pilihan), struktur `switch - case` jauh lebih rapi dibanding menulis belasan `else if`.

Di balik layar, `switch` menggunakan perbandingan kesetaraan ketat (`===`):

```javascript
const peranPengguna = "editor";

switch (peranPengguna) {
  case "admin":
    console.log("Akses Penuh: Kelola pengguna dan sistem.");
    break;
  case "editor":
    console.log("Akses Sedang: Tulis, edit, dan terbitkan artikel.");
    break;
  case "penulis":
    console.log("Akses Terbatas: Tulis draf artikel.");
    break;
  default:
    console.log("Akses Tamu: Hanya membaca artikel.");
    break;
}
```

### Mengapa Kata Kunci `break` Sangat Penting?
Kata kunci `break` menghentikan eksekusi blok switch begitu sebuah kasus cocok. 

Jika Anda lupa menuliskan `break`, peramban akan mengalami fenomena **Fallthrough**, yaitu terus mengeksekusi baris kode pada `case` berikutnya ke bawah meskipun nilainya tidak cocok!

### Memanfaatkan Fallthrough yang Disengaja
Terkadang kita sengaja membiarkan beberapa case berjalan berurutan untuk mengelompokkan aksi yang sama:

```javascript
const hari = "Sabtu";

switch (hari) {
  case "Senin":
  case "Selasa":
  case "Rabu":
  case "Kamis":
  case "Jumat":
    console.log("Hari Kerja: Waktunya produktif berkarya.");
    break;
  case "Sabtu":
  case "Minggu":
    console.log("Akhir Pekan: Waktunya istirahat dan liburan!");
    break;
  default:
    console.log("Nama hari tidak valid.");
}
```

## 4. Rantai Operator Ternary (Ternary Chaining)

Untuk kasus penetapan variabel berdasarkan tingkatan nilai secara ringkas, kita dapat merangkai operator ternary:

```javascript
const skor = 85;

const hasil = skor >= 90 ? "Sangat Baik"
            : skor >= 75 ? "Baik"
            : skor >= 60 ? "Cukup"
            : "Kurang";

console.log(hasil); // Output: Baik
```

> [!TIP]
> Gunakan ternary bersarang hanya jika strukturnya pendek dan mudah dibaca. Jika logikanya melibatkan banyak instruksi kompleks, selalu utamakan blok `if - else` agar kode mudah dirawat di masa depan.
