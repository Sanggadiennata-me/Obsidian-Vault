## Sintaks Modern ES6: Destructuring, Spread, dan Rest

Salah satu lompatan terbesar dalam sintaksis JavaScript modern adalah diperkenalkannya fitur **Destructuring Assignment** serta simbol tiga titik (`...`) yang dapat berfungsi sebagai **Spread Operator** atau **Rest Parameter**.

Fitur-fitur ini secara drastis mengurangi baris kode repetitif (*boilerplate*) dan membuat manipulasi struktur data menjadi sangat ekspresif.

## 1. Destructuring Assignment

Destructuring adalah sintaksis khusus yang memungkinkan kita "membongkar" nilai dari array atau properti dari objek langsung ke dalam variabel-variabel terpisah.

### a. Destrukturisasi Array (Array Destructuring)
Destrukturisasi array bekerja berdasarkan **urutan posisi indeks**:

```javascript
const warna = ["Merah", "Hijau", "Biru", "Kuning"];

// Mengambil elemen ke dalam variabel terpisah
const [warnaSatu, warnaDua] = warna;
console.log(warnaSatu); // Output: Merah
console.log(warnaDua);  // Output: Hijau

// Melewati elemen tertentu menggunakan koma kosong
const [pertama, , ketiga] = warna;
console.log(ketiga); // Output: Biru

// Nilai Default (Default Value) jika data tidak tersedia
const [item1, item2, item3, item4, item5 = "Ungu"] = warna;
console.log(item5); // Output: Ungu
```

#### Trik Cerdas: Menukar Nilai Dua Variabel Tanpa Variabel Sementara
```javascript
let x = 10;
let y = 20;

// Menukar nilai secara instan dengan destrukturisasi
[x, y] = [y, x];

console.log(x); // Output: 20
console.log(y); // Output: 10
```

### b. Destrukturisasi Objek (Object Destructuring)
Destrukturisasi objek bekerja berdasarkan **kesesuaian nama properti (*keys*)**:

```javascript
const profil = {
  nama: "Siti Rahma",
  umur: 22,
  kota: "Surabaya"
};

// Mengambil properti nama dan kota
const { nama, kota } = profil;
console.log(nama); // Output: Siti Rahma
console.log(kota); // Output: Surabaya
```

#### Mengganti Nama Variabel (Renaming / Aliasing) dan Nilai Default:
```javascript
const konfigurasi = {
  port: 8080
};

// Mengubah nama variabel 'port' menjadi 'serverPort' dan menetapkan default host
const { port: serverPort, host = "localhost" } = konfigurasi;

console.log(serverPort); // Output: 8080
console.log(host);       // Output: localhost
```

#### Destrukturisasi Objek Bersarang (Nested Destructuring):
```javascript
const karyawan = {
  id: "EMP-01",
  biodata: {
    namaLengkap: "Ahmad Dahlan",
    divisi: "Engineering"
  }
};

const { biodata: { namaLengkap, divisi } } = karyawan;
console.log(namaLengkap); // Output: Ahmad Dahlan
console.log(divisi);      // Output: Engineering
```

## 2. Spread Operator (`...`)

Simbol tiga titik `...` disebut sebagai **Spread Operator** ketika digunakan untuk **mengembangkan, membongkar, atau menyebarkan (*to spread / expand*)** seluruh elemen dari sebuah array atau objek ke tempat yang baru.

### a. Menggabungkan dan Menyalin Array
```javascript
const timFrontend = ["HTML", "CSS"];
const timBackend = ["Node.js", "PostgreSQL"];

// Menggabungkan dua array secara mulus
const fullstack = [...timFrontend, "JavaScript", ...timBackend];
console.log(fullstack);
// Output: ["HTML", "CSS", "JavaScript", "Node.js", "PostgreSQL"]

// Menyalin array secara aman (Shallow Copy)
const duplikatArray = [...timFrontend];
```

### b. Mengirim Elemen Array ke Parameter Fungsi
Metode bawaan seperti `Math.max()` menerima argumen angka individual, bukan array utuh. Gunakan spread operator untuk membongkar isinya:

```javascript
const kumpulanNilai = [45, 88, 92, 67, 100];

// console.log(Math.max(kumpulanNilai)); // NaN (Gagal karena menerima array)
console.log(Math.max(...kumpulanNilai));  // Output: 100 (Berhasil!)
```

### c. Menggabungkan dan Menimpa Properti Objek
```javascript
const produkDasar = {
  id: "P01",
  nama: "Kaos Polos",
  harga: 50000
};

// Menyalin dan menimpa harga produk
const produkDiskon = {
  ...produkDasar,
  harga: 35000,
  stok: 100
};

console.log(produkDiskon);
/* Output:
{
  id: 'P01',
  nama: 'Kaos Polos',
  harga: 35000,
  stok: 100
}
*/
```

## 3. Rest Parameter (`...`)

Simbol tiga titik `...` disebut sebagai **Rest Parameter** ketika digunakan untuk **mengumpulkan atau mewadahi sisa-sisa nilai (*the rest of elements*)** menjadi satu array kesatuan.

### a. Rest Parameter pada Fungsi (Fungsi dengan Argumen Fleksibel)
Sebelumnya, jika sebuah fungsi menerima jumlah argumen yang dinamis dan tidak pasti, programmer harus menggunakan objek `arguments` yang kuno. Dengan Rest Parameter, semua sisa argumen otomatis dikemas ke dalam Array standar:

```javascript
function hitungTotal(...daftarHarga) {
  // daftarHarga adalah sebuah Array murni
  return daftarHarga.reduce((total, harga) => total + harga, 0);
}

console.log(hitungTotal(10000, 20000));             // Output: 30000
console.log(hitungTotal(5000, 15000, 25000, 50000));// Output: 95000
```

> [!CAUTION]
> Rest parameter **harus selalu diletakkan di posisi paling terakhir** pada daftar parameter fungsi. Penulisan seperti `function uji(a, ...sisa, b)` akan memicu SyntaxError!

### b. Rest pada Destrukturisasi Array dan Objek
```javascript
// Rest pada Array
const [juara1, juara2, ...pesertaLain] = ["Emas", "Perak", "Perunggu", "Peserta A", "Peserta B"];
console.log(juara1);       // "Emas"
console.log(juara2);       // "Perak"
console.log(pesertaLain);  // ["Perunggu", "Peserta A", "Peserta B"]

// Rest pada Objek
const { id, ...dataUmum } = { id: 101, nama: "Budi", email: "budi@mail.com", role: "Member" };
console.log(id);        // 101
console.log(dataUmum);  // { nama: "Budi", email: "budi@mail.com", role: "Member" }
```

## Ringkasan Perbedaan: Spread vs Rest

- **Spread Operator**: Digunakan saat Anda ingin **membongkar atau memecah** satu koleksi menjadi butir-butir terpisah.
- **Rest Parameter**: Digunakan saat Anda ingin **mengumpulkan banyak butir nilai terpisah** menjadi satu wadah array tunggal.
