## Pengertian Objek dalam JavaScript

Jika Array digunakan untuk menyimpan kumpulan data terurut berdasarkan nomor indeks, maka **Objek (*Object*)** adalah struktur data yang digunakan untuk menyimpan sekumpulan data berbasis **Pasangan Kunci dan Nilai (*Key-Value Pairs*)**.

Objek sangat ideal untuk memodelkan entitas atau benda di dunia nyata (seperti data pengguna, informasi produk, transaksi perbankan, atau konfigurasi aplikasi).

![Struktur Data Objek](img/DataObject.png)

Karakteristik penting Objek:
- **Kunci (*Key / Property Name*)**: Berupa teks string atau simbol unik yang berfungsi sebagai label pengenal.
- **Nilai (*Value*)**: Dapat berupa tipe data apa pun (number, string, boolean, array, objek bersarang, hingga fungsi).
- **Properti (*Property*)**: Pasangan antara satu kunci dan nilainya.

## 1. Membuat Objek dengan Object Literal

Cara paling umum, sederhana, dan direkomendasikan untuk membuat objek adalah menggunakan notasi kurung kurawal `{ ... }` (*Object Literal*):

```javascript
const pengguna = {
  nama: "Sangga Diennata",
  usia: 24,
  kota: "Bandung",
  isProgrammer: true,
  keahlian: ["HTML", "CSS", "JavaScript"],
  alamat: {
    jalan: "Jl. Asia Afrika No. 10",
    kodePos: "40111"
  }
};
```

Setiap properti dipisahkan oleh tanda koma. Nilai properti di atas mencakup tipe data primitif, array, dan objek lain di dalamnya (*nested object*).

## 2. Cara Mengakses Properti Objek

Terdapat dua teknik utama untuk membaca nilai properti di dalam objek:

### a. Notasi Titik (Dot Notation)
Cara yang paling bersih, standar, dan paling sering digunakan:

```javascript
console.log(pengguna.nama); // Output: Sangga Diennata
console.log(pengguna.usia); // Output: 24
console.log(pengguna.alamat.kota); // Output: Bandung
```

### b. Notasi Kurung Siku (Bracket Notation)
Mengakses properti dengan menuliskan nama properti sebagai string di dalam tanda kurung siku `obj["properti"]`.

Notasi kurung siku **WAJIB** digunakan pada situasi-situasi berikut:
1. **Nama properti memiliki spasi atau tanda hubung**:
   ```javascript
   const produk = {
     "kode-sku": "ELEC-001",
     "nama lengkap": "Monitor Gaming 24 Inch"
   };
   
   // console.log(produk.kode-sku); // ERROR: Dikira operasi pengurangan minus!
   console.log(produk["kode-sku"]);     // Output: ELEC-001
   console.log(produk["nama lengkap"]); // Output: Monitor Gaming 24 Inch
   ```
2. **Nama properti bersifat dinamis dari variabel**:
   ```javascript
   const pilihanPengguna = "kota";
   console.log(pengguna[pilihanPengguna]); // Sama dengan pengguna["kota"] -> Output: Bandung
   ```

## 3. Menambah, Mengubah, dan Menghapus Properti

Objek pada JavaScript bersifat dinamis. Anda dapat menambah, mengubah, atau menghapus properti kapan saja saat program berjalan:

```javascript
const buku = {
  judul: "Pemrograman Web Dasar",
  penulis: "Dicoding"
};

// 1. Menambahkan properti baru
buku.tahunTerbit = 2026;
buku["penerbit"] = "Nusantara Press";

// 2. Mengubah nilai properti yang sudah ada
buku.penulis = "Tim Kurikulum Dicoding";

// 3. Menghapus properti menggunakan operator delete
delete buku.penerbit;

console.log(buku);
/* Hasil:
{
  judul: 'Pemrograman Web Dasar',
  penulis: 'Tim Kurikulum Dicoding',
  tahunTerbit: 2026
}
*/
```

## 4. Method: Fungsi di dalam Objek

Ketika sebuah fungsi disimpan sebagai nilai properti di dalam suatu objek, fungsi tersebut disebut sebagai **Method**. Method merepresentasikan perilaku atau tindakan yang dapat dilakukan oleh objek tersebut.

Di dalam method, kita dapat menggunakan kata kunci `this` untuk merujuk pada objek pemilik method tersebut:

```javascript
const kalkulator = {
  nama: "Kalkulator Saku",
  tambah(a, b) {
    return a + b;
  },
  sapa() {
    console.log(`Halo, ini adalah ${this.nama}`);
  }
};

console.log(kalkulator.tambah(10, 5)); // Output: 15
kalkulator.sapa(); // Output: Halo, ini adalah Kalkulator Saku
```

## 5. Metode Utilitas Bawaan: `Object.keys`, `values`, dan `entries`

JavaScript menyediakan fungsi statis pada objek global `Object` untuk membaca isi properti dalam bentuk array:

```javascript
const mobil = {
  merek: "Toyota",
  model: "Corolla",
  tahun: 2022
};

// 1. Mengambil seluruh nama kunci properti
console.log(Object.keys(mobil));
// Output: ["merek", "model", "tahun"]

// 2. Mengambil seluruh nilai data properti
console.log(Object.values(mobil));
// Output: ["Toyota", "Corolla", 2022]

// 3. Mengambil pasangan [kunci, nilai] dalam bentuk array dua dimensi
console.log(Object.entries(mobil));
// Output: [["merek", "Toyota"], ["model", "Corolla"], ["tahun", 2022]]
```

## 6. Memeriksa Keberadaan Properti

Ada dua cara aman untuk memeriksa apakah suatu properti ada di dalam objek:

1. **Operator `in`**:
   ```javascript
   console.log("merek" in mobil); // Output: true
   console.log("warna" in mobil); // Output: false
   ```
2. **Metode Modern `Object.hasOwn()` (ES2022)**:
   ```javascript
   console.log(Object.hasOwn(mobil, "model")); // Output: true
   console.log(Object.hasOwn(mobil, "mesin")); // Output: false
   ```
