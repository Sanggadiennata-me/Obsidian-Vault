## Paradigma Fungsional dalam Pengolahan Array

Dalam JavaScript modern, pengembang profesional jarang sekali menulis perulangan `for` konvensional dengan indeks manual untuk memanipulasi data daftar. Sebagai gantinya, JavaScript menyediakan serangkaian **Metode Pengolahan Tingkat Tinggi (*Higher-Order Array Methods*)**.

Metode-metode ini menerima sebuah fungsi pemanggil (*callback function*) sebagai argumennya, memungkinkan penulisan kode yang deklaratif, ringkas, ekspresif, dan minim bug.

## 1. Menjalankan Aksi per Elemen: `forEach()`

Metode `forEach()` mengeksekusi fungsi callback untuk setiap elemen di dalam array. Metode ini **tidak mengembalikan nilai apa pun (*returns undefined*)** dan murni digunakan untuk menghasilkan efek samping (*side-effects*), seperti mencetak log atau memperbarui antarmuka pengguna:

```javascript
const daftarBahasa = ["JavaScript", "Python", "Rust", "Go"];

daftarBahasa.forEach((bahasa, indeks) => {
  console.log(`Indeks ke-${indeks}: Bahasa ${bahasa}`);
});
```

Fungsi callback menerima 3 parameter opsional: `(nilaiElemen, nomorIndeks, arrayAsli)`.

## 2. Mengubah Bentuk Data: `map()`

Metode `map()` digunakan untuk **mentransformasi setiap elemen** di dalam array menjadi bentuk baru, lalu menghasilkan **Array baru berukuran sama persis** tanpa merusak array aslinya:

```javascript
const hargaRupiah = [10000, 25000, 50000];

// Menghitung harga setelah diskon 10%
const hargaDiskon = hargaRupiah.map((harga) => harga * 0.9);

console.log(hargaDiskon); // [9000, 22500, 45000]
console.log(hargaRupiah); // [10000, 25000, 50000] (Array asli tetap utuh)
```

Contoh transformasi objek data pengguna menjadi daftar nama teks saja:
```javascript
const pengguna = [
  { id: 1, nama: "Ahmad" },
  { id: 2, nama: "Budi" }
];

const daftarNama = pengguna.map((user) => user.nama);
console.log(daftarNama); // ["Ahmad", "Budi"]
```

## 3. Menyaring Elemen: `filter()`

Metode `filter()` digunakan untuk **menyaring dan memilih elemen** yang memenuhi kriteria tertentu. Fungsi callback harus mengembalikan nilai boolean (`true` atau `false`):
- Jika `true`, elemen tersebut dimasukkan ke dalam array hasil baru.
- Jika `false`, elemen tersebut diabaikan.

```javascript
const daftarNilai = [45, 80, 92, 58, 77, 63, 88];

// Mengambil siswa dengan nilai kelulusan 75 ke atas
const siswaLulus = daftarNilai.filter((nilai) => nilai >= 75);

console.log(siswaLulus); // [80, 92, 77, 88]
```

## 4. Pencarian Item Tunggal: `find()` dan `findIndex()`

Jika Anda hanya membutuhkan **satu elemen pertama** yang cocok (bukan kumpulan array seperti `filter`), gunakan `find()`:
- `find()`: Mengembalikan nilai elemen pertama yang cocok, atau `undefined` jika tidak ada data yang cocok.
- `findIndex()`: Mengembalikan nomor indeks pertama yang cocok, atau `-1` jika tidak ada.

Begitu elemen yang dicari ditemukan, metode ini langsung berhenti (*early exit*) sehingga jauh lebih hemat performa dibanding `filter`:

```javascript
const produk = [
  { id: "P01", nama: "Mouse Wireless", harga: 150000 },
  { id: "P02", nama: "Keyboard Mechanical", harga: 650000 },
  { id: "P03", nama: "Webcam HD", harga: 350000 }
];

const barangDicari = produk.find((item) => item.id === "P02");
console.log(barangDicari); 
// Output: { id: "P02", nama: "Keyboard Mechanical", harga: 650000 }
```

## 5. Pemeriksaan Kondisi Logis: `some()` dan `every()`

- `some()`: Mengembalikan `true` jika **minimal ada satu saja** elemen yang memenuhi syarat.
- `every()`: Mengembalikan `true` hanya jika **seluruh elemen tanpa terkecuali** memenuhi syarat.

```javascript
const umurPeserta = [18, 22, 16, 25];

// Apakah ada minimal satu anak di bawah umur?
const adaAnakDiBawahUmur = umurPeserta.some((umur) => umur < 17);
console.log(adaAnakDiBawahUmur); // true

// Apakah semua peserta sudah dewasa (17 tahun ke atas)?
const semuaDewasa = umurPeserta.every((umur) => umur >= 17);
console.log(semuaDewasa); // false
```

## 6. Mengakumulasi Nilai: `reduce()`

Metode `reduce()` adalah metode array paling kuat dalam JavaScript. Metode ini mengevaluasi seluruh elemen array dari kiri ke kanan untuk **mengakumulasikannya menjadi satu nilai akhir tunggal** (dapat berupa angka total, objek agregat, atau array gabungan).

Sintaks dasar:
```javascript
array.reduce((akumulator, elemenSaatIni) => {
  return akumulator + elemenSaatIni;
}, nilaiAwal);
```

### Menghitung Total Keranjang Belanja:
```javascript
const belanjaan = [
  { barang: "Buku", harga: 45000 },
  { barang: "Pulpen", harga: 5000 },
  { barang: "Tas", harga: 120000 }
];

const totalBayar = belanjaan.reduce((total, item) => {
  return total + item.harga;
}, 0); // Nilai awal akumulator: 0

console.log(`Total tagihan kasir: Rp ${totalBayar}`); // Rp 170000
```

## 7. Pengurutan Data: `sort()` dan Jebakan Urutan Angka

Secara default, metode `sort()` mengurutkan elemen dengan mengubahnya menjadi string terlebih dahulu, lalu membandingkannya berdasarkan urutan kode karakter UTF-16:

```javascript
const angka = [10, 5, 40, 25, 100, 1];
angka.sort();
console.log(angka); // [1, 10, 100, 25, 40, 5] -> URUTAN RUSAK!
```
Angka `100` dianggap lebih kecil daripada `5` karena karakter `'1'` berada sebelum `'5'` di dalam tabel teks!

### Cara Mengurutkan Angka yang Benar:
Sertakan fungsi pembanding (*compare function*):
- Urutan Naik (*Ascending*): `(a, b) => a - b`
- Urutan Turun (*Descending*): `(a, b) => b - a`

```javascript
angka.sort((a, b) => a - b);
console.log(angka); // [1, 5, 10, 25, 40, 100] (Benar!)
```

## 8. Menggabungkan Metode Secara Rantai (Method Chaining)

Salah satu keistimewaan terbesar dari metode array non-mutasi adalah kemampuannya dirangkai secara berurutan (*method chaining*) dalam satu aliran pipa data (*data pipeline*) yang sangat bersih dan mudah dipahami:

```javascript
const katalogBuku = [
  { judul: "Belajar HTML", harga: 80000, kategori: "Web" },
  { judul: "Resep Masakan Sunda", harga: 55000, kategori: "Kuliner" },
  { judul: "Mastering CSS Grid", harga: 95000, kategori: "Web" },
  { judul: "JavaScript Lanjutan", harga: 120000, kategori: "Web" }
];

// Alur: Saring buku Web -> Berikan diskon 10% -> Hitung total harga
const totalBukuWeb = katalogBuku
  .filter((buku) => buku.kategori === "Web")
  .map((buku) => buku.harga * 0.9)
  .reduce((total, harga) => total + harga, 0);

console.log(`Total harga buku kategori Web setelah diskon: Rp ${totalBukuWeb}`);
// Total: (72000 + 85500 + 108000) = Rp 265500
```
