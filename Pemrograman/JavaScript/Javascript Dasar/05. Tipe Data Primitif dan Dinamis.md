## Karakteristik Tipe Data Dinamis (Dynamically Typed)

JavaScript adalah bahasa yang bertipe dinamis (*dynamically typed language*). Artinya, Anda tidak perlu mendeklarasikan tipe data secara eksplisit saat membuat variabel (berbeda dengan bahasa bertipe statis seperti Java, C++, atau Rust).

Di JavaScript, tipe data terikat pada **nilai (*value*)**, bukan pada wadah variabelnya. Sebuah variabel yang awalnya menampung angka dapat diubah untuk menampung teks string di baris berikutnya:

```javascript
let data = 42;          // Bertipe data Number
data = "Halo Dunia";    // Berubah menjadi bertipe data String
data = true;            // Berubah menjadi bertipe data Boolean
```

## Klasifikasi Tipe Data dalam JavaScript

Tipe data dalam JavaScript secara garis besar dibagi menjadi dua kelompok besar:
1. **Tipe Data Primitif (*Primitive Types*)**: Data sederhana bernilai tunggal yang bersifat tidak dapat diubah (*immutable*), disimpan langsung di tumpukan memori (*stack memory*), dan diteruskan melalui penyalinan nilai (*pass-by-value*).
2. **Tipe Data Referensi (*Reference Types / Objects*)**: Struktur data kompleks yang disimpan di tumpukan memori besar (*heap memory*) dan diteruskan melalui alamat referensi (*pass-by-reference*).

## 7 Tipe Data Primitif

Standar ECMAScript modern menyediakan 7 tipe data primitif:

### 1. Number
Menampung angka bilangan bulat (*integer*) maupun bilangan desimal (*floating-point*). Di balik layar, JavaScript merepresentasikan seluruh angka menggunakan format standar IEEE 754 presisi ganda 64-bit (*double precision*).

```javascript
let umur = 25;
let beratBadan = 65.5;
let saldo = 1_000_000; // Fitur numeric separator underscore agar mudah dibaca manusia
```

#### Nilai Khusus pada Tipe Number:
- `Infinity` dan `-Infinity`: Hasil pembagian angka positif/negatif dengan nol (`10 / 0`).
- `NaN` (*Not-a-Number*): Menandakan hasil operasi komputasi matematika yang tidak valid secara matematis (misalnya: membagi kata teks dengan angka `"apel" / 5`).

> [!NOTE]
> **Presisi Bilangan Desimal (Floating-Point Issue)**:
> Sesuai standar komputasi biner IEEE 754, angka desimal tertentu tidak dapat direpresentasikan secara biner dengan presisi sempurna:
> ```javascript
> console.log(0.1 + 0.2 === 0.3); // Output: false! (Hasil riilnya: 0.30000000000000004)
> ```
> Untuk menangani kalkulasi keuangan yang sangat presisi, gunakan pembulatan nilai sen atau pustaka khusus akuntansi.

### 2. BigInt
Tipe Number biasa hanya mampu merepresentasikan angka bulat secara aman hingga batas $2^{53} - 1$ (`9.007.199.254.740.991`). 

Jika Anda memerlukan angka yang jauh lebih besar dari batas tersebut (misalnya untuk kriptografi, token blockchain, atau ID transaksi database 64-bit), gunakan `BigInt` dengan menambahkan huruf `n` di akhir angka:

```javascript
const angkaRaksasa = 9007199254740995n;
const hasilKali = angkaRaksasa * 2n;
```

### 3. String
Menampung urutan karakter teks. Terdapat 3 cara menuliskan string di JavaScript:

1. **Petik Tunggal (`'...'`)**: `'Belajar JavaScript'`
2. **Petik Ganda (`"..."`)**: `"Belajar JavaScript"`
3. **Template Literals (Backtick `` `...` ``)**: Fitur modern ES6 yang mendukung penulisan teks multi-baris serta penyisipan ekspresi variabel secara elegan (*string interpolation*):
   ```javascript
   const produk = "Kopi Robusta";
   const harga = 25000;
   
   // Menggunakan Template Literals
   const pesan = `Detail Pesanan:
   - Barang: ${produk}
   - Total Tagihan: Rp ${harga * 2}`;
   
   console.log(pesan);
   ```

### 4. Boolean
Hanya memiliki dua kemungkinan nilai logis: `true` (benar) atau `false` (salah). Tipe data ini menjadi tulang punggung dalam pengujian kondisi percabangan dan perulangan.

```javascript
let isAktif = true;
let hasDiskon = false;
```

### 5. Null
Tipe data khusus yang memiliki satu nilai tunggal: `null`. Nilai ini digunakan oleh programmer secara sengaja untuk menandai bahwa suatu variabel saat ini **kosong atau belum memiliki nilai objek apa pun** (*intentional absence of value*).

```javascript
let dataPengguna = null; // Menandakan bahwa data pengguna sengaja dikosongkan terlebih dahulu
```

### 6. Undefined
Menandakan bahwa sebuah variabel telah dideklarasikan, tetapi **belum pernah diinisialisasi atau diisi nilai apa pun**:

```javascript
let nama;
console.log(nama); // Output: undefined
```

#### Perbedaan Hakiki: Null vs Undefined
- `undefined` berarti variabel belum pernah diberi nilai (bawaan sistem default).
- `null` berarti variabel sengaja dikosongkan nilainya oleh sang programmer.

### 7. Symbol
Diperkenalkan pada ES6, `Symbol` digunakan untuk menghasilkan pengidentifikasi yang dijamin **unik 100% dan tidak akan pernah bertabrakan**, meskipun memiliki deskripsi nama yang sama. Sering digunakan sebagai kunci properti tersembunyi pada objek:

```javascript
const id1 = Symbol("id");
const id2 = Symbol("id");
console.log(id1 === id2); // Output: false! (Masing-masing unik seumur hidup)
```

## Memeriksa Tipe Data: Operator `typeof`

Untuk memeriksa tipe data dari suatu variabel atau ekspresi secara dinamis, gunakan operator `typeof`:

```javascript
console.log(typeof 42);             // "number"
console.log(typeof "Halo");         // "string"
console.log(typeof true);           // "boolean"
console.log(typeof undefined);      // "undefined"
console.log(typeof 100n);           // "bigint"
console.log(typeof Symbol("token"));// "symbol"
console.log(typeof { nama: "Budi" });// "object"
console.log(typeof [1, 2, 3]);      // "object" (Array adalah turunan dari Object)
console.log(typeof function(){});   // "function"
```

> [!CAUTION]
> **Bug Historis JavaScript: `typeof null`**
> Jika Anda menjalankan:
> ```javascript
> console.log(typeof null); // Output: "object"
> ```
> Ini adalah **kesalahan desain bersejarah (bug)** dari versi pertama JavaScript pada tahun 1995. Di mesin aslinya, nilai pointer null ditandai dengan bit 000 yang kebetulan sama dengan penanda tipe objek. Kesalahan ini sengaja tidak diperbaiki hingga hari ini karena jika diubah akan merusak miliaran baris kode website lawas di seluruh dunia (*backward compatibility*).
