## Apa itu JavaScript?

JavaScript adalah bahasa pemrograman tingkat tinggi (*high-level*), dinamis, dan multi-paradigma yang menjadi fondasi utama perilaku interaktif di World Wide Web. Bersama dengan HTML dan CSS, JavaScript membentuk trio teknologi inti pengembangan web modern:

1. **HTML**: Membangun struktur dan kerangka konten halaman.
2. **CSS**: Memberikan tata letak, warna, tipografi, dan keindahan visual.
3. **JavaScript**: Mengatur logika, merespons aksi pengguna, melakukan kalkulasi, memanipulasi tampilan secara dinamis, dan berkomunikasi dengan server.

Ketika Anda melihat tombol yang memunculkan jendela pop-up, formulir yang memvalidasi kesalahan ketik tanpa me-refresh halaman, umpan Instagram yang bergulir tiada henti (*infinite scroll*), atau aplikasi peta Google Maps yang dapat digeser secara mulus, semua pengalaman interaktif tersebut digerakkan oleh JavaScript.

## Sejarah Singkat dan Standarisasi ECMAScript

JavaScript diciptakan pada Mei 1995 oleh **Brendan Eich** saat bekerja di Netscape Communications. Awalnya bahasa ini dikembangkan hanya dalam waktu 10 hari dengan nama sandi **Mocha**, kemudian diubah menjadi **LiveScript**, dan akhirnya resmi dinamai **JavaScript**.

Penamaan "JavaScript" pada saat itu merupakan strategi pemasaran bersama Sun Microsystems untuk mendompleng popularitas bahasa Java yang sedang naik daun. Secara teknis, **JavaScript tidak memiliki keterkaitan arsitektur langsung dengan bahasa Java**. Pepatah terkenal di kalangan programmer mengatakan: *"Java dan JavaScript memiliki hubungan yang sama seperti Mobil (Car) dan Karpet (Carpet)"*.

### ECMAScript (ES)
Untuk mencegah fragmentasi antar-browser, Netscape menyerahkan spesifikasi JavaScript kepada badan standardisasi internasional **ECMA International**. Standar resmi bahasa ini dinamai **ECMAScript (ES)**.

Tonggak sejarah terbesar JavaScript modern terjadi pada tahun 2015 dengan dirilisnya **ECMAScript 2015 (ES6)**. Pembaruan ini merombak drastis kemampuan JavaScript dengan memperkenalkan fitur-fitur modern seperti sintaks `let` dan `const`, *Arrow Functions*, *Classes*, *Template Literals*, *Destructuring*, dan *Modules (ESM)*. Sejak saat itu, komite TC39 merilis pembaruan spesifikasi baru setiap tahun (ES2016, ES2020, hingga standar terbaru saat ini).

## Mengapa JavaScript Menjadi Bahasa Terpopuler di Dunia?

1. **Bahasa Bawaan Seluruh Peramban Web**: JavaScript adalah satu-satunya bahasa pemrograman yang didukung secara natif oleh seluruh browser di dunia (Chrome, Firefox, Safari, Edge) tanpa memerlukan plugin tambahan.
2. **Satu Bahasa untuk Semua Ekosistem (Full-Stack)**:
   - **Frontend Web**: React, Vue, Svelte, Angular.
   - **Backend Server**: Node.js, Express, Fastify, NestJS, Deno, Bun.
   - **Aplikasi Ponsel (Mobile)**: React Native, Ionic.
   - **Aplikasi Desktop**: Electron (VS Code, Slack, Discord dibuat dengan JavaScript/TypeScript), Tauri.
   - **Kecerdasan Buatan & IoT**: TensorFlow.js, Johnny-Five.
3. **Komunitas Terbesar dan Ekosistem Paket Terlengkap**: Melalui npm (*Node Package Manager*), JavaScript memiliki repositori pustaka sumber terbuka terbesar di dunia dengan lebih dari 2 juta paket siap pakai.

## Bagaimana Kode JavaScript Dijalankan? (Engine V8)

Komputer dan prosesor perangkat keras hanya memahami instruksi biner berupa angka `0` dan `1` (*Machine Code*). Agar kode JavaScript yang ditulis manusia dapat dipahami komputer, peramban memiliki komponen khusus bernama **JavaScript Engine**.

Engine JavaScript paling terkenal adalah **V8 Engine** yang dikembangkan oleh Google untuk peramban Google Chrome dan lingkungan server Node.js. Engine lainnya meliputi:
- **SpiderMonkey**: Digunakan oleh Mozilla Firefox.
- **JavaScriptCore (Nitro)**: Digunakan oleh Apple Safari.

### Cara Kerja Engine V8 (Just-In-Time Compilation)
Dahulu, JavaScript dianggap lambat karena dieksekusi baris demi baris menggunakan *interpreter* murni. Engine V8 modern mengubah hal tersebut dengan menggabungkan kecepatan peluncuran interpreter dan efisiensi performa compiler:

1. **Parser**: Membaca kode JavaScript mentah dan mengubahnya menjadi struktur data pohon bernama **AST (*Abstract Syntax Tree*)**.
2. **Ignition (Interpreter)**: Menghasilkan kode biner perantara (*bytecode*) dari AST agar program dapat langsung dijalankan seketika tanpa jeda waktu kompilasi awal.
3. **Profiler & TurboFan (JIT Compiler)**: Sambil program berjalan, profiler memantau bagian kode yang sering dieksekusi berulang kali (*hot functions*). Bagian kode tersebut langsung dikompilasi oleh modul TurboFan menjadi kode mesin biner murni yang sangat teroptimasi (*optimized machine code*).

Berkat arsitektur JIT (*Just-In-Time*) ini, JavaScript mampu beroperasi dengan kecepatan tinggi yang mendekati performa bahasa kompilasi tradisional.
