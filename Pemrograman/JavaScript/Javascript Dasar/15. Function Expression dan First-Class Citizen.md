## Fungsi Sebagai Warga Kelas Satu (First-Class Citizens)

Salah satu keunggulan terbesar bahasa JavaScript adalah memperlakukan fungsi sebagai **Warga Kelas Satu (*First-Class Citizens*)**.

Artinya, sebuah fungsi di JavaScript diperlakukan sama persis seperti nilai data biasa (seperti angka, teks, atau objek):
1. Fungsi dapat disimpan ke dalam variabel.
2. Fungsi dapat dikirimkan sebagai argumen ke dalam fungsi lain (*Callback Function*).
3. Fungsi dapat dihasilkan atau dikembalikan dari dalam fungsi lain (*Higher-Order Functions*).
4. Fungsi dapat disimpan sebagai elemen array atau properti objek (*Methods*).

Konsep ini menjadi fondasi bagi paradigma pemrograman fungsional (*functional programming*) yang mendominasi arsitektur web modern saat ini.

## 1. Ekspresi Fungsi (Function Expression)

Jika pada materi sebelumnya kita membuat fungsi dengan sintaks deklarasi, kita juga dapat membuat fungsi menggunakan **Function Expression**, yaitu mendefinisikan sebuah fungsi anonim (tanpa nama) lalu menyimpannya langsung ke dalam sebuah variabel:

![Function Expression](img/Fexspression.png)

```javascript
// Mendefinisikan Function Expression
const konversiSuhu = function(celsius) {
  return (9 / 5) * celsius + 32;
};

// Memanggil fungsi melalui nama variabelnya
const hasilFahrenheit = konversiSuhu(30);
console.log(`30 Celsius = ${hasilFahrenheit} Fahrenheit`);
// Output: 30 Celsius = 86 Fahrenheit
```

### Perbedaan Krusial Hoisting: Declaration vs Expression

Pahami perbedaan perilaku hoisting berikut agar Anda tidak terjebak error:

- **Function Declaration**: Mengalami hoisting penuh, sehingga dapat dipanggil sebelum baris pembuatannya.
- **Function Expression**: Mengikuti aturan variabel (`const` atau `let`). Fungsi **TIDAK BISA dipanggil sebelum baris pembuatannya** karena variabel penampungnya masih berada dalam *Temporal Dead Zone (TDZ)*:

```javascript
// Panggilan Function Expression sebelum baris definisinya:
// salam(); // ERROR: ReferenceError: Cannot access 'salam' before initialization

const salam = function() {
  console.log("Halo!");
};

salam(); // Berhasil dipanggil setelah baris definisinya
```

Banyak tim pengembang profesional lebih menyukai *Function Expression* justru karena sifatnya yang tidak mengizinkan pemanggilan sebelum deklarasi, sehingga alur baca kode menjadi lebih tertib dan terstruktur dari atas ke bawah.

## 2. Fungsi Tingkat Tinggi (Higher-Order Functions)

**Higher-Order Function (HOF)** adalah fungsi yang menerima fungsi lain sebagai argumen masukan, atau mengembalikan fungsi baru sebagai hasil kembaliannya.

Fungsi yang diteruskan sebagai argumen tersebut dinamai **Callback Function**.

Contoh membuat kalkulator operasi matematika fleksibel menggunakan HOF:

```javascript
// Fungsi pembantu operasi matematika
const operasiTambah = function(a, b) {
  return a + b;
};

const operasiKali = function(a, b) {
  return a * b;
};

// Higher-Order Function: Menerima fungsi operasi sebagai parameter ketiga
function eksekusiKalkulasi(angka1, angka2, fungsiOperasi) {
  console.log("Memulai proses kalkulasi...");
  const hasil = fungsiOperasi(angka1, angka2);
  return hasil;
}

// Mengirimkan operasiTambah sebagai argumen
const hasil1 = eksekusiKalkulasi(10, 5, operasiTambah);
console.log(`Hasil Penjumlahan: ${hasil1}`); // Output: 15

// Mengirimkan operasiKali sebagai argumen
const hasil2 = eksekusiKalkulasi(10, 5, operasiKali);
console.log(`Hasil Perkalian: ${hasil2}`);   // Output: 50
```

Contoh HOF bawaan JavaScript yang sudah sering kita gunakan adalah metode array seperti `.map()`, `.filter()`, dan `.forEach()`.

## 3. Fungsi yang Menghasilkan Fungsi Baru (Function Factory / Closure)

Karena fungsi adalah nilai, sebuah fungsi dapat mengembalikan fungsi lain:

```javascript
function buatPengali(faktorPengali) {
  // Mengembalikan fungsi baru yang mengingat nilai faktorPengali
  return function(angka) {
    return angka * faktorPengali;
  };
}

const kaliDua = buatPengali(2);
const kaliSepuluh = buatPengali(10);

console.log(kaliDua(5));      // Output: 10
console.log(kaliSepuluh(5));  // Output: 50
```

Kemampuan fungsi anak mengingat variabel induknya di atas dikenal sebagai konsep **Closure**.

## 4. Immediately Invoked Function Expression (IIFE)

**IIFE** (dilafalkan *"iffy"*) adalah fungsi yang langsung dieksekusi seketika tepat pada saat fungsi tersebut selesai didefinisikan:

```javascript
(function() {
  const kunciRahasia = "API_KEY_12345";
  console.log("IIFE dijalankan seketika! Kunci aman terisolasi.");
})();

// console.log(kunciRahasia); // ERROR: ReferenceError (Aman, variabel tidak bocor ke scope global)
```

Sintaks IIFE dibungkus oleh sepasang kurung luar `(function() { ... })` untuk mengubahnya menjadi ekspresi, lalu diakhiri dengan kurung panggil `()`. Di masa sebelum adanya ES6 Modules, IIFE sangat populer digunakan untuk mengisolasi variabel agar tidak mengotori cakupan global (*global namespace*).
