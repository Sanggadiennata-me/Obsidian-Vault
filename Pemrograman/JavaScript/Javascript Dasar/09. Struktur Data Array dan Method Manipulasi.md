## Apa itu Array dalam JavaScript?

Array adalah struktur data terurut (*ordered collection*) yang digunakan untuk menyimpan sekumpulan nilai elemen di dalam satu wadah variabel tunggal.

Berbeda dengan array pada bahasa bertipe statis (seperti C atau Java) yang memiliki ukuran kaku dan hanya boleh menyimpan satu tipe data seragam, Array pada JavaScript bersifat **sangat dinamis dan heterogen**:
- Ukurannya dapat bertambah atau menyusut secara otomatis saat program berjalan.
- Mampu menyimpan campuran berbagai macam tipe data sekaligus (angka, teks, boolean, objek, hingga array bersarang).

```javascript
// Array dengan tipe data heterogen
const koleksiData = [42, "Dicoding", true, { role: "Admin" }, [1, 2]];
```

Secara teknis di JavaScript, Array adalah varian khusus dari objek:
```javascript
console.log(typeof [1, 2, 3]); // Output: "object"
console.log(Array.isArray([1, 2, 3])); // Output: true (Cara akurat memeriksa array)
```

## 1. Membuat dan Mengakses Elemen Array

Cara paling umum dan direkomendasikan untuk membuat array adalah menggunakan **Array Literal** dengan sepasang tanda kurung siku `[...]`:

```javascript
const daftarSiswa = ["Ahmad", "Budi", "Citra", "Dewi"];
```

### Sistem Pengindeksan Berbasis Nol (0-Based Indexing)
Setiap elemen di dalam array memiliki nomor posisi yang disebut **Indeks**, yang selalu dimulai dari angka `0`:
- Indeks `0`: Elemen pertama (`"Ahmad"`)
- Indeks `1`: Elemen kedua (`"Budi"`)
- Indeks `2`: Elemen ketiga (`"Citra"`)

```javascript
console.log(daftarSiswa[0]); // Output: Ahmad
console.log(daftarSiswa[2]); // Output: Citra

// Jika mengakses indeks di luar batas, menghasilkan undefined (tanpa crash)
console.log(daftarSiswa[10]); // Output: undefined
```

### Properti `.length` dan Metode Modern `.at()`
Properti `.length` mengembalikan total jumlah elemen yang ada di dalam array:

```javascript
console.log(daftarSiswa.length); // Output: 4

// Mengakses elemen terakhir cara tradisional
console.log(daftarSiswa[daftarSiswa.length - 1]); // Output: Dewi

// Mengakses elemen terakhir cara modern (ES2022) dengan method .at()
console.log(daftarSiswa.at(-1)); // Output: Dewi
console.log(daftarSiswa.at(-2)); // Output: Citra (Dua dari belakang)
```

## 2. Metode Manipulasi yang Mengubah Array Asli (Mutating Methods)

Metode-metode berikut secara langsung memodifikasi isi dari array yang bersangkutan:

### a. Menambah dan Menghapus di Bagian Akhir: `push()` dan `pop()`
- `push(...items)`: Menambahkan satu atau lebih elemen baru ke posisi paling ujung belakang array.
- `pop()`: Menghapus satu elemen paling ujung belakang dan mengembalikan elemen yang dihapus tersebut.

```javascript
const antrean = ["A", "B"];

antrean.push("C", "D");
console.log(antrean); // ["A", "B", "C", "D"]

const elemenDihapus = antrean.pop();
console.log(elemenDihapus); // "D"
console.log(antrean); // ["A", "B", "C"]
```

### b. Menambah dan Menghapus di Bagian Awal: `unshift()` dan `shift()`
- `unshift(...items)`: Menyisipkan elemen baru ke posisi paling depan (menggeser seluruh indeks ke kanan).
- `shift()`: Menghapus elemen pertama di posisi paling depan.

```javascript
const angka = [20, 30];

angka.unshift(10);
console.log(angka); // [10, 20, 30]

angka.shift();
console.log(angka); // [20, 30]
```

### c. Mengubah Elemen di Tengah: `splice()`
Metode serbaguna `splice(indeksAwal, jumlahHapus, ...elemenSisipan)` dapat menghapus, menyisipkan, atau mengganti elemen pada posisi mana pun di dalam array:

```javascript
const bulan = ["Januari", "Maret", "April"];

// Menyisipkan "Februari" di indeks ke-1 tanpa menghapus elemen lain (deleteCount: 0)
bulan.splice(1, 0, "Februari");
console.log(bulan); // ["Januari", "Februari", "Maret", "April"]

// Menghapus 1 elemen di indeks ke-2 ("Maret")
bulan.splice(2, 1);
console.log(bulan); // ["Januari", "Februari", "April"]
```

## 3. Metode yang Tidak Mengubah Array Asli (Non-Mutating Methods)

Metode-metode berikut menghasilkan data baru tanpa merusak array asli:

### a. Mengambil Potongan: `slice(start, end)`
Menyalin sebagian elemen array dari indeks `start` hingga sebelum indeks `end` (tidak inklusif):

```javascript
const angkaAsli = [10, 20, 30, 40, 50];
const subArray = angkaAsli.slice(1, 4); // Mengambil indeks 1, 2, dan 3

console.log(subArray);  // [20, 30, 40]
console.log(angkaAsli); // [10, 20, 30, 40, 50] (Tetap utuh)
```

### b. Menggabungkan Array: `concat()`
Menggabungkan dua array atau lebih menjadi satu array baru:

```javascript
const timA = ["Budi", "Siti"];
const timB = ["Andi", "Dewi"];
const semuaTim = timA.concat(timB);

console.log(semuaTim); // ["Budi", "Siti", "Andi", "Dewi"]
```

### c. Pencarian Elemen: `includes()`, `indexOf()`
- `includes(item)`: Mengembalikan nilai `true` jika elemen ada di dalam array, atau `false` jika tidak ada.
- `indexOf(item)`: Mengembalikan nomor indeks pertama tempat elemen ditemukan, atau `-1` jika data tidak ditemukan.

```javascript
const buah = ["Apel", "Jeruk", "Pisang"];

console.log(buah.includes("Jeruk"));  // true
console.log(buah.includes("Durian")); // false
console.log(buah.indexOf("Pisang"));  // 2
console.log(buah.indexOf("Alpukat")); // -1
```

### d. Mengubah Array Menjadi Kalimat Teks: `join(separator)`
Menggabungkan seluruh elemen array menjadi satu string tunggal dengan pemisah khusus:

```javascript
const kata = ["Belajar", "JavaScript", "Itu", "Seru"];
const kalimat = kata.join(" ");

console.log(kalimat); // "Belajar JavaScript Itu Seru"
```

## 4. Array Multidimensi (Matriks)

Array juga dapat menampung array lain sebagai elemennya. Struktur ini sering disebut sebagai **Array Multidimensi** atau **Matriks Dua Dimensi** (misalnya untuk sistem koordinat grid papan catur atau peta permainan):

```javascript
const papanCatur = [
  ["Benteng", "Kuda", "Gajah"],
  ["Pion",    "Pion", "Pion"],
  ["Kosong",  "Raja", "Kosong"]
];

// Mengakses baris ke-0, kolom ke-1 (Kuda)
console.log(papanCatur[0][1]); // Output: Kuda

// Mengakses baris ke-2, kolom ke-1 (Raja)
console.log(papanCatur[2][1]); // Output: Raja
```
