## Revolusi Sintaksis: Arrow Function (ES6)

Diperkenalkan pada ECMAScript 2015 (ES6), **Arrow Function** adalah cara penulisan fungsi yang lebih ringkas dan modern menggunakan notasi panah gemuk (*fat arrow*) `=>`.

Arrow Function dengan cepat menjadi salah satu fitur paling digemari dan paling sering digunakan di seluruh ekosistem JavaScript (khususnya dalam pustaka modern seperti React, Vue, dan Node.js).

![Arrow Function](img/ArrowFunction.png)

Mari kita bandingkan perubahannya:

```javascript
// 1. Regular Function Expression
const kaliRegular = function(a, b) {
  return a * b;
};

// 2. Arrow Function
const kaliArrow = (a, b) => {
  return a * b;
};
```

## 1. Aturan dan Variasi Penyingkatan Sintaksis

Keunggulan terbesar Arrow Function adalah fleksibilitasnya dalam memangkas baris kode repetitif (*boilerplate*):

### a. Pengembalian Implisit (Implicit Return)
Jika tubuh fungsi hanya terdiri dari **satu baris ekspresi tunggal**, Anda dapat **menghilangkan tanda kurung kurawal `{}` dan kata kunci `return`**. Nilai dari ekspresi tersebut secara otomatis akan dikembalikan:

```javascript
// Sangat ringkas dalam satu baris
const tambah = (a, b) => a + b;

console.log(tambah(10, 25)); // Output: 35
```

### b. Parameter Tunggal Tanpa Tanda Kurung
Jika fungsi hanya menerima **satu parameter saja**, tanda kurung pembungkus parameter boleh dihilangkan:

```javascript
// Tanda kurung pada 'nama' boleh dihilangkan
const salam = nama => `Halo, ${nama}!`;

console.log(salam("Budi")); // Output: Halo, Budi!
```

> [!NOTE]
> Jika fungsi **tidak memiliki parameter sama sekali**, atau memiliki **dua parameter atau lebih**, sepasang tanda kurung `()` **wajib** disertakan:
> ```javascript
> const acak = () => Math.random();
> const luas = (p, l) => p * l;
> ```

### c. Mengembalikan Objek Secara Implisit (Jebakan Kurung Kurawal)
Jika Anda ingin mengembalikan sebuah Objek literal secara implisit menggunakan baris tunggal, Anda **harus membungkus objek tersebut di dalam tanda kurung biasa `(...)`**:

```javascript
// SALAH: Interpreter mengira kurung kurawal adalah blok tubuh fungsi, menghasilkan undefined!
// const buatUser = (nama, usia) => { nama: nama, usia: usia }; 

// BENAR: Bungkus objek dengan tanda kurung (...)
const buatUser = (nama, usia) => ({ nama: nama, usia: usia });

console.log(buatUser("Siti", 21)); 
// Output: { nama: 'Siti', usia: 21 }
```

## 2. Perbedaan Mendasar: Arrow Function vs Regular Function

Meskipun terlihat hanya sebagai pemanis sintaksis (*syntactic sugar*), Arrow Function memiliki perbedaan arsitektural yang sangat fundamental dibanding fungsi reguler:

### a. Pengikatan Leksikal Kata Kunci `this` (Lexical this)
Pada Regular Function, nilai dari kata kunci `this` bersifat dinamis dan bergantung pada **bagaimana fungsi tersebut dipanggil saat runtime**. Hal ini sering memicu bug di mana `this` tiba-tiba berubah menjadi `window` atau `undefined` di dalam callback timer:

```javascript
// MASALAH PADA REGULAR FUNCTION:
const penghitung = {
  angka: 0,
  mulaiHitung() {
    setTimeout(function() {
      // Di sini 'this' bukan lagi menunjuk ke objek 'penghitung', melainkan ke objek global/window!
      this.angka++;
      console.log("Nilai reguler:", this.angka); // Output: NaN!
    }, 1000);
  }
};
penghitung.mulaiHitung();
```

**Arrow Function memecahkan masalah ini secara elegan!**
Arrow Function **TIDAK MEMILIKI objek `this` sendiri**. Arrow function secara otomatis mewarisi (*lexically bind*) nilai `this` dari cakupan lingkup di luarnya:

```javascript
// SOLUSI DENGAN ARROW FUNCTION:
const penghitungModern = {
  angka: 0,
  mulaiHitung() {
    setTimeout(() => {
      // 'this' secara alami menunjuk ke objek 'penghitungModern'
      this.angka++;
      console.log("Nilai modern:", this.angka); // Output: 1 (Berhasil!)
    }, 1000);
  }
};
penghitungModern.mulaiHitung();
```

### b. Tidak Memiliki Objek `arguments`
Regular function memiliki objek khusus bernama `arguments` yang menampung seluruh argumen. Arrow Function tidak memilikinya. Sebagai gantinya, gunakan fitur modern **Rest Parameter (`...args`)**:

```javascript
const cetakSemua = (...daftar) => {
  console.log(daftar);
};
cetakSemua(1, 2, 3); // Output: [1, 2, 3]
```

### c. Tidak Dapat Dijadikan Konstruktor Objek (`new`)
Arrow Function tidak memiliki metode internal `[[Construct]]`. Jika Anda mencoba membuat objek baru menggunakan operator `new` pada Arrow Function, peramban akan memunculkan error:

```javascript
const Mahasiswa = (nama) => {
  this.nama = nama;
};

// const mhs1 = new Mahasiswa("Andi"); 
// ERROR: TypeError: Mahasiswa is not a constructor
```

## Kapan Harus Memakai dan Menghindari Arrow Function?

### Sangat Dianjurkan Digunakan Untuk:
1. Fungsi callback pada metode array (seperti `.map()`, `.filter()`, `.reduce()`).
2. Fungsi callback di dalam timer atau operasi asinkron (`setTimeout`, `setInterval`, `Promise`).
3. Fungsi kalkulasi utilitas murni (*pure functions*).

### Hindari Penggunaan Untuk:
1. **Method Objek yang Butuh Mengakses Properti Objek**:
   ```javascript
   const profil = {
     nama: "Budi",
     // BURUK: 'this.nama' akan bernilai undefined karena this menunjuk ke scope global!
     sapa: () => `Halo ${this.nama}` 
   };
   ```
2. **Event Listener DOM yang Butuh Elemen Pemicu**:
   Jika Anda membutuhkan `this` yang merujuk pada elemen tombol HTML yang sedang diklik pengguna, gunakan regular function:
   ```javascript
   tombol.addEventListener('click', function() {
     this.classList.toggle('aktif'); // 'this' merujuk ke elemen tombol
   });
   ```
