## Konversi Eksplisit vs Koersi Implisit

Sebagai bahasa yang bertipe dinamis, JavaScript sangat fleksibel dalam mengolah berbagai tipe data. Namun, fleksibilitas ini dapat menjadi pedang bermata dua jika Anda tidak memahami cara kerja pengubahan tipe data.

Terdapat dua mekanisme pengubahan tipe data di JavaScript:
1. **Konversi Eksplisit (*Type Casting / Explicit Conversion*)**: Pengubahan tipe data yang dilakukan secara sadar oleh programmer menggunakan fungsi utilitas standar.
2. **Koersi Implisit (*Type Coercion / Implicit Conversion*)**: Pengubahan tipe data yang dilakukan secara otomatis oleh mesin JavaScript di balik layar saat mengeksekusi operasi antara dua tipe yang berbeda.

## 1. Konversi Eksplisit (Type Casting)

Konversi eksplisit adalah praktik terbaik yang selalu dianjurkan karena membuat maksud kode menjadi jelas dan dapat diprediksi.

### a. Mengonversi ke String
Ada dua cara umum mengubah data menjadi teks:
1. Fungsi `String(nilai)`
2. Metode `.toString()`

```javascript
const angka = 123;
const status = true;

const strAngka = String(angka);      // "123" (tipe string)
const strStatus = status.toString(); // "true" (tipe string)

console.log(typeof strAngka);  // "string"
console.log(typeof strStatus); // "string"
```

> [!WARNING]
> Metode `.toString()` akan memicu error jika dipanggil pada nilai `null` atau `undefined` (`null.toString()` &rarr; TypeError). Sebaliknya, fungsi `String(null)` aman dan menghasilkan `"null"`.

### b. Mengonversi ke Number
Terdapat 4 cara utama mengubah teks menjadi angka:

```javascript
// 1. Fungsi Number() - Konversi murni
console.log(Number("42"));       // 42
console.log(Number("3.14"));     // 3.14
console.log(Number(""));         // 0 (String kosong menjadi 0)
console.log(Number("42px"));     // NaN (Gagal karena ada huruf 'px')

// 2. parseInt(string, radix) - Membaca bilangan bulat
// Mengabaikan karakter bukan angka di bagian belakang
console.log(parseInt("42px", 10)); // 42 (Berhasil mengekstrak angka!)
console.log(parseInt("10.85", 10)); // 10 (Memotong desimal)

// 3. parseFloat(string) - Membaca bilangan desimal
console.log(parseFloat("3.14meter")); // 3.14

// 4. Operator Unary Plus (+) - Cara jalan pintas populer
const inputUser = "5000";
const nilaiNominal = +inputUser; // 5000 (Number)
```

> [!TIP]
> **Selalu Sertakan Parameter Radix pada `parseInt`**:
> Selalu tuliskan basis angka `10` pada parameter kedua: `parseInt(teks, 10)` untuk memastikan peramban selalu menginterpretasikannya dalam sistem desimal, bukan sistem oktal atau heksadesimal.

### c. Mengonversi ke Boolean
Gunakan fungsi `Boolean(nilai)` atau operator ganda tanda seru `!!nilai`:

```javascript
console.log(Boolean("Halo")); // true (String tidak kosong = truthy)
console.log(Boolean(100));    // true (Bukan angka nol = truthy)
console.log(Boolean([]));     // true (Array = truthy)

console.log(Boolean(""));     // false (String kosong = falsy)
console.log(Boolean(0));      // false (Angka nol = falsy)
console.log(Boolean(null));   // false (Null = falsy)

// Jalan pintas operator ganda bang (!!)
console.log(!!"Sangga");      // true
console.log(!!0);             // false
```

## 2. Koersi Implisit (Type Coercion)

Di balik layar, mesin JavaScript mencoba "membantu" programmer agar kode tidak crash saat mengoperasikan tipe yang berbeda. Namun jika tidak berhati-hati, hal ini dapat menghasilkan perilaku yang sangat aneh:

### a. Operator `+` Mengutamakan Penggabungan String
Jika salah satu operan pada operator `+` adalah sebuah **String**, maka operan lainnya akan dipaksa dikonversi menjadi string:

```javascript
console.log("5" + 3);       // Output: "53" (Bukan 8!)
console.log(10 + "20");     // Output: "1020"
console.log("Total: " + true); // Output: "Total: true"
```

### b. Operator Matematika Lain (`-`, `*`, `/`, `%`) Mengutamakan Number
Berbeda dengan `+`, operator pengurangan, perkalian, dan pembagian akan memaksa string teks dikonversi menjadi **Number**:

```javascript
console.log("10" - 5);      // Output: 5 (String "10" dikonversi jadi 10)
console.log("6" * "4");     // Output: 24 (Kedua string dikonversi jadi angka)
console.log("100" / "2");   // Output: 50

// Jika teks tidak bisa diubah menjadi angka valid:
console.log("apel" - 2);    // Output: NaN (Not-a-Number)
```

### c. Koersi Nilai Boolean ke Number
Di dalam operasi matematika, nilai boolean dikonversi: `true` menjadi `1`, dan `false` menjadi `0`:

```javascript
console.log(1 + true);  // Output: 2 (1 + 1)
console.log(10 - false); // Output: 10 (10 - 0)
```

## Tabel Rangkuman Konversi Khusus

| Nilai Awal | Ke Tipe Number | Ke Tipe String | Ke Tipe Boolean |
| :--- | :--- | :--- | :--- |
| `0` | `0` | `"0"` | `false` |
| `1` | `1` | `"1"` | `true` |
| `""` (String kosong) | `0` | `""` | `false` |
| `"0"` (String nol) | `0` | `"0"` | **`true`** (Hati-hati!) |
| `null` | **`0`** | `"null"` | `false` |
| `undefined` | **`NaN`** | `"undefined"` | `false` |
| `[]` (Array kosong) | `0` | `""` | **`true`** |
| `{}` (Objek kosong) | `NaN` | `"[object Object]"` | **`true`** |

> [!CAUTION]
> Perhatikan bahwa `null` yang dikonversi ke Number menjadi `0`, sedangkan `undefined` yang dikonversi ke Number menghasilkan `NaN`. Ini adalah salah satu alasan utama mengapa operasi matematika terhadap nilai yang belum diisi sering kali berujung pada nilai `NaN`.
