## Statement dan Expression dalam JavaScript

Dua istilah paling mendasar dalam memahami cara kerja bahasa pemrograman apa pun adalah **Statement** dan **Expression**. Memahami perbedaan keduanya akan mempermudah Anda saat mempelajari alur percabangan, fungsi, hingga konsep pemrograman reaktif.

Secara analogi tata bahasa manusia:
- **Expression** adalah sebuah frasa atau kata benda yang mewakili suatu nilai (misalnya: *"apel merah"*, *"5 ditambah 3"*).
- **Statement** adalah sebuah kalimat perintah lengkap yang melakukan suatu tindakan dan diakhiri tanda titik (misalnya: *"Tolong ambilkan apel merah itu."*).

## 1. Apa itu Expression?

**Expression (Ekspresi)** adalah setiap penggalan kode yang dievaluasi oleh mesin JavaScript untuk **menghasilkan satu nilai (*value*)**.

Contoh-contoh expression:
```javascript
// Literal Expression (Menghasilkan nilai literal itu sendiri)
42;                 // Menghasilkan number: 42
"Belajar Coding";   // Menghasilkan string: "Belajar Coding"
true;               // Menghasilkan boolean: true

// Arithmetic Expression (Menghasilkan nilai hasil kalkulasi)
10 + 5;             // Menghasilkan number: 15
price * 0.1;        // Menghasilkan hasil perkalian

// String Expression (Menghasilkan teks gabungan)
"Halo " + "Dunia";  // Menghasilkan string: "Halo Dunia"

// Logical & Comparison Expression (Menghasilkan boolean true atau false)
score >= 80;        // Menghasilkan boolean: true atau false
isValid && isReady; // Menghasilkan boolean

// Function Call Expression (Menghasilkan nilai kembalian dari fungsi)
Math.max(10, 20);   // Menghasilkan number: 20
```

> [!TIP]
> **Aturan Praktis Menguji Expression**:
> Jika Anda dapat memasukkan penggalan kode tersebut ke dalam tanda kurung `console.log(...)` atau menyematkannya di dalam template literal `${...}` tanpa menimbulkan error sintaks, maka penggalan kode tersebut pasti merupakan sebuah **Expression**.

## 2. Apa itu Statement?

**Statement (Pernyataan / Kalimat Instruksi)** adalah satu unit instruksi lengkap yang memerintahkan komputer untuk mengeksekusi suatu tindakan tertentu (*action*). Statement tidak menghasilkan nilai secara langsung, melainkan mengatur aliran jalannya program.

Contoh-contoh statement:
```javascript
// 1. Declaration Statement (Mendeklarasikan variabel)
let skor = 100;
const nama = "Dicoding";

// 2. Control Flow Statement (Percabangan logika)
if (skor >= 75) {
  console.log("Lulus ujian");
}

// 3. Iteration Statement (Perulangan)
for (let i = 0; i < 3; i++) {
  console.log(i);
}

// 4. Return Statement (Menghentikan fungsi dan mengembalikan nilai)
return totalHarga;
```

Sebuah statement umumnya tersusun dari satu atau beberapa expression. Pada baris:
```javascript
let total = 5000 + 2500;
```
- Keseluruhan baris adalah sebuah **Declaration Statement**.
- Penggalan `5000 + 2500` adalah sebuah **Arithmetic Expression** yang dievaluasi menghasilkan angka `7500`.

## Titik Koma (Semicolon) dan Fitur ASI

Di dalam JavaScript, setiap statement biasanya diakhiri dengan tanda titik koma (`;`). Titik koma berfungsi sebagai penanda batas akhir instruksi bagi interpreter.

Contoh penulisan beberapa statement dalam satu baris menggunakan titik koma:
```javascript
const a = 1; const b = 2; console.log(a + b);
```

### Automatic Semicolon Insertion (ASI)
JavaScript memiliki fitur bawaan bernama **ASI (*Automatic Semicolon Insertion*)**. Jika Anda tidak menuliskan tanda titik koma di akhir baris, mesin JavaScript akan mencoba menyisipkan titik koma secara otomatis di balik layar saat membaca baris baru.

Meskipun fitur ini mempermudah penulisan, terdapat **jebakan berbahaya** jika Anda tidak berhati-hati saat memisahkan baris pada perintah `return`:

```javascript
// CONTOH JEBAKAN ASI:
function buatAkun() {
  return
  {
    nama: "Sangga"
  };
}

console.log(buatAkun()); // Output: undefined!
```

Mengapa hasilnya `undefined`?
Karena terdapat baris baru tepat setelah kata kunci `return`, mesin ASI mengira Anda telah menyelesaikan instruksi dan otomatis menyisipkan titik koma menjadi: `return;`. Akibatnya, blok objek di bawahnya diabaikan sama sekali.

Cara penulisan yang benar:
```javascript
function buatAkun() {
  return {
    nama: "Sangga"
  };
}
```

## Aturan Penulisan Komentar

Komentar adalah baris catatan yang diabaikan sepenuhnya oleh mesin JavaScript. Komentar digunakan untuk mendokumentasikan maksud dari logika yang rumit, memberi catatan kepada rekan tim, atau menonaktifkan kode sementara saat mencari kesalahan (*debugging*).

JavaScript mendukung 2 jenis komentar:

### 1. Komentar Satu Baris (Single-Line Comment)
Diawali dengan dua garis miring `//`. Seluruh teks setelah tanda ini hingga akhir baris dianggap sebagai komentar:
```javascript
// Menghitung pajak pertambahan nilai (PPN 11%)
const pajak = totalBelanja * 0.11;

const diskon = 10000; // Diskon khusus pelanggan setia
```

### 2. Komentar Multi-Baris (Multi-Line Comment)
Diawali dengan `/*` dan ditutup dengan `*/`. Sangat bermanfaat untuk menulis dokumentasi penjelasan yang panjang:
```javascript
/*
  Fungsi ini digunakan untuk menghitung rumus bunga majemuk.
  Parameter pokok: saldo awal modal pinjaman
  Parameter sukuBunga: persentase bunga tahunan dalam desimal
  Parameter periode: durasi tenor pinjaman dalam satuan tahun
*/
function hitungBunga(pokok, sukuBunga, periode) {
  return pokok * Math.pow((1 + sukuBunga), periode);
}
```

> [!NOTE]
> **Praktik Terbaik Menulis Komentar**:
> Jangan menulis komentar untuk menjelaskan hal yang sudah jelas terbaca dari kode (misal: `// menambahkan variabel i dengan 1`). Tulislah komentar untuk menjelaskan **alasan (mengapa)** suatu logika khusus dipilih ketika kodenya melibatkan algoritma yang tidak biasa.
