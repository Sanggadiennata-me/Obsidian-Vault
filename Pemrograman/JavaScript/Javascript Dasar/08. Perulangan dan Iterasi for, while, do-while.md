## Pengertian Perulangan (Looping / Iteration)

Dalam dunia nyata, komputer sangat diandalkan karena kemampuannya mengeksekusi instruksi yang sama berulang-ulang hingga jutaan kali dengan kecepatan kilat dan tanpa pernah merasa lelah.

Tanpa perulangan, mencetak teks sebanyak 5 kali mengharuskan kita menulis lima baris perintah manual:
```javascript
// Tanpa Perulangan (Melanggar Prinsip DRY - Don't Repeat Yourself)
console.log("Hello World");
console.log("Hello World");
console.log("Hello World");
console.log("Hello World");
console.log("Hello World");
```

Dengan struktur **Perulangan (*Looping / Iterasi*)**, kita dapat memerintahkan komputer mengulangi blok instruksi tersebut secara otomatis selama kondisi tertentu masih terpenuhi.

## 1. Perulangan `for` Tradisional

Struktur `for` paling cocok digunakan saat Anda **telah mengetahui secara pasti berapa kali perulangan harus dijalankan**.

Sintaks dasar:
```javascript
for (inisialisasi; kondisiUji; pembaruan) {
  // Blok instruksi yang diulang
}
```

```javascript
for (let i = 0; i < 5; i++) {
  console.log(`Perulangan ke-${i}`);
}

console.log("Selesai di luar blok for.");
```

Tahapan alur eksekusi perulangan di atas:
1. **Inisialisasi (`let i = 0`)**: Dijalankan hanya satu kali di awal sebelum iterasi pertama dimulai.
2. **Kondisi Uji (`i < 5`)**: Diperiksa sebelum setiap putaran loop. Jika bernilai `true`, blok kode di dalamnya dieksekusi. Jika `false`, perulangan langsung berhenti.
3. **Pembaruan / Increment (`i++`)**: Dijalankan di akhir setiap putaran loop untuk menambahkan nilai variabel pencacah.

### Iterasi Mundur (Decrement Loop):
```javascript
// Menghitung mundur dari 5 hingga 1
for (let i = 5; i > 0; i--) {
  console.log(`Hitung mundur: ${i}`);
}
console.log("Meluncur!");
```

## 2. Perulangan `while`

Struktur `while` mengevaluasi kondisi terlebih dahulu sebelum menjalankan blok kode. Struktur ini sangat ideal digunakan saat **jumlah putaran perulangan tidak dapat diprediksi secara pasti di awal**, melainkan bergantung pada kondisi dinamis (misalnya membaca data streaming atau menunggu status jaringan).

```javascript
let counter = 0;

while (counter < 5) {
  console.log(`Nilai counter saat ini: ${counter}`);
  counter++; // PENTING: Variabel pengubah harus diperbarui!
}

console.log("Keluar dari kondisi while.");
```

> [!CAUTION]
> **Bahaya Perulangan Tak Hingga (Infinite Loop)**:
> Jika Anda lupa menambahkan baris pembaruan variabel (seperti `counter++`), kondisi `counter < 5` akan selalu bernilai `true` selamanya. Akibatnya, tab browser atau proses server Anda akan mengalami *hang/freeze* karena kehabisan sumber daya CPU.

## 3. Perulangan `do - while`

Perulangan `do - while` memiliki karakteristik unik: **blok kode dijamin dijalankan minimal satu kali**, baru kemudian kondisi pengujiannya dievaluasi di akhir.

```javascript
let angka = 10;

do {
  console.log(`Nilai angka: ${angka}`);
  angka++;
} while (angka < 5);

// Output: Nilai angka: 10
```

Meskipun kondisi `angka < 5` bernilai salah sejak awal, teks di dalam blok `do` tetap sempat dieksekusi satu kali sebelum loop terhenti.

## 4. Perulangan Elemen Koleksi: `for...of`

Diperkenalkan pada ES6, `for...of` adalah cara paling bersih, modern, dan bebas bug untuk mengulang setiap isi data (*values*) dari struktur data yang dapat diiterasi (*iterable*) seperti Array, String, Map, atau Set:

```javascript
const daftarBuah = ["Apel", "Mangga", "Jeruk", "Pisang"];

for (const buah of daftarBuah) {
  console.log(`Saya suka makan buah: ${buah}`);
}
```

Anda tidak perlu lagi mengelola variabel indeks manual (`i = 0`, `i < arr.length`, `i++`), sehingga menghilangkan risiko kesalahan *off-by-one error*.

Kita juga dapat mengiterasi setiap huruf di dalam sebuah teks string:
```javascript
for (const huruf of "KODING") {
  console.log(huruf);
}
```

## 5. Perulangan Kunci Objek: `for...in`

Struktur `for...in` digunakan untuk menelusuri setiap **nama properti (*keys*)** yang ada di dalam sebuah Objek:

```javascript
const profil = {
  nama: "Sangga",
  kota: "Bandung",
  profesi: "Software Engineer"
};

for (const kunci in profil) {
  console.log(`Properti ${kunci}: ${profil[kunci]}`);
}
```

Output yang dihasilkan:
- Properti nama: Sangga
- Properti kota: Bandung
- Properti profesi: Software Engineer

## 6. Pengendalian Loop: `break` dan `continue`

JavaScript menyediakan dua kata kunci untuk menginterupsi alur perulangan secara dinamis:

### a. Kata Kunci `break`
Menghentikan seluruh perulangan seketika dan langsung keluar dari blok loop (misalnya saat data yang dicari sudah berhasil ditemukan):

```javascript
const angkaAcak = [12, 45, 78, 90, 23, 56];
const target = 90;

for (const item of angkaAcak) {
  console.log(`Sedang memeriksa angka: ${item}`);
  if (item === target) {
    console.log(`Angka ${target} ditemukan! Menghentikan pencarian.`);
    break; // Langsung keluar dari loop, angka 23 dan 56 tidak akan diperiksa
  }
}
```

### b. Kata Kunci `continue`
Mengabaikan sisa baris kode pada putaran saat ini dan langsung melompat ke putaran (*iterasi*) berikutnya:

```javascript
// Mencetak hanya bilangan ganjil antara 1 hingga 6
for (let i = 1; i <= 6; i++) {
  if (i % 2 === 0) {
    continue; // Jika angka genap, lewati baris console.log di bawah
  }
  console.log(`Bilangan ganjil: ${i}`);
}
```
