## Perbedaan Bahasa Pemrograman: Scripting vs Compiled

Komputer pada tingkat fisik perangkat keras hanya mengenali sinyal tegangan listrik yang direpresentasikan dalam sistem angka biner `0` dan `1` (*Machine Code*). 

Bahasa yang ditulis oleh programmer manusia (seperti JavaScript, C++, Python, dan Java) tergolong sebagai **Bahasa Tingkat Tinggi (*High-Level Language*)** karena menggunakan kata-kata bahasa Inggris dan simbol logika yang mudah dipahami manusia.

Agar instruksi yang ditulis manusia dapat dipahami oleh prosesor komputer, berkas kode sumber (*source code*) harus dikonversi ke dalam bahasa mesin. Dalam dunia ilmu komputer, terdapat dua mekanisme konversi utama: **Compiler** dan **Interpreter**.

## 1. Bahasa Terkompilasi (Compiled Language)

Pada bahasa yang menggunakan *compiler*, kode sumber harus diterjemahkan secara menyeluruh menjadi satu berkas biner berekstensi khusus (seperti berkas `.exe` di Windows atau biner ELF di Linux) sebelum program dapat dijalankan.

![Mekanisme Compiler](img/compiler.png)

Tahapan eksekusi:
1. Programmer menulis kode sumber (misalnya berkas `main.cpp`).
2. Program compiler memindai dan memeriksa seluruh baris kode. Jika ada satu saja kesalahan sintaks atau tipe data, proses kompilasi akan gagal seketika (*Compile-Time Error*).
3. Jika berhasil, compiler menghasilkan berkas biner mandiri yang siap diserahkan langsung ke prosesor komputer tanpa membutuhkan penerjemah lagi.

Contoh bahasa terkompilasi murni: **C, C++, Rust, Go, Swift**.

**Karakteristik**:
- Kecepatan eksekusi sangat tinggi karena instruksi sudah dalam format biner asli prosesor.
- Memerlukan waktu jeda (*build time*) setiap kali ada perubahan kode sebelum bisa diuji.

## 2. Bahasa Skrip (Scripting / Interpreted Language)

Bahasa skrip tidak memerlukan tahapan kompilasi manual di awal. Kode sumber dibaca, diartikan, dan dieksekusi secara langsung baris demi baris pada saat program berjalan (*runtime*) oleh sebuah program perantara bernama **Interpreter**.

Contoh bahasa berbasis interpreter: **JavaScript, Python, PHP, Ruby**.

**Karakteristik**:
- Sangat fleksibel dan cepat untuk tahap pengujian (*rapid prototyping*), Anda cukup menyimpan berkas kode lalu langsung menjalankannya.
- Portabel: Kode yang sama dapat dijalankan di berbagai sistem operasi (Windows, macOS, Linux) asalkan di komputer tersebut terpasang interpreter yang sesuai.

> [!NOTE]
> Seperti yang telah kita pelajari di bab sebelumnya, mesin JavaScript modern (seperti V8 Engine) saat ini menggunakan pendekatan hibrida **JIT (Just-In-Time) Compilation**. JavaScript menggabungkan kemudahan bahasa skrip (bisa langsung dijalankan tanpa kompilasi awal) dengan performa tinggi bahasa kompilasi (mengubah fungsi yang sering dipakai menjadi instruksi biner saat program berjalan).

## Dua Lingkungan Eksekusi JavaScript Modern

Kode JavaScript Anda dapat dieksekusi pada dua tempat lingkungan kerja (*runtime environment*) yang berbeda:

### 1. Browser Runtime (Sisi Klien / Client-Side)
Ini adalah lingkungan tradisional JavaScript di peramban web seperti Google Chrome, Firefox, dan Safari.
- **Tujuan Utama**: Memanipulasi tampilan halaman web (DOM), merespons klik dan input pengguna, serta mengatur efek visual antarmuka.
- **Objek Spesifik**: Menyediakan objek bawaan seperti `window`, `document`, `localStorage`, dan `fetch`.
- **Batasan Keamanan (Sandbox)**: Peramban melarang kode JavaScript membaca atau menghapus berkas pribadi di dalam hard disk pengguna tanpa izin eksplisit demi keamanan.

#### Cara Menjalankan Kode di Browser:
1. Buka peramban Google Chrome atau Firefox.
2. Buka menu Developer Tools dengan menekan tombol <kbd>F12</kbd> (atau klik kanan &rarr; **Inspect**), lalu pilih tab **Console**.
3. Ketikkan perintah:
   ```javascript
   console.log("Halo dari Developer Console!");
   ```
   Lalu tekan <kbd>Enter</kbd>. Pesan akan langsung dicetak seketika.

### 2. Node.js Runtime (Sisi Server & Desktop)
Node.js diciptakan oleh Ryan Dahl pada tahun 2009 dengan mengekstrak Engine V8 milik Google Chrome agar dapat berjalan di luar peramban secara mandiri di sistem operasi komputer.
- **Tujuan Utama**: Membangun server backend, REST API, automasi sistem, skrip terminal (CLI), dan pengolahan database.
- **Objek Spesifik**: Menyediakan objek bawaan seperti `global`, `process`, serta modul sistem berkas `fs`, jalur `path`, dan jaringan `http`.
- **Hak Akses Penuh**: Memiliki akses langsung ke sistem operasi lokal seperti membaca hard disk, menjalankan perintah shell, dan membuka port jaringan.

#### Cara Menjalankan Kode Menggunakan Node.js:
1. Buka aplikasi Terminal atau Command Prompt di komputer Anda.
2. Mode Interaktif (REPL): Ketik perintah `node` lalu tekan Enter. Anda dapat langsung mengetikkan kode JavaScript baris demi baris.
3. Mode Eksekusi Berkas: Buat berkas baru bernama `app.js` yang berisi:
   ```javascript
   console.log("Halo dari lingkungan server Node.js!");
   ```
   Lalu jalankan di terminal dengan perintah:
   ```bash
   node app.js
   ```
