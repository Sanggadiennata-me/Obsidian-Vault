## Pengenalan Operator dalam JavaScript

Operator adalah simbol atau kata kunci khusus yang digunakan untuk melakukan operasi pemrosesan matematis, perbandingan, atau logika terhadap satu atau lebih operan (nilai data) guna menghasilkan nilai baru.

JavaScript menyediakan beragam kategori operator yang sangat lengkap untuk mengolah data dalam aplikasi Anda.

## 1. Operator Aritmatika

Digunakan untuk melakukan perhitungan matematika:

| Operator | Operasi | Contoh | Hasil |
| :--- | :--- | :--- | :--- |
| `+` | Penjumlahan / Penggabungan Teks | `10 + 5` / `"Halo " + "Dunia"` | `15` / `"Halo Dunia"` |
| `-` | Pengurangan | `20 - 7` | `13` |
| `*` | Perkalian | `6 * 4` | `24` |
| `/` | Pembagian | `25 / 5` | `5` |
| `%` | Modulus (Sisa Pembagian) | `10 % 3` | `1` |
| `**`| Eksponensial (Perpangkatan) | `2 ** 3` (2 pangkat 3) | `8` |

### Operator Penambahan (Increment `++`) dan Pengurangan (Decrement `--`)
- **Postfix (`x++`)**: Mengembalikan nilai lama terlebih dahulu, baru kemudian menambahkan 1 ke variabel `x`.
- **Prefix (`++x`)**: Menambahkan 1 ke variabel `x` terlebih dahulu, baru kemudian mengembalikan nilai barunya.

```javascript
let a = 5;
let b = a++; // b bernilai 5, a sekarang menjadi 6

let c = 5;
let d = ++c; // c menjadi 6, d bernilai 6
```

## 2. Operator Penugasan (Assignment)

Digunakan untuk memberikan atau memperbarui nilai suatu variabel dengan cara yang ringkas:

```javascript
let x = 10;
x += 5;  // Sama dengan: x = x + 5; (Hasil: 15)
x -= 3;  // Sama dengan: x = x - 3; (Hasil: 12)
x *= 2;  // Sama dengan: x = x * 2; (Hasil: 24)
x /= 4;  // Sama dengan: x = x / 4; (Hasil: 6)
x %= 5;  // Sama dengan: x = x % 5; (Hasil: 1)
```

## 3. Operator Perbandingan: Mengapa `===` Sangat Penting?

Operator perbandingan mengevaluasi dua nilai dan menghasilkan nilai boolean (`true` atau `false`).

| Operator | Arti | Contoh | Hasil |
| :--- | :--- | :--- | :--- |
| `===` | Kesetaraan Ketat (*Strict Equality*) | `5 === "5"` | `false` (Beda tipe) |
| `==` | Kesetaraan Longgar (*Loose Equality*) | `5 == "5"` | `true` (Dipaksa sama) |
| `!==` | Ketidaksamaan Ketat (*Strict Inequality*) | `5 !== "5"` | `true` |
| `!=` | Ketidaksamaan Longgar | `5 != "5"` | `false` |
| `>` | Lebih dari | `10 > 5` | `true` |
| `<` | Kurang dari | `3 < 2` | `false` |
| `>=` | Lebih dari atau sama dengan | `5 >= 5` | `true` |
| `<=` | Kurang dari atau sama dengan | `4 <= 5` | `true` |

> [!WARNING]
> **Aturan Emas Industri: Selalu Gunakan `===` dan `!==`**
> Hindari operator kesetaraan longgar `==`. Operator `==` melakukan konversi tipe data implisit (*type coercion*) yang sering kali menghasilkan perilaku aneh dan membingungkan (misal: `0 == ""` bernilai `true`, `false == "0"` bernilai `true`).
> 
> Gunakan selalu operator ketat `===` karena memeriksa kesamaan **nilai sekaligus tipe datanya** secara disiplin.

## 4. Operator Logika (Logical Operators)

### a. Logika AND (`&&`)
Menghasilkan `true` hanya jika **kedua operan bernilai benar (*truthy*)**. Jika salah satu bernilai salah, hasilnya `false`.

```javascript
const punyaSIM = true;
const umurCukup = true;
console.log(punyaSIM && umurCukup); // Output: true
```

### b. Logika OR (`||`)
Menghasilkan `true` jika **salah satu dari kedua operan bernilai benar**. Hanya menghasilkan `false` jika kedua operan salah.

```javascript
const isAdmin = false;
const isEditor = true;
console.log(isAdmin || isEditor); // Output: true
```

### c. Logika NOT (`!`)
Membalikkan nilai boolean: `!true` menjadi `false`, dan `!false` menjadi `true`.

```javascript
const isTerkunci = false;
console.log(!isTerkunci); // Output: true
```

### Evaluasi Jalur Pendek (Short-Circuit Evaluation)
Operator `&&` dan `||` mengevaluasi nilai dari kiri ke kanan dan berhenti begitu hasil akhir sudah pasti:
- Pada `&&`: Jika sisi kiri *falsy*, sisi kanan tidak akan pernah dieksekusi.
- Pada `||`: Jika sisi kiri *truthy*, sisi kanan tidak akan pernah dieksekusi.

## 5. Operator Nullish Coalescing (`??`)

Di masa lalu, programmer sering memakai operator `||` untuk memberikan nilai cadangan (*default value*):
```javascript
let jumlahPesanan = 0;
let hasil = jumlahPesanan || 10; // Masalah: Angka 0 dianggap falsy, sehingga hasil menjadi 10!
```

ES2020 menghadirkan operator `??` (*Nullish Coalescing*) yang **hanya memeriksa apakah nilai di sisi kiri adalah `null` atau `undefined`**. Nilai `0` atau string kosong `""` tidak akan dianggap kosong:

```javascript
let kuota = 0;
let nilaiDefault = kuota ?? 100;
console.log(nilaiDefault); // Output: 0 (Aman dan tepat!)
```

## 6. Operator Ternary (Kondisional Sebaris)

Operator ternary adalah jalan pintas praktis untuk menulis percabangan `if-else` sederhana dalam satu baris:

```javascript
// Sintaks: kondisi ? nilaiJikaTrue : nilaiJikaFalse
const nilai = 85;
const statusKelulusan = nilai >= 75 ? "Lulus" : "Tidak Lulus";
console.log(statusKelulusan); // Output: Lulus
```

## 7. Operator Rantai Opsional (Optional Chaining `?.`)

Saat mengakses properti objek yang bersarang dalam (*nested object*), aplikasi akan crash dengan error `TypeError: Cannot read properties of undefined` jika objek induknya tidak ada.

Operator `?.` menghentikan evaluasi secara aman dan mengembalikan `undefined` tanpa membuat program crash:

```javascript
const pengguna = {
  nama: "Siti",
  alamat: null
};

// Aman: Tidak crash meskipun alamat bernilai null
console.log(pengguna.alamat?.kota); // Output: undefined
```
