## Pengertian Fungsi (Function)

Fungsi (*Function*) adalah blok kode terorganisir yang dirancang untuk melakukan satu tugas spesifik tertentu. Tanpa fungsi, program akan dipenuhi oleh baris-baris kode yang diduplikasi berulang kali setiap kali tugas yang sama perlu dijalankan.

Manfaat utama penggunaan fungsi:
1. **Reusabilitas (*Code Reusability*)**: Kode ditulis satu kali dan dapat dipanggil puluhan hingga ribuan kali dari berbagai bagian program.
2. **Keterbacaan (*Readability*)**: Membungkus algoritma kompleks di balik nama fungsi yang deskriptif (misalnya: `hitungPajak()`, `validasiEmail()`).
3. **Kemudahan Perawatan (*Maintainability*)**: Jika ada perubahan rumus atau perbaikan bug, Anda cukup memperbaikinya di satu tempat di dalam tubuh fungsi tersebut.

## 1. Deklarasi Fungsi (Function Declaration)

Deklarasi fungsi adalah cara paling mendasar dalam mendefinisikan fungsi di JavaScript dengan menggunakan kata kunci `function`:

```javascript
// Mendefinisikan fungsi
function sapaDunia() {
  console.log("Halo, selamat datang di dunia pemrograman JavaScript!");
}

// Memanggil / mengeksekusi fungsi
sapaDunia();
```

### Keistimewaan Hoisting pada Function Declaration
Fungsi yang dibuat menggunakan sintaks deklarasi memiliki keistimewaan **Hoisting Penuh**. Artinya, fungsi tersebut dapat dipanggil di baris kode mana pun, bahkan **sebelum** baris pendefinisian fisiknya di dalam berkas:

```javascript
// Berjalan mulus tanpa error berkat Function Hoisting!
tampilkanPesan();

function tampilkanPesan() {
  console.log("Fungsi ini dipanggil sebelum baris deklarasinya!");
}
```

## 2. Parameter dan Argumen

Fungsi menjadi jauh lebih dinamis dan fleksibel ketika dapat menerima data masukan dari luar:

- **Parameter**: Nama variabel penampung yang ditulis di dalam tanda kurung saat mendefinisikan fungsi.
- **Argumen**: Nilai data riil yang dikirimkan ke dalam fungsi saat fungsi tersebut dipanggil.

```javascript
// 'nama' dan 'waktu' adalah PARAMETER
function sapaPengguna(nama, waktu) {
  console.log(`Selamat ${waktu}, rekan ${nama}!`);
}

// "Ahmad" dan "pagi" adalah ARGUMEN
sapaPengguna("Ahmad", "pagi"); // Output: Selamat pagi, rekan Ahmad!
sapaPengguna("Siti", "malam");  // Output: Selamat malam, rekan Siti!
```

## 3. Parameter Bawaan (Default Parameters)

Jika pemanggil fungsi tidak menyertakan argumen, parameter tersebut secara default akan bernilai `undefined`. Fitur **Default Parameters** (ES6) memungkinkan kita menentukan nilai cadangan otomatis:

```javascript
// Jika parameter 'nama' tidak diisi, gunakan nilai bawaan "Pengunjung"
function sambutTamu(nama = "Pengunjung") {
  console.log(`Halo, ${nama}! Selamat menikmati acara.`);
}

sambutTamu("Budi"); // Output: Halo, Budi! Selamat menikmati acara.
sambutTamu();       // Output: Halo, Pengunjung! Selamat menikmati acara.
```

## 4. Nilai Kembalian (Return Value)

Sebuah fungsi tidak hanya dapat mencetak teks ke layar konsol, tetapi juga dapat **mengembalikan hasil perhitungan (*return value*)** kembali ke baris pemanggilnya untuk disimpan ke dalam variabel atau diolah lebih lanjut.

Kita menggunakan kata kunci `return` untuk mengembalikan nilai:

![Return Value Ilustrasi](img/returnvalue.png)

```javascript
function hitungLuasPersegi(panjang, lebar) {
  const luas = panjang * lebar;
  return luas; // Mengirimkan nilai keluar dari fungsi
}

// Menampung hasil kembalian fungsi ke dalam variabel
const hasilLuas = hitungLuasPersegi(10, 5);
console.log(`Luas tanah: ${hasilLuas} meter persegi`); // Output: Luas tanah: 50 meter persegi
```

> [!NOTE]
> Jika sebuah fungsi tidak memiliki kata kunci `return` (atau hanya menuliskan `return;` tanpa nilai di belakangnya), fungsi tersebut secara otomatis mengembalikan nilai **`undefined`**.

### Kata Kunci `return` Menghentikan Fungsi
Perintah `return` bertindak sebagai pintu keluar instan. Baris kode apa pun yang ditulis setelah perintah `return` di dalam blok yang sama tidak akan pernah dieksekusi:

```javascript
function contohSelesai() {
  console.log("Baris ini dieksekusi.");
  return "Selesai";
  console.log("Baris ini TIDAK AKAN PERNAH dieksekusi!");
}
```

## 5. Pola Pengembalian Dini (Early Return / Guard Clauses)

Pola desain yang sangat dianjurkan oleh pengembang profesional adalah **Early Return**. Alih-alih membungkus seluruh tubuh fungsi di dalam blok `if-else` bersarang yang dalam, periksa kondisi kegagalan atau input tidak valid di awal dan langsung keluar dengan `return`:

```javascript
// Pendekatan Bersih: Early Return (Guard Clauses)
function prosesPembayaran(totalBelanja, saldoDompet) {
  // 1. Validasi awal (Guard Clause)
  if (totalBelanja <= 0) {
    return "Error: Total belanja tidak valid.";
  }

  if (saldoDompet < totalBelanja) {
    return "Error: Saldo dompet tidak mencukupi.";
  }

  // 2. Jalur logika utama berjalan bersih tanpa indentasi if-else yang bertumpuk
  const sisaSaldo = saldoDompet - totalBelanja;
  return `Pembayaran berhasil! Sisa saldo Anda: Rp ${sisaSaldo}`;
}

console.log(prosesPembayaran(50000, 100000)); // Pembayaran berhasil! Sisa saldo Anda: Rp 50000
console.log(prosesPembayaran(150000, 100000)); // Error: Saldo dompet tidak mencukupi.
```
