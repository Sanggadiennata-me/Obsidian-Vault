## Pengertian Variabel dalam Komputer

Dalam pemrograman, variabel dapat diibaratkan sebagai sebuah kotak penyimpanan berlabel di dalam memori komputer (RAM). Kotak tersebut diberi nama pengenal (*identifier*) agar programmer dapat menyimpan suatu data, membaca kembali nilainya, atau memperbarui isinya di kemudian hari saat program sedang berjalan.

```javascript
let namaPengguna = "Sangga";
console.log(namaPengguna); // Menampilkan: Sangga
```

## Tiga Kata Kunci Deklarasi: var, let, dan const

JavaScript menyediakan 3 kata kunci untuk mendeklarasikan variabel: `var`, `let`, dan `const`. Memahami perbedaan ketiganya sangat penting karena menandai evolusi besar dari JavaScript lama (ES5) menuju JavaScript modern (ES6+).

| Fitur / Karakteristik | `var` (Tradisional ES5) | `let` (Modern ES6) | `const` (Modern ES6) |
| :--- | :--- | :--- | :--- |
| **Cakupan Wilayah (*Scope*)** | Function Scope | Block Scope (`{}`) | Block Scope (`{}`) |
| **Bisa Ditugaskan Ulang (*Reassign*)?** | Ya | Ya | **Tidak** |
| **Bisa Dideklarasikan Ulang (*Redeclare*)?**| Ya (Rawan Bug) | Tidak | Tidak |
| **Wajib Inisialisasi Nilai Awal?** | Tidak | Tidak | **Ya (Wajib)** |
| **Hoisting Behavior** | Terangkat dengan nilai `undefined` | Terangkat ke Temporal Dead Zone (TDZ) | Terangkat ke Temporal Dead Zone (TDZ) |

### 1. Kata Kunci `let`
Gunakan `let` untuk variabel yang **nilainya akan berubah** seiring berjalannya program (misalnya: variabel pencacah loop, status login, skor game, atau total keranjang belanja).

```javascript
let skor = 0;
skor = 10; // Valid: Nilai diperbarui
console.log(skor); // Output: 10
```

### 2. Kata Kunci `const`
Gunakan `const` (*constant*) sebagai **pilihan utama secara default** untuk setiap data yang nilainya tidak boleh atau tidak diharapkan berubah setelah pertama kali ditetapkan.

```javascript
const pi = 3.14159;
// pi = 3.14; // ERROR: TypeError: Assignment to constant variable.
```

> [!IMPORTANT]
> **Mutabilitas pada Objek dan Array `const`**:
> Kata kunci `const` mencegah penugasan ulang alamat memori (*reassignment*). Namun jika nilai variabelnya bertipe referensi (seperti Objek atau Array), **isi properti di dalamnya tetap dapat diubah atau dimutasi**:
> ```javascript
> const pengguna = { nama: "Budi", usia: 20 };
> pengguna.usia = 21; // Valid: Mengubah properti internal
> console.log(pengguna.usia); // Output: 21
> 
> // pengguna = { nama: "Siti" }; // ERROR: Tidak boleh reassign variabel pengguna
> ```

### 3. Kata Kunci `var` (Hindari Penggunaannya)
Sebelum tahun 2015, `var` adalah satu-satunya cara membuat variabel di JavaScript. Saat ini, penggunaan `var` dianggap sebagai **praktik usang (*deprecated pattern*)** karena perilakunya yang tidak intuitif dan sering menyebabkan variabel bocor ke luar lingkup blok program.

## Konsep Cakupan Variabel (Scoping)

Cakupan (*Scope*) menentukan di bagian kode mana suatu variabel dapat diakses atau dibaca.

### Block Scope vs Function Scope
- **Block Scope (`let` dan `const`)**: Variabel hanya hidup di dalam sepasang tanda kurung kurawal `{ ... }` tempat ia dideklarasikan (seperti di dalam blok `if`, `for`, atau fungsi). Begitu blok selesai, variabel tersebut dihancurkan dari memori.
- **Function Scope (`var`)**: Variabel `var` mengabaikan batas blok kurung kurawal `if` atau `for`, dan hanya terkurung jika diletakkan di dalam deklarasi fungsi.

Perhatikan contoh kebocoran variabel `var`:
```javascript
if (true) {
  var pesanVar = "Halo dari var";
  let pesanLet = "Halo dari let";
}

console.log(pesanVar); // Output: Halo dari var (BOCOR ke luar blok!)
// console.log(pesanLet); // ERROR: ReferenceError: pesanLet is not defined (Aman terisolasi)
```

## Fenomena Hoisting dan Temporal Dead Zone (TDZ)

**Hoisting** adalah mekanisme di mana mesin JavaScript memindai seluruh deklarasi variabel dan fungsi, lalu secara konseptual "mengangkat" deklarasi tersebut ke bagian paling atas dari cakupannya sebelum baris kode pertama dieksekusi.

### Perilaku Hoisting pada `var`:
Variabel `var` diangkat dan otomatis diisi nilai bawaan `undefined`:
```javascript
console.log(nama); // Output: undefined (Program tidak crash, tapi membingungkan)
var nama = "Dicoding";
```

### Perilaku Hoisting pada `let` dan `const` (Temporal Dead Zone):
Variabel `let` dan `const` sebenarnya juga mengalami hoisting, namun mereka berada dalam wilayah terlarang bernama **Temporal Dead Zone (TDZ)** sampai baris inisialisasi aslinya tercapai:
```javascript
// Wilayah TDZ untuk variabel 'kota' dimulai di sini
// console.log(kota); // ERROR: ReferenceError: Cannot access 'kota' before initialization
let kota = "Bandung"; // Wilayah TDZ berakhir di sini
console.log(kota); // Output: Bandung
```
Perilaku TDZ pada JavaScript modern jauh lebih aman karena langsung memicu pesan error yang jelas jika ada programmer yang tidak sengaja memakai variabel sebelum baris pembuatannya.

## Aturan Baku Penamaan Variabel (Naming Conventions)

Untuk menulis kode yang bersih, konsisten, dan bebas dari error sintaks, patuhi aturan penamaan berikut:

1. **Format camelCase**: Awali kata pertama dengan huruf kecil, dan kapitalisasi huruf pertama pada setiap kata berikutnya:
   - Baik: `namaLengkap`, `totalHargaBarang`, `isUserLoggedIn`.
   - Buruk: `namalengkap`, `Totalhargabarang`.
2. **Karakter yang Diizinkan**: Hanya boleh terdiri dari huruf alfabet (a-z, A-Z), angka (0-9), garis bawah (*underscore*) `_`, dan simbol dolar `$`.
3. **Tidak Boleh Diawali Angka**:
   - Benar: `user1`, `produk2`.
   - Salah: `1user`, `2produk` (memicu SyntaxError).
4. **Sensitif Huruf Besar-Kecil (Case-Sensitive)**: Variabel `skor`, `Skor`, dan `SKOR` adalah 3 variabel yang sepenuhnya berbeda di memori.
5. **Dilarang Menggunakan Kata Kunci Cadangan (Reserved Words)**: Jangan menamai variabel dengan kata perintah bahasa JavaScript seperti `let`, `const`, `function`, `class`, `return`, atau `if`.
