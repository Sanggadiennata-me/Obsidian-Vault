## Struktur Data Koleksi Modern: Map dan Set

Pada spesifikasi ECMAScript 2015 (ES6), JavaScript memperkenalkan dua struktur data koleksi baru: **Map** dan **Set**. Kehadiran keduanya dirancang secara khusus untuk mengatasi keterbatasan struktur data tradisional Objek dan Array:

- Pada Objek biasa, kunci properti (*keys*) hanya boleh bertipe String atau Symbol, dan berisiko mewarisi properti bawaan (*prototype collision*).
- Pada Array biasa, data dapat memiliki duplikasi elemen yang identik secara berulang.

## 1. Struktur Data `Map`

`Map` adalah struktur data yang menyimpan pasangan kunci dan nilai (*key-value pairs*), di mana **kunci dapat bertipe data apa saja tanpa batasan** (bisa berupa angka number, boolean, fungsi, bahkan objek lain).

### Membuat dan Mengoperasikan Map:
```javascript
// Membuat instance Map kosong
const modalBisnis = new Map();

// Objek yang dijadikan sebagai Kunci (Key)
const cabangBandung = { id: 1, nama: "Cabang Bandung" };
const cabangJakarta = { id: 2, nama: "Cabang Jakarta" };

// 1. Menyimpan data menggunakan metode set(key, value)
modalBisnis.set(cabangBandung, 50000000);
modalBisnis.set(cabangJakarta, 85000000);
modalBisnis.set("targetTahunan", 200000000);
modalBisnis.set(100, "Bonus Maksimal");

// 2. Membaca data menggunakan metode get(key)
console.log(modalBisnis.get(cabangBandung)); // Output: 50000000
console.log(modalBisnis.get("targetTahunan")); // Output: 200000000

// 3. Memeriksa keberadaan kunci menggunakan has(key)
console.log(modalBisnis.has(cabangJakarta)); // Output: true
console.log(modalBisnis.has("cabangBali")); // Output: false

// 4. Memeriksa jumlah data menggunakan properti size
console.log(modalBisnis.size); // Output: 4

// 5. Menghapus data menggunakan delete(key)
modalBisnis.delete(100);

// 6. Mengosongkan seluruh Map menggunakan clear()
// modalBisnis.clear();
```

### Iterasi Data pada Map:
`Map` mempertahankan urutan penyisipan data (*insertion order*), sehingga dapat diiterasi secara andal menggunakan `for...of`:

```javascript
for (const [kunci, nilai] of modalBisnis) {
  console.log(`Kunci:`, kunci, `-> Nilai:`, nilai);
}
```

### Perbandingan: Kapan Memilih `Map` Dibanding Objek Biasa?

| Fitur | Objek Biasa (`{}`) | `Map` |
| :--- | :--- | :--- |
| **Tipe Kunci yang Diizinkan** | Hanya String dan Symbol | **Sembarang Tipe Data** (Number, Objek, Fungsi, Boolean) |
| **Menghitung Jumlah Elemen** | Manual lewat `Object.keys(obj).length` | Sangat cepat via properti `.size` |
| **Jaminan Urutan Iterasi** | Kurang konsisten pada kunci angka | **Dijamin 100%** sesuai urutan saat data dimasukkan |
| **Performa Tambah/Hapus Dinamis** | Lambat untuk mutasi frekuensi tinggi | **Dioptimasi tinggi** untuk skenario sering tambah dan hapus |

## 2. Struktur Data `Set`

`Set` adalah struktur data yang menyimpan sekumpulan nilai yang **dijamin unik 100% (*collection of unique values*)**. Nilai yang sama tidak akan pernah dapat diduplikasi di dalam sebuah Set.

Jika Anda mencoba memasukkan nilai yang sudah ada sebelumnya, Set akan mengabaikan nilai duplikat tersebut secara otomatis tanpa memicu error.

### Membuat dan Mengoperasikan Set:
```javascript
// Membuat Set baru dari array dengan nilai duplikat
const angkaUnik = new Set([1, 2, 2, 3, 4, 4, 4, 5]);

console.log(angkaUnik); // Set(5) { 1, 2, 3, 4, 5 } (Duplikasi otomatis dibuang!)

// 1. Menambahkan nilai baru dengan add(value)
angkaUnik.add(6);
angkaUnik.add(1); // Diabaikan karena angka 1 sudah ada

// 2. Memeriksa keberadaan nilai dengan has(value)
console.log(angkaUnik.has(3));  // true
console.log(angkaUnik.has(10)); // false

// 3. Menghapus nilai dengan delete(value)
angkaUnik.delete(2);

// 4. Membaca jumlah total nilai unik
console.log(angkaUnik.size); // 5 (yaitu: 1, 3, 4, 5, 6)
```

### Trik Populer: Menghapus Duplikasi Array dalam Satu Baris
Menggabungkan `Set` dengan `Spread Operator` adalah teknik standar industri paling elegan untuk menghapus duplikasi data pada Array:

```javascript
const daftarEmailKotor = [
  "budi@mail.com",
  "siti@mail.com",
  "budi@mail.com",
  "ahmad@mail.com",
  "siti@mail.com"
];

// Konversi Array -> Set (otomatis unik) -> Konversi kembali ke Array
const daftarEmailBersih = [...new Set(daftarEmailKotor)];

console.log(daftarEmailBersih);
// Hasil: ["budi@mail.com", "siti@mail.com", "ahmad@mail.com"]
```
