### Laboratorium Praktik dan Latihan Mandiri

Modul ini dilengkapi dengan berkas kode skrip JavaScript yang siap dijalankan langsung di Node.js atau Browser Developer Console:

#### Direktori Praktik Kode:
- [Praktek/Variable.js](Praktek/Variable.js) - Eksperimen deklarasi variabel
- [Praktek/Conditional.js](Praktek/Conditional.js) - Simulasi logika kelulusan dan alur kontrol
- [Praktek/Looping.js](Praktek/Looping.js) - Demonstrasi perulangan for, while, dan for-of
- [Praktek/DataArray.js](Praktek/DataArray.js) - Manipulasi indeks dan elemen array
- [Praktek/DataObject.js](Praktek/DataObject.js) - Eksperimen penambahan dan mutasi properti objek
- [Praktek/DataSet.js](Praktek/DataSet.js) - Pengujian nilai unik pada struktur Set
- [Praktek/Function.js](Praktek/Function.js) - Uji pemanggilan fungsi dan parameter
- [Praktek/FunExpression.js](Praktek/FunExpression.js) - Implementasi first-class function
- [Praktek/Implementasi Flow Control.js](Praktek/Implementasi%20Flow%20Control.js) - Studi kasus alur logika bisnis
- [Praktek/Mengubah Type Data.js](Praktek/Mengubah%20Type%20Data.js) - Simulasi konversi eksplisit dan koersi tipe data

#### Direktori Latihan Lanjutan:
- [Latihan/BasicLogic.js](Latihan/BasicLogic.js) - Soal logika seleksi kondisi
- [Latihan/Loop.js](Latihan/Loop.js) - Tantangan perulangan algoritma
- [Latihan/ArrayProcessing.js](Latihan/ArrayProcessing.js) - Pemrosesan kumpulan data array
- [Latihan/ObjectManipulation.js](Latihan/ObjectManipulation.js) - Manipulasi objek profil data
- [Latihan/LatihanFunction.js](Latihan/LatihanFunction.js) - Pembuatan fungsi modular
- [Latihan/Module/main.mjs](Latihan/Module/main.mjs) & [Latihan/Module/utils.mjs](Latihan/Module/utils.mjs) - Implementasi nyata ES Modules
