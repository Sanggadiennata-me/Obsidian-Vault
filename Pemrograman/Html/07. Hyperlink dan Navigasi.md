## Pengertian Hyperlink dan Elemen Anchor (`<a>`)

Hyperlink (atau sering disingkat tautan/link) adalah fitur inti yang menghubungkan dokumen-dokumen di seluruh World Wide Web. Tanpa hyperlink, web hanya akan menjadi kumpulan dokumen terisolasi.

Pada HTML, hyperlink dibuat menggunakan elemen anchor `<a>` (*Anchor Tag*). Elemen ini membutuhkan atribut wajib `href` (*Hypertext REFerence*) yang menentukan URL atau berkas tujuan ketika tautan tersebut diklik.

```html
<a href="https://dicoding.com">Kunjungi Situs Dicoding</a>
```

Teks di antara tag pembuka `<a>` dan tag penutup `</a>` disebut sebagai teks jangkar (*anchor text*).

## Jenis-Jenis Tautan Berdasarkan Alamat (URL)

Secara umum, tautan dapat dikelompokkan menjadi tiga tipe alamat tujuan:

### 1. Tautan Absolut (Absolute URL)
Tautan absolut mengarah ke domain atau situs web eksternal. Alamat URL harus ditulis lengkap beserta protokolnya (`http://` atau `https://`).

```html
<a href="https://www.google.com">Cari di Google</a>
<a href="https://developer.mozilla.org/id/">Dokumentasi MDN</a>
```

### 2. Tautan Relatif (Relative URL)
Tautan relatif mengarah ke berkas atau halaman lain di dalam situs web yang sama. Jalur penulisan (*path*) disesuaikan dengan posisi berkas saat ini:

- **Satu Folder yang Sama**: Cukup sebutkan nama berkasnya langsung atau awali dengan `./`.
  ```html
  <a href="tentang.html">Tentang Kami</a>
  <a href="./kontak.html">Hubungi Kami</a>
  ```
- **Masuk ke Dalam Subfolder**:
  ```html
  <a href="artikel/belajar-html.html">Baca Artikel HTML</a>
  ```
- **Keluar Naik Satu Tingkat Folder**: Gunakan tanda dua titik `../`.
  ```html
  <a href="../index.html">Kembali ke Beranda</a>
  ```
- **Dari Folder Akar (Root Relative)**: Diawali dengan garis miring tunggal `/`.
  ```html
  <a href="/layanan/konsultasi.html">Layanan Konsultasi</a>
  ```

### 3. Tautan Lompatan Internal Halaman (Fragment Identifier)
Anda dapat membuat tautan yang membuat halaman langsung menggulir (*scroll*) ke bagian tertentu pada dokumen yang sama. Caranya dengan menargetkan nilai atribut `id` dari elemen tujuan, diawali dengan tanda pagar `#`.

```html
<!-- Tautan Navigasi di Atas Halaman -->
<nav>
  <a href="#profil">Profil</a> |
  <a href="#portofolio">Portofolio</a> |
  <a href="#kontak">Kontak</a>
</nav>

<!-- Bagian Konten Halaman -->
<section id="profil">
  <h2>Profil Pengembang</h2>
  <p>Detail profil...</p>
</section>

<section id="portofolio">
  <h2>Daftar Portofolio</h2>
  <p>Detail portofolio...</p>
</section>

<section id="kontak">
  <h2>Hubungi Saya</h2>
  <p>Detail kontak...</p>
</section>
```

Tautan lompatan ini juga bisa digabungkan dengan halaman lain, misalnya:
```html
<a href="layanan.html#harga">Lihat Tabel Harga di Halaman Layanan</a>
```

## Membuka Tautan di Tab Baru: Atribut `target`

Secara default, ketika pengguna mengklik tautan, halaman baru akan dimuat pada tab browser yang sedang aktif (`target="_self"`).

Jika Anda ingin tautan terbuka di tab atau jendela baru peramban, gunakan atribut `target="_blank"`:

```html
<a href="https://github.com" target="_blank" rel="noopener noreferrer">
  Buka Profil GitHub di Tab Baru
</a>
```

> [!WARNING]
> **Aturan Keamanan Krusial**: Setiap kali Anda menggunakan `target="_blank"` pada tautan eksternal, Anda **WAJIB** menyertakan atribut `rel="noopener noreferrer"`.
> 
> Tanpa atribut tersebut, halaman eksternal yang baru dibuka dapat mengakses halaman asal Anda melalui objek JavaScript `window.opener`, yang dapat dimanfaatkan oleh peretas untuk melakukan serangan pengalihan berbahaya (*reverse tabnabbing phishing*).

## Skema Protokol Khusus

Elemen `<a>` tidak hanya dapat membuka halaman web, tetapi juga dapat memicu aplikasi bawaan di komputer atau ponsel pengguna:

### 1. Tautan Email: `mailto:`
Memicu aplikasi email klien (seperti Thunderbird, Apple Mail, atau Outlook) dengan alamat tujuan yang sudah terisi otomatis:
```html
<a href="mailto:halo@sanggadiennata.my.id">Kirim Email</a>

<!-- Disertai Subjek dan Pesan Awal -->
<a href="mailto:halo@sanggadiennata.my.id?subject=Tanya%20Kerjasama&body=Halo%20Tim,%20saya%20tertarik...">Hubungi Kerjasama</a>
```

### 2. Tautan Telepon: `tel:`
Pada perangkat smartphone, tautan ini akan langsung membuka aplikasi panggilan telepon dengan nomor yang sudah siap dipanggil:
```html
<a href="tel:+6281234567890">Telepon Sekarang: (0812) 3456-7890</a>
```

### 3. Tautan SMS: `sms:`
Membuka aplikasi perpesanan SMS pada perangkat ponsel:
```html
<a href="sms:+6281234567890?body=Halo%20Admin">Kirim SMS</a>
```

## Mengunduh Berkas: Atribut `download`

Jika Anda ingin pengguna langsung mengunduh berkas (misal: PDF, ZIP, gambar) daripada membukanya langsung di peramban, tambahkan atribut `download`:

```html
<!-- Mengunduh file dengan nama asli -->
<a href="dokumen/panduan.pdf" download>Unduh Panduan (PDF)</a>

<!-- Mengunduh file dan otomatis menamai ulang nama berkas di komputer pengguna -->
<a href="dokumen/panduan.pdf" download="Panduan-Lengkap-HTML5.pdf">Unduh Panduan Resmi</a>
```

## Praktik Terbaik Teks Tautan (SEO & Aksesibilitas)

1. **Gunakan Teks Tautan yang Deskriptif**: Hindari menulis "klik di sini" atau "baca selengkapnya". Screen reader sering kali membaca daftar link secara terisolasi tanpa membaca kalimat sekitarnya.
   - Buruk: *"Untuk mengunduh kurikulum, klik `[di sini](kurikulum.pdf)`."*
   - Baik: *"Unduh `[Kurikulum Lengkap HTML5 (PDF)](kurikulum.pdf)` untuk mempelajari silabus."*
2. **Beri Petunjuk Format dan Ukuran**: Jika tautan mengarah ke berkas unduhan besar, sebutkan format dan ukurannya (misal: `Unduh Laporan Keuangan (PDF, 4.2 MB)`).
