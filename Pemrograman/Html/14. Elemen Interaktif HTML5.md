## Interaktivitas Natif Tanpa JavaScript Eksternal

Di masa lalu, pembuatan komponen interaktif seperti akordion buka-tutup (*collapsible accordion*), jendela sembul (*modal popup*), atau bilah indikator kemajuan (*progress bar*) selalu memerlukan puluhan baris kode JavaScript dan pustaka eksternal.

HTML5 memperkenalkan elemen-elemen interaktif bawaan yang didukung langsung oleh mesin peramban secara natif, cepat, ringan, dan ramah aksesibilitas (*A11y*).

## 1. Akordion Buka-Tutup: `<details>` dan `<summary>`

Elemen `<details>` digunakan untuk membuat widget buka-tutup yang menyembunyikan atau menampilkan informasi tambahan sesuai interaksi klik pengguna.

Di dalam `<details>`, kita menggunakan tag `<summary>` sebagai judul tombol pemicu (*label heading*) yang dapat diklik.

```html
<details>
  <summary>Apakah kursus ini cocok untuk pemula yang belum pernah coding?</summary>
  <p>
    Tentu saja! Kurikulum ini disusun secara terstruktur dari tingkat paling dasar tanpa memerlukan pengalaman pemrograman sebelumnya.
  </p>
</details>

<details open>
  <summary>Berapa lama masa akses materi pembelajaran?</summary>
  <p>
    Anda mendapatkan akses seumur hidup (lifetime access) termasuk pembaruan materi di masa mendatang.
  </p>
</details>
```

### Karakteristik Penting:
1. **Atribut `open`**: Jika disertakan pada tag `<details open>`, panel konten akan langsung terbuka secara default saat halaman dimuat.
2. **Aksesibilitas Bawaan**: Secara otomatis dapat dioperasikan menggunakan keyboard (tombol <kbd>Space</kbd> atau <kbd>Enter</kbd> untuk membuka/menutup).
3. **Ikon Segitiga Bawaan**: Peramban menampilkan ikon panah segitiga yang otomatis berputar saat dibuka. Tampilan ini dapat dikustomisasi menggunakan CSS pseudo-element `::marker`.

## 2. Jendela Modal Pop-Up Natif: Elemen `<dialog>`

Elemen `<dialog>` adalah salah satu fitur paling revolusioner dalam HTML5 modern. Elemen ini menyajikan jendela dialog atau modal tanpa memerlukan plugin pustaka pihak ketiga.

```html
<!-- Tombol untuk membuka modal -->
<button type="button" id="btnBukaModal">Buka Syarat & Ketentuan</button>

<!-- Komponen Dialog Modal -->
<dialog id="modalSyarat">
  <h2>Syarat dan Ketentuan Layanan</h2>
  <p>
    Dengan mendaftar, Anda menyetujui seluruh ketentuan privasi data pengguna yang berlaku di platform kami.
  </p>
  
  <!-- Form method="dialog" otomatis menutup modal saat tombol diklik -->
  <form method="dialog">
    <button type="submit">Saya Mengerti & Setuju</button>
  </form>
</dialog>

<script>
  const tombolBuka = document.getElementById('btnBukaModal');
  const dialogModal = document.getElementById('modalSyarat');

  // Membuka modal dengan lapisan gelap di belakang (backdrop)
  tombolBuka.addEventListener('click', () => {
    dialogModal.showModal();
  });
</script>
```

### Mengapa Elemen `<dialog>` Sangat Unggul?
1. **Metode `.showModal()`**: Menampilkan dialog sebagai modal sejati di lapisan *top layer*, otomatis menggelapkan latar belakang halaman di belakangnya, dan mencegah pengguna mengklik konten lain di luar modal.
2. **Perangkap Fokus Keyboard (*Focus Trap*)**: Tombol <kbd>Tab</kbd> keyboard pengguna secara otomatis terkunci hanya di dalam elemen modal demi aksesibilitas penyandang disabilitas.
3. **Dukungan Tombol <kbd>Escape</kbd>**: Menekan tombol <kbd>Esc</kbd> di keyboard akan langsung menutup dialog modal secara otomatis tanpa kode tambahan.
4. **Penutupan Tanpa JavaScript**: Form dengan atribut `method="dialog"` otomatis menutup modal ketika tombol submit ditekan.
5. **Styling Latar Belakang dengan CSS `::backdrop`**:
   ```css
   dialog::backdrop {
     background-color: rgba(0, 0, 0, 0.65);
     backdrop-filter: blur(4px);
   }
   ```

## 3. Bilah Kemajuan Tugas: Elemen `<progress>`

Elemen `<progress>` digunakan untuk menampilkan bilah kemajuan (*progress bar*) dari sebuah proses yang sedang berlangsung (misalnya: pengunggahan berkas, penginstalan aplikasi, atau tingkat penyelesaian profil).

```html
<!-- Mode Determinate (Nilai Terukur Jelas) -->
<label for="unggah">Kemajuan Pengunggahan Berkas:</label>
<progress id="unggah" value="70" max="100">70%</progress>
```

- `value`: Angka progres saat ini (contoh: 70).
- `max`: Nilai maksimal target (contoh: 100). Nilai default jika diabaikan adalah 1.0.

### Mode Indeterminate (Tidak Diketahui)
Jika Anda menghilangkan atribut `value`, peramban akan menampilkan animasi garis berjalan bolak-balik tanpa henti:
```html
<label for="proses">Sedang memproses transaksi...</label>
<progress id="proses"></progress>
```
Sangat ideal digunakan saat aplikasi sedang memuat data yang durasinya belum dapat diprediksi secara pasti.

## 4. Pengukur Nilai Skalar: Elemen `<meter>`

Elemen `<meter>` digunakan untuk menampilkan pengukuran nilai kuantitatif dalam rentang tertentu yang telah diketahui batasnya (misalnya: penggunaan memori RAM, kapasitas penyimpanan SSD, tingkat suhu baterai, atau kekuatan kata sandi).

```html
<label for="disk">Kapasitas Penyimpanan Disk C:</label>
<meter 
  id="disk" 
  value="85" 
  min="0" 
  max="100" 
  low="30" 
  high="80" 
  optimum="20"
>
  85 GB dari 100 GB
</meter>
```

### Atribut Pengatur Skala pada `<meter>`:
- `value`: Nilai kuantitas aktual saat ini.
- `min` dan `max`: Batas bawah dan batas atas rentang ukur.
- `low`: Ambang batas bawah kategori rendah.
- `high`: Ambang batas atas kategori tinggi.
- `optimum`: Titik nilai yang dianggap paling ideal.

> [!NOTE]
> Peramban akan otomatis mengubah warna visual bilah meter (misalnya hijau menjadi kuning atau merah) jika nilainya melampaui batas `high` atau menjauhi nilai `optimum`.

### Perbedaan Krusial: `<progress>` vs `<meter>`
- Gunakan `<progress>` untuk sesuatu yang **sedang berjalan menuju penyelesaian** (seperti proses download atau tahapan wizard registrasi).
- Gunakan `<meter>` untuk **nilai statis yang sedang diukur pada titik waktu tertentu** (seperti sisa baterai 45% atau kapasitas ruang disk).
