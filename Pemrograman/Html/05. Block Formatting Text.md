## Pengenalan Block Formatting Text

Selain paragraf dan heading, HTML menyediakan elemen-elemen khusus untuk memformat blok konten tertentu secara mandiri dan bermakna (*semantic block formatting*). Elemen-elemen ini meliputi kutipan panjang (`<blockquote>`), teks dengan spasi terformat (`<pre>`), ilustrasi independen (`<figure>`), serta informasi kontak penulis (`<address>`).

## 1. Kutipan Panjang: `<blockquote>`

Jika Anda menampilkan kutipan langsung dari tokoh, kutipan artikel, atau testimoni pengguna yang panjang, gunakan elemen `<blockquote>`. Elemen ini membungkus konten kutipan yang bisa berupa paragraf, heading, atau daftar item.

```html
<blockquote>
  <p>
    Situs web adalah sekumpulan halaman web yang saling berhubungan yang umumnya berada pada peladen yang sama berisikan kumpulan informasi yang disediakan secara perorangan, kelompok, atau organisasi.
  </p>
</blockquote>
```

Secara visual, browser default akan memberikan indentasi margin di sisi kiri dan kanan kutipan.

Elemen `<blockquote>` mendukung atribut `cite` untuk mencantumkan URL sumber rujukan asli dari kutipan tersebut:

```html
<blockquote cite="https://id.wikipedia.org/wiki/Situs_web">
  <p>
    Situs web adalah sekumpulan halaman web yang saling berhubungan yang umumnya berada pada peladen yang sama berisikan kumpulan informasi yang disediakan secara perorangan, kelompok, atau organisasi.
  </p>
</blockquote>
```

> [!NOTE]
> Nilai atribut `cite` pada `<blockquote>` ditujukan untuk mesin pencari dan metadata peramban. Teks URL tersebut tidak muncul secara visual di layar.

## 2. Teks Berformat Asli: `<pre>`

Seperti yang telah kita pelajari, HTML secara normal akan mereduksi spasi berulang dan enter. Namun untuk beberapa jenis konten (seperti bait puisi, seni ASCII, atau kode program), jarak spasi dan perpindahan baris asli sangatlah krusial.

Elemen `<pre>` (*Preformatted Text*) menampilkan teks persis seperti yang Anda ketikkan di dalam text editor, dengan mempertahankan seluruh spasi, tab, dan baris baru, serta ditampilkan menggunakan jenis font *monospace*.

```html
<pre>
  SAJAK PUTIH

Bersandar pada tari warna pelangi
Kau depanku bertudung sutra senja
Di hitam matamu kembang mawar dan melati
Harum rambutmu mengalun bergelut senda

Sepi menyanyi, malam dalam mendoa tiba
Meriak muka air kolam jiwa
Dan dalam dadaku memerdu lagu
Menarik menari seluruh aku

Hidup dari hidupku, pintu terbuka
Selama matamu bagiku menengadah
Selama kau darah mengalir dari luka
Antara kita Mati datang tidak membelah...

                  Karya: Chairil Anwar
</pre>
```

### Kombinasi `<pre>` dan `<code>` untuk Blok Kode
Ketika Anda ingin menampilkan blok kode pemrograman dalam artikel web, gabungkan tag `<pre>` dengan tag `<code>`:

```html
<pre><code>function hitungLuas(panjang, lebar) {
  return panjang * lebar;
}
console.log(hitungLuas(10, 5));</code></pre>
```

Tag `<code>` menandai bahwa kontennya adalah bahasa komputer, sedangkan `<pre>` mempertahankan struktur baris dan indentasinya.

## 3. Konten Mandiri: `<figure>` dan `<figcaption>`

Elemen `<figure>` digunakan untuk membungkus konten mandiri (*self-contained content*) seperti gambar foto, diagram grafik, ilustrasi arsitektur, tabel data, atau potongan kode referensi.

Keunggulan utama `<figure>` adalah konten di dalamnya bersifat independen. Jika posisi `<figure>` dipindahkan ke halaman lampiran atau bagian bawah dokumen, arti dari alur teks utama tidak akan terganggu.

Di dalam elemen `<figure>`, Anda dapat menambahkan tag `<figcaption>` sebagai keterangan judul (*caption*) dari konten tersebut:

```html
<p>
  Dicoding adalah perusahaan teknologi edukasi yang bertujuan mengembangkan talenta digital di seluruh Indonesia.
</p>

<figure>
  <img
    src="https://raw.githubusercontent.com/dicodingacademy/a123-webdasar-labs/099-shared-files/shared-media/g-dicoding-logo.png"
    alt="Logo Dicoding Indonesia"
    width="200"
  >
  <figcaption>Gambar 1.1: Logo resmi Dicoding Indonesia</figcaption>
</figure>
```

Tampilan yang dihasilkan:

![Elemen Figure](Image/Figure.png)

Elemen `<figure>` juga dapat digunakan untuk membungkus teks puisi atau diagram kode bersama `<figcaption>`:

```html
<figure>
  <pre>
  function salam() {
    alert("Halo Dunia!");
  }
  </pre>
  <figcaption>Listing 1.2: Fungsi salam sederhana</figcaption>
</figure>
```

## 4. Informasi Kontak Penulis: `<address>`

Elemen semantik `<address>` digunakan untuk membungkus informasi kontak untuk pemilik atau penulis dokumen. Jika diletakkan di dalam `<footer>` halaman, `<address>` merujuk pada kontak seluruh website.

```html
<footer>
  <address>
    Ditulis oleh <a href="mailto:author@example.com">Tim Redaksi</a>.<br>
    Kunjungi kami di Gedung Cyber Lt. 5, Jl. Rasuna Said, Jakarta.<br>
    Telepon: <a href="tel:+62215551234">(021) 555-1234</a>
  </address>
</footer>
```
