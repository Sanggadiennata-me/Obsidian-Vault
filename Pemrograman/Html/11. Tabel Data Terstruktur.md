## Pengertian Data Tabular dan Elemen `<table>`

Dalam menyajikan data multidimensi yang tersusun atas baris dan kolom (seperti jadwal pelajaran, daftar harga, rekap skor, atau laporan transaksi keuangan), HTML menyediakan elemen semantik `<table>`.

Data tabular disajikan dalam kisi dua dimensi yang terdiri atas baris (*rows*) dan sel kolom (*columns/cells*).

![Contoh Data Tabular](Image/Tabel.png)

> [!CAUTION]
> **Aturan Penting**: Gunakan elemen `<table>` **hanya** untuk menyajikan data tabular riil. Jangan sekali-kali menggunakan tabel untuk menyusun tata letak (*layout*) keseluruhan halaman web! Tata letak halaman web modern harus selalu disusun menggunakan CSS Flexbox atau CSS Grid.

## 1. Struktur Dasar Tabel

Tabel pada HTML paling mendasar tersusun dari 3 elemen:
- `<table>`: Pembungkus utama tabel.
- `<tr>` (*Table Row*): Membuat sebuah baris horisontal baru.
- `<th>` (*Table Header*): Sel judul kolom atau baris (teks otomatis tebal dan berada di tengah).
- `<td>` (*Table Data*): Sel data biasa yang menampung isi konten.

![Ilustrasi Struktur Baris dan Sel](Image/Tabel2.png)

Hubungan antara elemen-elemen tersebut dipetakan sebagai berikut:

![Konversi Ilustrasi ke Elemen HTML](Image/Table3.png)

Contoh kode dasar tabel:

```html
<table>
  <tr>
    <th>Tahun</th>
    <th>Juara 1</th>
    <th>Juara 2</th>
    <th>Juara 3</th>
  </tr>
  <tr>
    <td>2018</td>
    <td>Prancis</td>
    <td>Kroasia</td>
    <td>Belgia</td>
  </tr>
  <tr>
    <td>2014</td>
    <td>Jerman</td>
    <td>Argentina</td>
    <td>Belanda</td>
  </tr>
  <tr>
    <td>2010</td>
    <td>Spanyol</td>
    <td>Belanda</td>
    <td>Jerman</td>
  </tr>
</table>
```

## 2. Pengelompokan Semantik: `<thead>`, `<tbody>`, `<tfoot>`, dan `<caption>`

Untuk tabel berskala menengah hingga besar, HTML menyediakan elemen pengelompokan semantik yang membantu peramban dan pembaca layar memahami anatomi data secara utuh:

1. `<caption>`: Judul atau keterangan deskriptif tabel yang diletakkan tepat setelah tag pembuka `<table>`.
2. `<thead>`: Mengelompokkan baris header tabel (*table header*).
3. `<tbody>`: Mengelompokkan kumpulan baris data utama (*table body*).
4. `<tfoot>`: Mengelompokkan baris ringkasan, total akhir, atau catatan kaki (*table footer*).

```html
<table>
  <caption>Tabel Rekap Penjualan Kursus Q1 2026</caption>
  
  <thead>
    <tr>
      <th scope="col">Nama Kursus</th>
      <th scope="col">Siswa Terdaftar</th>
      <th scope="col">Total Pendapatan</th>
    </tr>
  </thead>
  
  <tbody>
    <tr>
      <th scope="row">HTML5 & CSS3 Dasar</th>
      <td>1.250</td>
      <td>Rp 125.000.000</td>
    </tr>
    <tr>
      <th scope="row">JavaScript Modern</th>
      <td>890</td>
      <td>Rp 178.000.000</td>
    </tr>
  </tbody>
  
  <tfoot>
    <tr>
      <th scope="row">Total Keseluruhan</th>
      <td>2.140</td>
      <td>Rp 303.000.000</td>
    </tr>
  </tfoot>
</table>
```

### Aksesibilitas dengan Atribut `scope`
Perhatikan penggunaan atribut `scope` pada elemen `<th>`:
- `scope="col"`: Menyatakan bahwa sel header ini menaungi seluruh data di kolom bawahnya.
- `scope="row"`: Menyatakan bahwa sel header ini menaungi seluruh data di baris samping kanannya.

Atribut ini sangat membantu pengguna tuna netra yang menggunakan screen reader untuk mengetahui konteks sel saat menavigasi baris dan kolom.

## 3. Penggabungan Sel: Spanning Cell

Sama seperti fitur *Merge Cells* pada Microsoft Excel, HTML memungkinkan sel tabel merentang melewati lebih dari satu kolom atau baris:

### Merentang Kolom: Atribut `colspan`
Atribut `colspan` merentangkan sebuah sel secara horisontal ke kanan melewati beberapa kolom.

```html
<table border="1">
  <tr>
    <th>18:00</th>
    <th>19:00</th>
    <th>20:00</th>
  </tr>
  <tr>
    <td colspan="2">Avengers: Endgame</td>
    <td>Spiderman</td>
  </tr>
  <tr>
    <td>One Piece</td>
    <td>Weathering With You</td>
    <td>Gundala</td>
  </tr>
</table>
```

Tampilan yang dihasilkan:

![Column Spanning](Image/Tabel5.png)

Pada contoh di atas, film *Avengers: Endgame* menempati 2 slot jam sekaligus (18.00 dan 19.00).

### Merentang Baris: Atribut `rowspan`
Atribut `rowspan` merentangkan sebuah sel secara vertikal ke bawah melewati beberapa baris.

```html
<table border="1">
  <tr>
    <th rowspan="3">18:00</th>
    <td>Avengers: Infinity War</td>
  </tr>
  <tr>
    <td>One Piece: Stampede</td>
  </tr>
  <tr>
    <td>Gundala</td>
  </tr>
</table>
```

Tampilan yang dihasilkan:

![Row Spanning](Image/Tabel6.png)

Sel header jam `18:00` merentang ke bawah melewati 3 baris secara bersamaan.
