## Template Standar Dokumen HTML5

Setiap dokumen web modern dibangun di atas fondasi kerangka standar HTML5. Kerangka ini memberi tahu browser jenis dokumen yang sedang dibaca dan mengatur konfigurasi awal sebelum halaman dirender ke layar pengguna.

Berikut adalah kerangka boilerplate dokumen HTML5 yang lengkap:

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Tutorial lengkap dasar HTML5 untuk pemula">
  <title>Belajar HTML5 Modern</title>
  
  <!-- Favicon -->
  <link rel="icon" type="image/png" href="favicon.png">
  
  <!-- File CSS Eksternal -->
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <h1>Selamat Datang di Dunia Web</h1>
  </header>

  <main>
    <p>Ini adalah konten utama yang tampil di jendela peramban.</p>
  </main>

  <footer>
    <p>&copy; 2026 Belajar Coding. Seluruh hak cipta dilindungi.</p>
  </footer>

  <!-- File JavaScript Eksternal -->
  <script src="script.js"></script>
</body>
</html>
```

Mari kita bedah fungsi dari masing-masing elemen pada kerangka di atas satu per satu.

## 1. Deklarasi Dokumen: `<!DOCTYPE html>`

Di baris paling pertama dokumen web, Anda akan selalu menemukan tag `<!DOCTYPE html>`.

Secara teknis, `<!DOCTYPE html>` bukanlah tag HTML, melainkan sebuah instruksi dokumen (*document type declaration*) yang ditujukan kepada peramban. Instruksi ini memerintahkan browser untuk merender halaman menggunakan standar spesifikasi HTML5 modern (*Standards Mode*).

Jika deklarasi ini dihilangkan, browser akan masuk ke mode kompatibilitas kuno (*Quirks Mode*). Akibatnya, tata letak dan perilaku CSS modern dapat mengalami kerusakan karena browser mencoba meniru perilaku browser lawas era 1990-an.

## 2. Elemen Akar: `<html lang="id">`

Elemen `<html>` adalah elemen induk teratas (*root element*) dari seluruh pohon DOM (*Document Object Model*) dalam sebuah halaman web. Semua elemen lain (kecuali DOCTYPE) harus berada di dalam tag pembuka `<html>` dan tag penutup `</html>`.

Atribut `lang` pada elemen html sangat penting:
- Menentukan bahasa utama yang digunakan dalam dokumen.
- Nilai `lang="id"` menunjukkan bahasa Indonesia, sedangkan `lang="en"` menunjukkan bahasa Inggris.
- Membantu perangkat pembaca layar (*screen reader*) bagi penyandang disabilitas agar melafalkan teks dengan aksen dan tata bahasa yang tepat.
- Membantu mesin pencari seperti Google mengkategorikan target demografis bahasa konten Anda.

## 3. Bagian Metadata: `<head>`

Elemen `<head>` berfungsi sebagai wadah untuk menyimpan seluruh data teknis dan konfigurasi dokumen (*metadata*). Konten yang berada di dalam tag `<head>` **tidak akan ditampilkan secara visual** pada kanvas halaman web oleh browser.

Elemen-elemen penting di dalam `<head>` meliputi:

### a. `meta charset="UTF-8"`
Menentukan sistem pengkodean karakter yang digunakan pada dokumen. Standar pengkodean universal adalah **UTF-8**, yang mendukung hampir seluruh huruf, simbol, angka, dan emoji dari berbagai bahasa di dunia (termasuk huruf Arab, Kanji, Hangul, simbol matematika, dan emoji).

Tanpa deklarasi ini, karakter khusus dapat mengalami kerusakan tampilan (*mojibake* atau simbol aneh seperti tanda tanya dalam kotak).

### b. `meta name="viewport" content="width=device-width, initial-scale=1.0"`
Konfigurasi ini mutlak diperlukan untuk menciptakan halaman web yang responsif di perangkat ponsel pintar (*smartphone*) dan tablet:
- `width=device-width`: Menyesuaikan lebar viewport peramban dengan lebar fisik layar perangkat pengguna.
- `initial-scale=1.0`: Menetapkan rasio zoom awal sebesar 100% ketika halaman pertama kali dibuka, sehingga teks tidak mengecil otomatis saat dibuka di layar HP.

### c. `title`
Menentukan judul dokumen. Judul ini ditampilkan pada:
1. Tab peramban pengguna.
2. Nama judul ketika halaman ditambahkan ke bookmark atau favorit.
3. Judul tautan utama pada hasil pencarian mesin pencari (Google SERP).

### d. `link rel="stylesheet"` dan `link rel="icon"`
Tag `<link>` digunakan untuk menghubungkan dokumen HTML dengan berkas eksternal:
- `rel="stylesheet"` menautkan file CSS eksternal.
- `rel="icon"` memasang favicon (ikon kecil yang muncul di sebelah kiri judul tab peramban).

## 4. Bagian Konten Visual: `<body>`

Elemen `<body>` mewakili seluruh konten dokumen yang dapat dilihat, dibaca, dan diinteraksikan secara langsung oleh pengguna di jendela peramban.

Semua teks, gambar, video, tombol navigasi, tabel, audio, dan formulir harus diletakkan di dalam tag `<body>`. Hanya boleh ada **satu** elemen `<body>` dalam satu dokumen HTML.

## Penempatan Tag Script JavaScript

Kode JavaScript eksternal biasanya dimuat menggunakan elemen `<script src="...">`. Ada dua praktik umum penempatannya:

1. **Di akhir sebelum penutup `</body>`**: Browser membaca dokumen dari atas ke bawah. Menempatkan script di bagian akhir memastikan seluruh elemen visual HTML telah ter-render terlebih dahulu, sehingga pengguna tidak mengalami penundaan visual saat script dimuat.
2. **Di dalam `<head>` dengan atribut `defer`**:
   ```html
   <head>
     <script src="script.js" defer></script>
   </head>
   ```
   Atribut `defer` memberi tahu peramban untuk mengunduh berkas JavaScript di latar belakang tanpa memblokir rendering HTML, lalu mengeksekusinya tepat setelah seluruh struktur HTML selesai dibaca.

## Komentar dalam HTML

Komentar adalah baris catatan yang ditulis oleh developer untuk menjelaskan maksud kode. Teks di dalam komentar **diabaikan oleh peramban** dan tidak akan muncul di layar pengguna.

Format komentar dalam HTML menggunakan sintaks:
```html
<!-- Ini adalah komentar satu baris -->

<!--
  Ini adalah komentar multi-baris.
  Sangat berguna untuk memberi catatan penjelasan,
  menandai pembagian seksi layout,
  atau menonaktifkan kode sementara saat debugging.
-->
```
