## Apa itu HTML?

HTML merupakan singkatan dari **HyperText Markup Language**. HTML adalah bahasa standar yang digunakan di seluruh dunia untuk menyusun struktur dasar dan menampilkan konten pada halaman web.

Banyak pemula yang mengira HTML adalah bahasa pemrograman. Secara teknis, HTML **bukan bahasa pemrograman**, melainkan sebuah bahasa markah (*markup language*). HTML tidak memiliki logika komputasi seperti variabel pemroses, percabangan kondisi (*if-else*), ataupun perulangan (*looping*). Peran utama HTML murni untuk menandai (*mark up*) bagian-bagian dokumen agar peramban (*web browser*) mengerti mana yang merupakan judul utama, paragraf teks, gambar, tabel, tautan navigasi, atau formulir input.

Dalam analogi pembangunan rumah atau tubuh manusia:
1. **HTML**: Rangka bangunan atau tulang tubuh manusia. Menentukan denah, ruangan, dan struktur dasar.
2. **CSS**: Desain interior, cat dinding, pakaian, dan riasan wajah. Menentukan keindahan visual, warna, dan tata letak.
3. **JavaScript**: Sistem kelistrikan otomatis, otot, dan saraf. Menentukan interaktivitas, animasi dinamis, dan perilaku aplikasi.

## Makna HyperText dan Markup

Untuk memahami cara kerja HTML, mari kita bedah dua kata kuncinya:
- **HyperText (Teks Terhubung)**: Teks yang dapat membawa pengguna berpindah dari satu halaman ke halaman lain di seluruh penjuru internet hanya dengan sekali klik (melalui hyperlink).
- **Markup (Penandaan)**: Kumpulan simbol atau tag khusus yang disematkan pada teks polos untuk memberi instruksi kepada browser mengenai bagaimana teks tersebut harus diinterpretasikan.

Misalkan kita menulis teks polos:
```text
Belajar Web Development itu menyenangkan.
```
Browser tidak tahu apakah teks di atas judul atau paragraf. Namun ketika kita menandainya dengan tag HTML:
```html
<h1>Belajar Web Development itu menyenangkan.</h1>
```
Browser langsung memahami bahwa teks tersebut adalah judul tingkat pertama (*Heading 1*) dan merendernya dengan ukuran besar serta tebal.

## Anatomi Elemen HTML

Sebuah elemen HTML umumnya terdiri dari tiga komponen utama: tag pembuka, isi konten, dan tag penutup.

```
       Atribut
      ┌───┴───┐
     <p class="intro">Halo dunia, selamat datang di web!</p>
     └───┬───┘        └──────────────┬──────────────┘ └───┬──┘
     Tag Pembuka                   Konten              Tag Penutup
```

Keterangan komponen:
1. **Tag Pembuka (*Opening Tag*)**: Terdiri dari nama elemen yang diapit oleh tanda kurung siku buka `<` dan siku tutup `>`. Tag ini menandai dimulainya elemen.
2. **Atribut (*Attribute*)**: Informasi tambahan yang disematkan di dalam tag pembuka untuk memodifikasi perilaku atau identitas elemen. Format atribut selalu berupa pasangan nama dan nilai: `nama="nilai"`. Contoh: `class="intro"`, `id="utama"`, atau `href="https://google.com"`.
3. **Konten (*Content*)**: Teks atau elemen lain yang berada di antara tag pembuka dan penutup.
4. **Tag Penutup (*Closing Tag*)**: Menandai berakhirnya elemen. Formatnya sama dengan tag pembuka, tetapi memiliki garis miring (*forward slash*) `/` sebelum nama elemen (contoh: `</p>`, `</h1>`, `</div>`).

## Elemen Berpasangan vs Elemen Kosong (Void Elements)

Mayoritas elemen HTML memiliki pasangan tag pembuka dan tag penutup karena mereka membungkus konten teks atau elemen turunan lain:
```html
<p>Ini adalah paragraf teks.</p>
<button type="button">Klik Saya</button>
```

Namun, ada beberapa elemen yang disebut **Void Elements** (elemen kosong / *self-closing*). Elemen jenis ini tidak memiliki konten di dalamnya dan tidak memerlukan tag penutup terpisah:
```html
<!-- Menampilkan gambar -->
<img src="foto.jpg" alt="Pemandangan Alam">

<!-- Membuat garis pemisah horizontal -->
<hr>

<!-- Pindah ke baris baru di dalam teks -->
<br>

<!-- Input data formulir -->
<input type="text" name="username">

<!-- Menautkan stylesheet CSS di bagian head -->
<link rel="stylesheet" href="style.css">

<!-- Metadata dokumen -->
<meta charset="UTF-8">
```

> [!NOTE]
> Pada standar HTML5 modern, penulisan void element tidak mewajibkan garis miring di akhir (misalnya cukup `<img>` dan bukan `<img />`). Keduanya valid, namun penulisan tanpa garis miring penutup adalah gaya paling umum pada HTML5.

## Standar Penulisan: Lowercase

HTML tidak sensitif terhadap huruf besar atau kecil (*case-insensitive*). Artinya, `<H1>`, `<h1>`, dan `<H1>` diperlakukan sama persis oleh peramban.

Meskipun demikian, standar resmi **W3C (World Wide Web Consortium)** dan konvensi industri profesional mewajibkan penulisan semua tag dan nama atribut dalam **huruf kecil (*lowercase*)**. Menulis tag dengan huruf kecil membuat kode lebih rapi, konsisten, dan mudah dirawat.

```html
<!-- Dianjurkan (Sesuai Standar Industri) -->
<a href="https://example.com" class="btn-primary">Kunjungi Website</a>

<!-- Tidak Dianjurkan (Meskipun Berfungsi) -->
<A HREF="https://example.com" CLASS="btn-primary">Kunjungi Website</A>
```

## Mengenal Berkas index.html

Ketika membuat sebuah website, nama berkas halaman utama selalu dinamai `index.html`. Mengapa demikian?

Web server di seluruh dunia secara default dikonfigurasi untuk mencari dan menyajikan berkas bernama `index.html` ketika pengguna mengunjungi root direktori suatu domain atau folder. 

Sebagai contoh:
- Saat seseorang membuka URL `https://mysite.com/`, web server di balik layar secara otomatis menyajikan berkas `https://mysite.com/index.html`.
- Jika Anda memiliki folder blog di `https://mysite.com/blog/`, web server akan mencari `https://mysite.com/blog/index.html`.

## Cara Menjalankan Berkas HTML

Salah satu keunggulan terbesar HTML adalah kemudahannya untuk dipelajari:
1. Buat folder proyek baru di komputer Anda.
2. Buat berkas baru bernama `index.html` menggunakan editor teks (misalnya Visual Studio Code).
3. Tulis kode HTML di dalamnya lalu simpan.
4. Klik dua kali berkas tersebut atau seret (*drag and drop*) ke peramban seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge.

Halaman web Anda akan langsung tampil di peramban tanpa memerlukan koneksi internet ataupun instalasi server lokal.
