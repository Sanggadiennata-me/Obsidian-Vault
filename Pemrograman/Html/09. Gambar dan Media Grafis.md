## Elemen Gambar (`<img>`)

Untuk menyematkan gambar visual ke dalam halaman web, kita menggunakan elemen `<img>`. Elemen ini merupakan *void element* (elemen kosong tanpa tag penutup) yang bekerja melalui atribut-atribut khusus di dalamnya.

```html
<img 
  src="https://raw.githubusercontent.com/dicodingacademy/a123-webdasar-labs/099-shared-files/shared-media/dicoding-logo.jpg" 
  alt="Logo Resmi Dicoding Indonesia"
  width="300"
  height="150"
  loading="lazy"
>
```

Mari kita bedah atribut-atribut penting yang menyertai elemen `<img>`:

## 1. Atribut Wajib: `src` dan `alt`

### Atribut `src` (Source)
Atribut `src` menentukan lokasi berkas gambar yang akan dimuat. Nilainya dapat berupa:
- **Jalur Relatif (*Relative Path*)**: Lokasi berkas di komputer lokal atau server hosting (contoh: `src="gambar/profil.jpg"` atau `src="../assets/hero.png"`).
- **Alamat URL Penuh (*Absolute URL*)**: Tautan langsung ke gambar di web server eksternal (contoh: `src="https://example.com/foto.webp"`).

### Atribut `alt` (Alternative Text)
Atribut `alt` menyediakan teks pengganti jika gambar gagal dimuat (misalnya karena koneksi internet lambat atau tautan berkas terputus). Selain itu, atribut `alt` memiliki dua peran krusial:
1. **Aksesibilitas (A11y)**: Dibacakan oleh perangkat *screen reader* untuk tuna netra, sehingga mereka mengetahui makna informasi yang terkandung dalam gambar.
2. **SEO Mesin Pencari**: Membantu perayap Google memahami topik visual halaman untuk pencarian Google Images.

> [!TIP]
> **Aturan Penulisan Alt Text**:
> - Tuliskan deskripsi yang informatif dan ringkas, hindari mengulang kata "gambar dari..." atau "foto...".
> - Jika gambar bersifat **murni dekoratif** (seperti garis ornamen hiasan atau pola latar abstrak yang tidak membawa informasi baru), gunakan atribut `alt=""` (string kosong). Ini memberi sinyal pada screen reader untuk mengabaikan ornamen tersebut sehingga tidak mengganggu pendengar tuna netra.

## 2. Pencegahan Pergeseran Tata Letak: `width` dan `height`

Selalu sertakan nilai atribut `width` dan `height` dalam piksel (tanpa menulis satuan `px` di HTML):

```html
<img src="produk.jpg" alt="Sepatu Lari Nyaman" width="600" height="400">
```

Mengapa ini sangat penting?
Ketika browser mengunduh HTML sebelum gambar selesai diunduh, browser menghitung rasio aspek (*aspect ratio*) dari atribut lebar dan tinggi tersebut untuk mencadangkan kotak ruang kosong di layar. 

Hal ini mencegah terjadinya **Cumulative Layout Shift (CLS)**, yaitu fenomena menyebalkan di mana teks artikel tiba-tiba melompat ke bawah saat gambar selesai dimuat.

## 3. Pemuatan Efisien: `loading="lazy"`

Secara default, browser akan mengunduh seluruh gambar yang ada di halaman sekaligus begitu halaman dibuka (*eager loading*). Jika halaman memiliki 20 gambar berukuran besar, hal ini akan memboroskan kuota internet pengguna dan memperlambat kecepatan buka situs (*First Contentful Paint*).

Tambahkan atribut `loading="lazy"` pada gambar yang posisinya berada di bawah lipatan layar (*below-the-fold*):

```html
<img src="galeri-10.jpg" alt="Koleksi Galeri Foto" width="800" height="600" loading="lazy">
```

Dengan `loading="lazy"`, browser menunda pengunduhan gambar sampai pengguna menggulir (*scroll*) layar mendekati posisi gambar tersebut.

## 4. Format Berkas Gambar Web Modern

Memilih format berkas yang tepat sangat berpengaruh terhadap performa situs web:

| Format | Karakteristik Utama | Rekomendasi Penggunaan |
| :--- | :--- | :--- |
| **WebP** | Format modern Google dengan kompresi 30% lebih ringan dibanding JPEG/PNG tanpa menurunkan kualitas. | Standar utama foto dan ilustrasi web saat ini. |
| **AVIF** | Format generasi terbaru berbasis video codec AV1, rasio kompresi sangat superior. | Foto berkualitas tinggi dengan ukuran file paling minimal. |
| **SVG** | Vektor matematis berbasis XML (*Scalable Vector Graphics*). Bebas pecah saat diperbesar berapapun. | Ikon, logo, diagram, dan ilustrasi flat. |
| **PNG** | Mendukung transparansi piksel (*alpha channel*), kompresi tanpa kehilangan data (*lossless*). | Grafis transparan atau tangkapan layar antarmuka (*screenshot*). |
| **JPEG / JPG** | Kompresi foto lossy tradisional, kompatibilitas 100% di semua perangkat tua. | Cadangan format untuk peramban kuno. |

## 5. Art Direction Responsif: Elemen `<picture>`

Terkadang kita ingin menyajikan gambar dengan orientasi atau resolusi berbeda sesuai lebar layar pengguna (misalnya: di layar komputer menampilkan foto landscape memanjang, namun di layar HP menampilkan foto portrait yang terpotong fokus ke subjek utama).

HTML5 menyediakan elemen `<picture>` yang dapat membungkus beberapa elemen `<source>` dan satu elemen cadangan `<img>`:

```html
<picture>
  <!-- Layar Desktop Lebar (di atas 1024px) -->
  <source media="(min-width: 1024px)" srcset="hero-desktop.webp" type="image/webp">
  
  <!-- Layar Tablet (di atas 768px) -->
  <source media="(min-width: 768px)" srcset="hero-tablet.webp" type="image/webp">
  
  <!-- Cadangan Format WebP untuk Ponsel -->
  <source srcset="hero-mobile.webp" type="image/webp">
  
  <!-- Fallback Default jika peramban tidak mendukung picture -->
  <img src="hero-fallback.jpg" alt="Suasana Kantor Startup" width="1200" height="600">
</picture>
```

Browser akan mengevaluasi kueri media dari atas ke bawah dan hanya mengunduh satu berkas gambar yang paling cocok dengan layar pengguna, menghemat konsumsi kuota data secara signifikan.
