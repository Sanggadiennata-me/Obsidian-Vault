## Pengiriman Data Formulir ke Server

Ketika pengguna menekan tombol kirim pada formulir, terjadi proses komunikasi klien-server (*client-server communication*). Browser mengemas seluruh data yang diisi pengguna, lalu mengirimkannya melalui protokol HTTP ke alamat server tujuan.

Untuk mengelola pengiriman data ini, seluruh kolom masukan harus dibungkus di dalam elemen `<form>`.

```html
<form action="/api/daftar" method="POST" enctype="multipart/form-data">
  <!-- Kolom-kolom masukan data formulir -->
  <button type="submit">Kirim Pendaftaran</button>
</form>
```

Tiga atribut utama pada elemen `<form>`:
1. `action`: Alamat URL tujuan (titik akhir / *endpoint* server) ke mana data formulir akan dikirimkan.
2. `method`: Metode transmisi HTTP yang digunakan (`GET` atau `POST`).
3. `enctype`: Format pengkodean data yang dikirim (*encoding type*).

## 1. Peran Wajib Atribut `name`

Data formulir dikirimkan ke server dalam format pasangan **Kunci dan Nilai (*Key-Value Pairs*)**.

Peramban menggunakan nilai dari atribut `name` pada masing-masing kolom input sebagai *Key*, dan data yang diketikkan pengguna sebagai *Value*.

```html
<input type="text" name="namaLengkap" value="Sangga">
<input type="email" name="userEmail" value="sangga@example.com">
```
Data yang terkirim ke server akan dibaca sebagai:
- `namaLengkap`: "Sangga"
- `userEmail`: "sangga@example.com"

> [!CAUTION]
> Kolom input yang **tidak memiliki atribut `name` tidak akan pernah dikirimkan ke server oleh peramban**, meskipun kolom tersebut telah diisi lengkap oleh pengguna!

## 2. Perbedaan Metode HTTP: GET vs POST

Pemilihan metode pengiriman pada atribut `method` sangat menentukan keamanan dan kinerja aplikasi:

### Metode `GET`
- Data formulir ditempelkan langsung di bilah alamat URL peramban sebagai parameter kueri (*query string*).
- Format URL hasil submit: `https://example.com/cari?keyword=belajar+html&kategori=coding`
- **Karakteristik**:
  - URL dapat disimpan ke bookmark, disalin, dan dibagikan kepada orang lain.
  - Memiliki batas panjang karakter (biasanya sekitar 2.048 karakter tergantung browser).
  - Data terlihat telanjang di bilah URL dan terekam dalam riwayat peramban (*browser history*).
- **Rekomendasi**: Gunakan `GET` hanya untuk formulir pencarian (*search bar*) atau filter data, di mana pengiriman form tidak mengubah keadaan data di database server (*idempotent*).

### Metode `POST`
- Data formulir dikemas di dalam badan permintaan (*HTTP request body*).
- Data **tidak terlihat** pada bilah URL peramban.
- **Karakteristik**:
  - Tidak memiliki batasan panjang karakter seketat GET.
  - Aman untuk membawa data sensitif seperti password, nomor kartu kredit, atau file biner.
  - Tidak dapat disimpan ke bookmark peramban.
- **Rekomendasi**: Gunakan `POST` untuk formulir pendaftaran, login, transaksi pembayaran, pembuatan artikel, atau pengunggahan berkas.

## 3. Tipe Pengkodean Berkas: Atribut `enctype`

Jika formulir Anda memiliki kolom input berkas (`<input type="file">`), Anda **wajib** menambahkan atribut:
```html
<form action="/upload" method="POST" enctype="multipart/form-data">
  <input type="file" name="fotoProfil">
  <button type="submit">Unggah Foto</button>
</form>
```

Tipe `enctype`:
- `application/x-www-form-urlencoded` (*default*): Mengubah teks menjadi format URL ter-encode (spasi menjadi `+` atau `%20`). Cocok untuk form teks biasa tanpa file.
- `multipart/form-data`: Memecah data formulir menjadi bagian-bagian biner terpisah. Format ini mutlak diperlukan agar server dapat menerima unggahan berkas foto, PDF, atau dokumen.

## 4. Validasi Klien Bawaan HTML5 (Constraint Validation)

Sebelum era HTML5, memastikan pengguna mengisi data dengan benar harus dilakukan menggunakan skrip JavaScript panjang. Kini, peramban modern menyediakan mesin validasi bawaan melalui serangkaian atribut deklaratif:

### a. Wajib Diisi: `required`
Mencegah formulir terkirim jika kolom masih dalam keadaan kosong. Browser akan memunculkan gelembung tooltip peringatan otomatis: *"Harap isi bidang ini"*.
```html
<input type="text" name="username" required>
```

### b. Batasan Panjang Karakter: `minlength` dan `maxlength`
Menentukan batas minimal dan maksimal jumlah huruf yang harus dimasukkan:
```html
<!-- Password minimal 8 karakter, maksimal 32 karakter -->
<input type="password" name="password" minlength="8" maxlength="32" required>
```

### c. Batasan Nilai Numerik dan Tanggal: `min`, `max`, dan `step`
Menentukan batas angka minimal, maksimal, serta kelipatan interval:
```html
<!-- Hanya menerima usia antara 18 hingga 65 tahun -->
<input type="number" name="usia" min="18" max="65" step="1">

<!-- Input tanggal pemesanan hotel minimal hari ini -->
<input type="date" name="checkIn" min="2026-11-03">
```

### d. Validasi Pola Regex: Atribut `pattern`
Memvalidasi masukan menggunakan pola ekspresi reguler (*Regular Expression*):
```html
<!-- Contoh validasi nomor telepon Indonesia diawali 08, panjang 10-13 digit -->
<input 
  type="tel" 
  name="telepon" 
  pattern="^08[0-9]{8,11}$" 
  title="Nomor telepon harus diawali 08 dan berjumlah 10 hingga 13 digit angka"
  required
>
```

### Menonaktifkan Validasi: Atribut `novalidate`
Jika Anda sedang menguji formulir di lingkungan pengembangan atau ingin validasi ditangani sepenuhnya oleh pustaka JavaScript kustom, tambahkan atribut `novalidate` pada tag `<form>`:
```html
<form action="/submit" method="POST" novalidate>
```

## 5. Jenis-Jenis Tombol dalam Formulir

Di dalam formulir, elemen `<button>` memiliki 3 tipe perilaku melalui atribut `type`:

1. `<button type="submit">Kirim</button>` (*default*): Memeriksa validasi formulir dan mengirimkan data ke URL `action`.
2. `<button type="reset">Reset</button>`: Mengosongkan dan mengembalikan seluruh isian form ke nilai awalnya (*gunakan dengan hati-hati agar pengguna tidak kehilangan ketikan secara tidak sengaja*).
3. `<button type="button">Klik Aksi</button>`: Tombol netral yang tidak melakukan submit. Sangat berguna untuk dihubungkan dengan fungsi JavaScript interaktif (seperti membuka modal atau menghitung kalkulasi).
