## Tipe-Tipe List dalam HTML

Dalam menyajikan informasi di web, daftar berbutir atau berurut mempermudah pembaca dalam mencerna poin-poin penting. HTML menyediakan 3 tipe elemen daftar:

1. **Unordered List (`<ul>`)**: Daftar tanpa urutan angka, menggunakan penanda butir (*bullet*).
2. **Ordered List (`<ol>`)**: Daftar berurutan numerik atau alfabetis.
3. **Description List (`<dl>`)**: Daftar pasangan istilah dan deskripsinya (*key-value*).

## 1. Unordered List (`<ul>`)

Unordered list digunakan saat urutan antar item tidak memiliki signifikansi hierarki (misalnya: daftar bahan masakan, daftar fitur produk, atau menu navigasi).

Elemen induk menggunakan `<ul>`, sedangkan setiap butir item di dalamnya dibungkus dengan tag `<li>` (*List Item*).

```html
<ul>
  <li>HTML5 Semantic Elements</li>
  <li>CSS Flexbox dan Grid</li>
  <li>JavaScript Dasar</li>
  <li>Version Control Git</li>
</ul>
```

Tampilan bawaan browser:
- HTML5 Semantic Elements
- CSS Flexbox dan Grid
- JavaScript Dasar
- Version Control Git

### Nested List (Daftar Bersarang)
Anda dapat menyisipkan elemen `<ul>` atau `<ol>` lain di dalam tag `<li>` untuk membuat daftar bertingkat (*nested list*):

```html
<ul>
  <li>Frontend Web
    <ul>
      <li>HTML5</li>
      <li>CSS3</li>
      <li>JavaScript Modern</li>
    </ul>
  </li>
  <li>Backend Web
    <ul>
      <li>Node.js</li>
      <li>Python</li>
      <li>PostgreSQL</li>
    </ul>
  </li>
</ul>
```

## 2. Ordered List (`<ol>`)

Ordered list digunakan ketika urutan langkah atau tahapan sangatlah penting (misalnya: instruksi resep masakan, alur registrasi, atau peringkat kejuaraan).

```html
<ol>
  <li>Unduh dan instal Visual Studio Code.</li>
  <li>Buat berkas baru bernama <code>index.html</code>.</li>
  <li>Tulis kerangka dasar dokumen HTML5.</li>
  <li>Buka berkas tersebut di peramban web.</li>
</ol>
```

Browser secara otomatis menghitung nomor urut secara berurutan:
1. Unduh dan instal Visual Studio Code.
2. Buat berkas baru bernama `index.html`.
3. Tulis kerangka dasar dokumen HTML5.
4. Buka berkas tersebut di peramban web.

### Mengubah Tipe Penomoran: Atribut `type`
Anda dapat mengganti format angka default menjadi huruf atau angka romawi melalui atribut `type`:

| Nilai | Contoh Tampilan | Keterangan |
| :--- | :--- | :--- |
| `1` | 1, 2, 3 | Angka desimal (*default*) |
| `a` | a, b, c | Huruf alfabet kecil |
| `A` | A, B, C | Huruf alfabet besar |
| `i` | i, ii, iii | Angka romawi kecil |
| `I` | I, II, III | Angka romawi besar |

```html
<ol type="A">
  <li>Bab Pertama: Fondasi Web</li>
  <li>Bab Kedua: Tata Letak Visual</li>
  <li>Bab Ketiga: Interaktivitas Logika</li>
</ol>
```

### Menentukan Angka Awal: Atribut `start`
Jika daftar Anda merupakan lanjutan dari halaman sebelumnya, gunakan atribut `start` untuk menentukan angka awal:

```html
<ol start="5">
  <li>Langkah kelima</li>
  <li>Langkah keenam</li>
  <li>Langkah ketujuh</li>
</ol>
```
Output penomoran akan dimulai dari angka 5, 6, 7.

### Urutan Terbalik: Atribut `reversed`
Atribut *boolean* `reversed` membalikkan urutan hitungan mundur:

```html
<ol start="3" reversed>
  <li>Juara 3: Medali Perunggu</li>
  <li>Juara 2: Medali Perak</li>
  <li>Juara 1: Medali Emas</li>
</ol>
```
Output penomoran akan berhitung mundur dari 3, 2, 1.

## 3. Description List (`<dl>`)

Description list (daftar deskripsi) sangat ideal untuk menyajikan daftar glosarium istilah teknis, pertanyaan umum (FAQ), atau spesifikasi metadata produk (*key-value pairs*).

Elemen ini tersusun dari 3 tag:
- `<dl>`: Pembungkus utama (*Description List*).
- `<dt>`: Istilah atau nama kunci yang didefinisikan (*Description Term*).
- `<dd>`: Penjelasan atau rincian dari istilah tersebut (*Description Details*).

```html
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language, bahasa standar perancangan struktur halaman web.</dd>

  <dt>CSS</dt>
  <dd>Cascading Style Sheets, bahasa untuk mendesain gaya visual dan tata letak dokumen web.</dd>

  <dt>JavaScript</dt>
  <dd>Bahasa pemrograman dinamis yang memungkinkan interaktivitas tingkat tinggi di sisi browser.</dd>
</dl>
```

Satu istilah `<dt>` juga dapat memiliki beberapa keterangan `<dd>` jika diperlukan, atau sebaliknya beberapa istilah memiliki satu keterangan yang sama.
