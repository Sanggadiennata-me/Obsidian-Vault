## Pengenalan Formulir dan Input Pengguna

Formulir (*form*) adalah pintu gerbang utama interaksi dua arah antara pengguna dan aplikasi web. Melalui formulir, pengguna dapat mendaftar akun, login, mengirim pesan kontak, membeli barang di e-commerce, hingga mengunggah dokumen.

HTML menyediakan serangkaian elemen masukan data (*form controls*) yang sangat lengkap, fleksibel, dan didukung fitur validasi otomatis oleh peramban.

## 1. Elemen Masukan Utama: `<input>`

Elemen `<input>` adalah elemen kosong (*void element*) paling serbaguna dalam HTML. Perilakunya ditentukan sepenuhnya oleh atribut `type`.

```html
<input type="text" name="nama" id="nama">
```

Berikut adalah daftar tipe masukan `<input>` yang paling sering digunakan dalam pengembangan web modern:

| Tipe Masukan | Deskripsi dan Karakteristik |
| :--- | :--- |
| `type="text"` | Masukan teks standar satu baris (*default jika atribut type tidak ditulis*). |
| `type="email"` | Kolom khusus alamat email. Peramban otomatis memvalidasi format tanda `@` dan nama domain. |
| `type="password"` | Karakter yang diketik otomatis disamarkan (*masked*) dengan titik hitam atau bintang demi keamanan. |
| `type="number"` | Hanya menerima angka numerik. Dilengkapi tombol panah atas/bawah (*spinner*). |
| `type="tel"` | Khusus nomor telepon. Menampilkan keyboard numerik pada layar smartphone. |
| `type="url"` | Masukan tautan alamat web. Memvalidasi protokol URL yang benar (`http://` atau `https://`). |
| `type="search"` | Masukan pencarian kata kunci. Dilengkapi tombol silang (✕) otomatis untuk menghapus teks cepat. |
| `type="date"` | Pemilih tanggal kalender natif peramban (format baku: YYYY-MM-DD). |
| `type="time"` | Pemilih waktu jam dan menit. |
| `type="checkbox"` | Kotak centang pilihan majemuk (*bisa memilih lebih dari satu opsi atau kondisi benar/salah*). |
| `type="radio"` | Tombol opsi tunggal (*hanya bisa memilih satu dari sekumpulan pilihan yang memiliki `name` sama*). |
| `type="file"` | Tombol untuk memilih dan mengunggah satu atau beberapa berkas dari komputer/HP. |
| `type="range"` | Penggeser nilai angka (*slider*) dalam rentang minimal dan maksimal. |
| `type="color"` | Palet pemilih warna interaktif (*color picker*) yang menghasilkan kode hexadesimal (misal: `#ff0000`). |
| `type="hidden"` | Masukan tersembunyi yang tidak tampak di layar, berguna untuk menyimpan token sesi atau ID database. |

## 2. Elemen `<label>`: Aksesibilitas dan Interaksi Pengguna

Setiap kolom input **wajib** dipasangkan dengan elemen `<label>`.

Manfaat krusial elemen `<label>`:
1. **Aksesibilitas (A11y)**: Perangkat screen reader akan membacakan teks label saat pengguna tuna netra berpindah fokus ke kolom input terkait.
2. **Kenyamanan Klik**: Pengguna dapat mengklik teks label untuk langsung memfokuskan kursor ke dalam kolom input atau mencentang kotak *checkbox*.

### Cara Menghubungkan Label dengan Input:
Gunakan atribut `for` pada label yang bernilai sama persis dengan atribut `id` pada elemen input terkait:

```html
<div>
  <label for="user-email">Alamat Email Resmi:</label>
  <input type="email" id="user-email" name="email" placeholder="nama@perusahaan.com" required>
</div>

<div>
  <label for="user-pass">Kata Sandi Akun:</label>
  <input type="password" id="user-pass" name="password" required>
</div>
```

> [!WARNING]
> **Atribut Placeholder Bukan Pengganti Label!**
> Atribut `placeholder` hanya berfungsi sebagai contoh isian samar (hint). Jangan pernah menggunakan placeholder sebagai pengganti `<label>`, karena teks placeholder akan lenyap begitu pengguna mulai mengetik, menyulitkan pengguna mengingat apa yang sedang mereka isi.

## 3. Pilihan Kotak Centang (Checkbox) dan Tombol Radio (Radio Button)

### Kotak Centang (`type="checkbox"`)
Digunakan saat pengguna diperbolehkan memilih beberapa pilihan sekaligus:
```html
<fieldset>
  <legend>Bahasa Pemrograman yang Dikuasai:</legend>
  
  <input type="checkbox" id="lang-html" name="skills" value="html">
  <label for="lang-html">HTML5</label><br>

  <input type="checkbox" id="lang-css" name="skills" value="css">
  <label for="lang-css">CSS3</label><br>

  <input type="checkbox" id="lang-js" name="skills" value="javascript">
  <label for="lang-js">JavaScript</label>
</fieldset>
```

### Tombol Radio (`type="radio"`)
Digunakan saat pengguna **hanya boleh memilih satu** dari sekumpulan pilihan eksklusif. Kunci utamanya adalah memberikan **nilai atribut `name` yang sama** pada seluruh grup tombol radio tersebut:

```html
<fieldset>
  <legend>Pilih Metode Pengiriman:</legend>

  <input type="radio" id="kirim-reg" name="pengiriman" value="reguler" checked>
  <label for="kirim-reg">Reguler (2-3 Hari)</label><br>

  <input type="radio" id="kirim-exp" name="pengiriman" value="express">
  <label for="kirim-exp">Express (1 Hari)</label><br>

  <input type="radio" id="kirim-ins" name="pengiriman" value="instant">
  <label for="kirim-ins">Instant (3 Jam)</label>
</fieldset>
```

## 4. Masukan Teks Multi-Baris: `<textarea>`

Jika Anda membutuhkan kolom isian teks panjang yang terdiri dari beberapa baris (seperti pesan kontak, alamat lengkap, atau catatan artikel), gunakan tag `<textarea>`.

```html
<label for="pesan">Pesan atau Masukan Anda:</label><br>
<textarea 
  id="pesan" 
  name="pesan" 
  rows="5" 
  cols="40" 
  placeholder="Tuliskan detail pertanyaan Anda di sini..."
></textarea>
```

- `rows`: Menentukan tinggi visual kolom berdasarkan jumlah baris teks.
- `cols`: Menentukan lebar visual kolom berdasarkan jumlah karakter rata-rata.

## 5. Menu Pilihan Dropdown: `<select>`, `<optgroup>`, dan `<option>`

Untuk menghemat ruang di layar, pilihan opsi dapat disajikan dalam menu tarik-turun (*dropdown list*):

```html
<label for="kota">Pilih Kota Asal:</label>
<select id="kota" name="kota">
  <option value="">-- Pilih Kota --</option>
  
  <optgroup label="Jawa Barat">
    <option value="bdg">Bandung</option>
    <option value="bgr">Bogor</option>
    <option value="bks">Bekasi</option>
  </optgroup>
  
  <optgroup label="Jawa Tengah">
    <option value="smg">Semarang</option>
    <option value="slo">Solo</option>
  </optgroup>
</select>
```

Elemen `<optgroup>` mengelompokkan opsi-opsi berelasi dengan judul kategori abu-abu yang rapi.

## 6. Fitur Rekomendasi Pintar: Elemen `<datalist>`

Elemen `<datalist>` menyediakan fitur pelengkapan otomatis (*autocomplete suggestion*) saat pengguna mengetik, namun tetap memberikan kebebasan jika pengguna ingin mengetikkan nilai baru yang tidak ada di dalam daftar rekomendasi:

```html
<label for="framework">Pilih Framework CSS Favorit:</label>
<input list="daftar-framework" id="framework" name="framework" placeholder="Ketik untuk mencari...">

<datalist id="daftar-framework">
  <option value="Tailwind CSS">
  <option value="Bootstrap">
  <option value="Bulma CSS">
  <option value="Semantic UI">
</datalist>
```

Hubungkan kolom `<input>` dengan `<datalist>` melalui atribut `list` pada input yang bernilai sama dengan `id` milik datalist.

## 7. Pengelompokan Logis: `<fieldset>` dan `<legend>`

Pada formulir yang panjang dan kompleks, kelompokkan bagian-bagian formulir yang sejenis menggunakan tag `<fieldset>` dan beri judul bingkai menggunakan tag `<legend>`.

```html
<fieldset>
  <legend>Informasi Akun Pribadi</legend>
  <!-- Kolom-kolom input nama, email, password -->
</fieldset>

<fieldset>
  <legend>Alamat Pengiriman Tagihan</legend>
  <!-- Kolom-kolom input jalan, kota, kode pos -->
</fieldset>
```
