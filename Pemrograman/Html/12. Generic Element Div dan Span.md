## Konsep Elemen Generik dalam HTML

Dalam dunia nyata, jenis informasi pada website sangat beraneka ragam. Meskipun HTML menyediakan puluhan tag semantik, terkadang kita membutuhkan wadah murni tanpa makna semantik bawaan untuk keperluan pembungkus tata letak (*layout wrapper*) atau pengait penataan gaya (*styling hook* CSS).

Untuk kebutuhan tersebut, HTML menyediakan dua elemen generik:
1. **`<div>` (*Division*)**: Elemen generik tingkat blok (*block-level container*).
2. **`<span>`**: Elemen generik tingkat baris (*inline container*).

Kedua elemen ini murni merupakan "kanvas kosong" yang tidak memberikan arti semantik apa pun dan tidak mengubah tampilan visual secara bawaan sebelum diberi aturan CSS.

## 1. Wadah Blok: Elemen `<div>`

Elemen `<div>` digunakan untuk mengelompokkan sekumpulan elemen menjadi satu blok kesatuan. Elemen ini selalu dimulai pada baris baru dan mengambil lebar 100% dari induknya secara default.

Penggunaan paling umum dari `<div>` adalah sebagai wadah pembungkus yang diberi atribut `class` atau `id` untuk ditata menggunakan CSS:

```html
<div class="card-profil">
  <h3>Sangga Diennata</h3>
  <p>Software Engineer dan Pengembang Web.</p>
</div>
```

```css
.card-profil {
  width: 280px;
  border: 1px solid #333;
  box-shadow: 8px 8px 5px #444;
  padding: 16px;
  border-radius: 8px;
  background-image: linear-gradient(180deg, #fff, #ddd 40%, #ccc);
}
```

## 2. Wadah Sebaris: Elemen `<span>`

Berbeda dengan `<div>` yang menciptakan blok baru, elemen `<span>` adalah wadah *inline*. Elemen ini digunakan untuk membungkus sepenggal kata atau teks di tengah-tengah kalimat tanpa merusak alur paragraf.

Elemen `<span>` sangat bermanfaat ketika Anda ingin mewarnai kata tertentu atau memberi tanda khusus pada potongan teks:

```html
<style>
  .sorotan-merah {
    color: red;
    font-weight: bold;
  }
</style>

<p>
  Untuk membuat kuah bakso yang lezat, siapkan <span class="sorotan-merah">daging sapi</span> pilihan, 
  bawang merah, dan <span class="sorotan-merah">bawang putih</span> goreng.
</p>
```

Tampilan yang dihasilkan:

![Elemen Span](Image/Span2.png)

Contoh lain, menandai nomor telepon untuk styling khusus:

```html
<ul>
  <li>Agil: <span class="phone">08123xxx</span></li>
  <li>Widy: <span class="phone">08222xxx</span></li>
  <li>Gilang: <span class="phone">08333xxx</span></li>
</ul>
```

```css
.phone {
  font-weight: bold;
}
```

## Bahaya "Div Soup" (Divitis)

Banyak pemula yang membuat seluruh halaman web hanya menggunakan tag `<div>` bersarang puluhan tingkat (disebut *Divitis* atau *Div Soup*):

```html
<!-- CONTOH BURUK (Div Soup / Tidak Semantik) -->
<div class="header">
  <div class="navigasi">
    <div class="link">Beranda</div>
  </div>
</div>
<div class="konten-utama">
  <div class="judul-artikel">Judul Berita</div>
  <div class="paragraf">Isi artikel...</div>
</div>
<div class="footer">
  <div class="hak-cipta">Hak Cipta 2026</div>
</div>
```

Masalah dengan kode di atas:
1. **Mesin pencari (Google)** tidak tahu mana menu navigasi dan mana konten berita utama.
2. **Perangkat tuna netra (Screen Reader)** tidak dapat membantu pengguna melompat ke bagian penting halaman.
3. Kode menjadi sulit dibaca dan dirawat oleh tim pengembang.

> [!TIP]
> **Pedoman Praktik Terbaik**:
> Gunakan `<div>` dan `<span>` sebagai **pilihan terakhir** ketika tidak ada elemen semantik HTML5 yang cocok untuk tujuan tersebut (misalnya murni hanya untuk pembungkus grid flexbox CSS).
> Jika ada tag semantik yang sesuai (seperti `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`), selalu prioritaskan tag semantik tersebut!
