### Proyek Praktek Langsung (Hands-on Labs):
Setiap proyek dilengkapi berkas `index.html` dan `styles.css` yang siap dibuka langsung di browser untuk latihan mandiri:

1. [Praktek 01: Profile Card Modern](praktek/01-profile-card/index.html) : Latihan Box Model, Border-radius, Box-shadow bertingkat, dan Avatar.
2. [Praktek 02: Navbar & Dropdown Menu](praktek/02-navbar-dropdown/index.html) : Latihan Fixed Navbar, pola Parent Relative + Child Absolute, dan menu dropdown interaktif.
3. [Praktek 03: Flexbox Dashboard Cards](praktek/03-flexbox-dashboard-cards/index.html) : Latihan menyusun kartu dashboard statistik responsif dengan `display: flex`, `gap`, dan `flex-wrap`.
4. [Praktek 04: Modern Pricing Table](praktek/04-pricing-table/index.html) : Latihan kartu perbandingan harga dengan ribbon badge melayang, hover elevation, dan tombol kapsul.
