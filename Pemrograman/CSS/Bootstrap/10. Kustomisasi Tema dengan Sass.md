#programming 

Banyak pemula mengubah tampilan Bootstrap dengan cara menulis file CSS terpisah lalu menimpanya menggunakan selector panjang atau jalan pintas buruk seperti `!important`. Cara profesional yang resmi dan paling bersih adalah mengustomisasi Bootstrap langsung dari akarnya menggunakan **Sass (SCSS)**.

---

## 1. Mengapa Menggunakan Sass?

* **Mengubah Warna Utama di Seluruh Komponen Sekaligus**:
  Cukup mengganti satu variabel `$primary: #6366f1;`, maka warna tombol, link, navbar, fokus ring formulir, dan badge di seluruh proyek otomatis berubah serentak.
* **Ukuran Berkas Lebih Ramping (*Tree-Shaking*)**:
  Anda hanya mengimpor komponen yang benar-benar Anda pakai. Jika website Anda tidak menggunakan Carousel atau Accordion, Anda bisa menghapus import komponen tersebut dari kompilasi Sass.

---

## 2. Struktur Alur Kerja Kustomisasi SCSS

### Langkah 1: Pasang Kompiler Sass
```bash
npm install -D sass bootstrap
```

### Langkah 2: Buat Berkas `src/custom.scss`
Aturan emas kustomisasi Bootstrap: **Ubah variabel Sass terlebih dahulu SEBELUM mengimpor berkas inti Bootstrap**:

```scss
// 1. Definisikan atau Timpa Variabel Bawaan Bootstrap Terlebih Dahulu
$primary: #4f46e5;        // Mengganti biru default dengan warna Indigo modern
$secondary: #64748b;      // Mengganti abu-abu dengan warna Slate
$border-radius: 0.75rem;   // Mengubah lengkungan tombol dan kartu menjadi lebih bulat (12px)
$enable-shadows: true;     // Otomatis mengaktifkan bayangan halus di semua tombol

// 2. Tambahkan Warna Baru ke Sistem Tema (*Theme Colors Map*)
$custom-colors: (
  "brand": #0ea5e9,
  "dark-card": #1e293b
);

// 3. Impor Inti Bootstrap untuk Menggabungkan Variabel Baru
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/variables-dark";
@import "bootstrap/scss/maps";

// Gabungkan warna kustom Anda dengan warna bawaan Bootstrap
$theme-colors: map-merge($theme-colors, $custom-colors);

// 4. Impor Seluruh Gaya dan Utilitas Bootstrap
@import "bootstrap/scss/utilities";
@import "bootstrap/scss/bootstrap";
```

### Langkah 3: Kompilasi SCSS Menjadi Berkas CSS Biasa
Jalankan perintah kompilasi di terminal:

```bash
npx sass src/custom.scss dist/custom.css --style=compressed
```

Sekarang Anda memiliki berkas `custom.css` produksi yang telah menggunakan warna identitas merek Anda sendiri tanpa konflik spesifisitas. Anda bahkan dapat memanggil class baru hasil buatan Anda sendiri: `.btn-brand` atau `.bg-dark-card`!

---

## 3. Utilitas API Bootstrap 5 (*The Utility API*)

Bootstrap 5 memiliki sistem Utility API canggih yang memungkinkan Anda mendaftarkan class utilitas baru langsung melalui map Sass `$utilities`.

Misalnya, untuk menambahkan utilitas kursor pointer baru:
```scss
@import "bootstrap/scss/utilities";

$utilities: map-merge(
  $utilities,
  (
    "cursor": (
      property: cursor,
      class: cursor,
      responsive: true,
      values: auto pointer wait not-allowed,
    )
  )
);
```
Setelah dikompilasi, Anda langsung bisa menggunakan class seperti `class="cursor-pointer"` atau `class="cursor-not-allowed"` di HTML.
