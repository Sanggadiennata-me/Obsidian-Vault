#programming 

Carousel dan Accordion adalah dua komponen interaktif yang sangat sering ditemui pada halaman muka website bisnis untuk menampilkan banner promo dinamis dan daftar pertanyaan umum (FAQ).

---

## 1. Tayangan Gambar Geser Otomatis (Carousel)

Komponen Carousel Bootstrap mendukung putaran otomatis, indikator titik di bagian bawah, teks keterangan (*caption*), dan tombol navigasi kiri-kanan.

```html
<div id="heroCarousel" class="carousel slide" data-bs-ride="carousel">
  <!-- Indikator Titik di Bagian Bawah -->
  <div class="carousel-indicators">
    <button type="button" data-bs-target="#heroCarousel" data-bs-slide-to="0" class="active"></button>
    <button type="button" data-bs-target="#heroCarousel" data-bs-slide-to="1"></button>
  </div>

  <!-- Wadah Gambar Slide -->
  <div class="carousel-inner rounded-4 shadow overflow-hidden">
    <!-- Slide 1 (Wajib Ada Class "active" pada Slide Pertama) -->
    <div class="carousel-item active" data-bs-interval="4000">
      <img src="banner-promo1.jpg" class="d-block w-100" alt="Promo 1">
      <div class="carousel-caption d-none d-md-block bg-dark/50 p-3 rounded-3">
        <h5>Promo Akhir Pekan</h5>
        <p>Diskon hingga 50% untuk seluruh paket langganan cloud.</p>
      </div>
    </div>

    <!-- Slide 2 -->
    <div class="carousel-item" data-bs-interval="4000">
      <img src="banner-promo2.jpg" class="d-block w-100" alt="Promo 2">
      <div class="carousel-caption d-none d-md-block bg-dark/50 p-3 rounded-3">
        <h5>Infrastruktur Stabil</h5>
        <p>Jaminan keamanan data tingkat enterprise bersertifikat internasional.</p>
      </div>
    </div>
  </div>

  <!-- Tombol Panah Kiri dan Kanan -->
  <button class="carousel-control-prev" type="button" data-bs-target="#heroCarousel" data-bs-slide="prev">
    <span class="carousel-control-prev-icon"></span>
  </button>
  <button class="carousel-control-next" type="button" data-bs-target="#heroCarousel" data-bs-slide="next">
    <span class="carousel-control-next-icon"></span>
  </button>
</div>
```

## 2. Daftar Lipat Tanya Jawab (Accordion)

Accordion memungkinkan pengguna membuka dan menutup bagian teks secara bergantian. Sangat ideal untuk halaman FAQ (*Frequently Asked Questions*) agar halaman tidak terlalu panjang.

```html
<div class="accordion shadow-sm rounded-3 overflow-hidden" id="faqAccordion">
  <!-- Item 1 (Terbuka Secara Default) -->
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button fw-semibold" type="button" data-bs-toggle="collapse" data-bs-target="#faq1">
        Berapa lama proses aktivasi layanan?
      </button>
    </h2>
    <!-- Class "show" Menandakan Panel Terbuka -->
    <div id="faq1" class="accordion-collapse collapse show" data-bs-parent="#faqAccordion">
      <div class="accordion-body text-secondary small">
        Layanan cloud dan server akan aktif secara instan dalam kurun waktu 5 menit setelah pembayaran berhasil dikonfirmasi oleh sistem.
      </div>
    </div>
  </div>

  <!-- Item 2 -->
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button collapsed fw-semibold" type="button" data-bs-toggle="collapse" data-bs-target="#faq2">
        Apakah tersedia garansi pengembalian dana?
      </button>
    </h2>
    <div id="faq2" class="accordion-collapse collapse" data-bs-parent="#faqAccordion">
      <div class="accordion-body text-secondary small">
        Kami memberikan jaminan uang kembali 30 hari penuh tanpa syarat jika Anda merasa performa layanan kami tidak memenuhi ekspektasi Anda.
      </div>
    </div>
  </div>
</div>
```

### Variasi Accordion:
* **`accordion-flush`** : Menghapus garis tepi luar dan sudut melengkung pada accordion agar tepi sisi kiri dan kanannya menyatu rata (*edge-to-edge*) dengan container pembungkus.
* **`data-bs-parent="#id"`** : Memastikan bahwa saat pengguna membuka panel baru, panel lama yang sedang terbuka akan otomatis tertutup sendiri. Hapus atribut ini jika Anda ingin pengguna bisa membuka banyak panel sekaligus.
