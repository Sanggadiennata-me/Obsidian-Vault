#programming 

Bootstrap 5 menyediakan sistem penataan formulir yang bersih, mudah diakses melalui keyboard, dan mendukung validasi visual yang responsif.

---

## 1. Elemen Input Standar (*Form Controls*)

Gunakan class `.form-control` pada tag `<input>` atau `<textarea>` agar input memiliki padding proporsional, border lembut, dan fokus ring berwarna biru:

```html
<div class="mb-3">
  <label for="inputEmail" class="form-label fw-semibold small">Alamat Email</label>
  <input type="email" class="form-control rounded-3" id="inputEmail" placeholder="nama@domain.com">
  <div class="form-text text-secondary">Kami tidak akan membagikan email Anda kepada pihak ketiga.</div>
</div>
```

---

## 2. Label Melayang Modern (*Floating Labels*)

Bootstrap 5 memperkenalkan fitur *Floating Labels* tanpa membutuhkan pustaka luar. Cukup bungkus input dan label di dalam container ber-class `.form-floating`:

```html
<div class="form-floating mb-3">
  <!-- Wajib sertakan atribut placeholder meskipun kosong -->
  <input type="email" class="form-control" id="floatingEmail" placeholder="nama@domain.com">
  <label for="floatingEmail">Ketikkan Alamat Email</label>
</div>
```
Saat input dalam keadaan kosong, teks label berada di tengah. Begitu pengguna mengklik atau mengetik teks, label otomatis melayang naik ke atas dengan ukuran huruf lebih kecil.

---

## 3. Gabungan Input dan Ikon (*Input Groups*)

Gunakan `.input-group` untuk menempelkan teks simbol mata uang, ikon, atau tombol langsung di samping kotak input:

```html
<!-- Input dengan Awalan Simbol Mata Uang -->
<div class="input-group mb-3">
  <span class="input-group-text bg-light text-secondary">Rp</span>
  <input type="number" class="form-control" placeholder="100000">
  <span class="input-group-text bg-light text-secondary">,00</span>
</div>

<!-- Input Pencarian Lengkap dengan Tombol Aksi -->
<div class="input-group">
  <input type="text" class="form-control" placeholder="Cari artikel...">
  <button class="btn btn-primary" type="button">Cari</button>
</div>
```

---

## 4. Kotak Centang, Radio, dan Saklar (*Switches*)

Gunakan `.form-check` untuk menjaga agar teks label sejajar sempurna dengan kotak centang:

```html
<!-- Checkbox Standar -->
<div class="form-check mb-2">
  <input class="form-check-input" type="checkbox" id="checkIngat">
  <label class="form-check-label" for="checkIngat">Ingat saya di perangkat ini</label>
</div>

<!-- Saklar Modern Bergaya Ponsel (*Toggle Switch*) -->
<div class="form-check form-switch mb-3">
  <input class="form-check-input" type="checkbox" role="switch" id="switchNotif" checked>
  <label class="form-check-label" for="switchNotif">Aktifkan notifikasi email</label>
</div>
```

## 5. Validasi Formulir Interaktif

Bootstrap menyediakan umpan balik warna hijau (*valid*) dan merah (*invalid*) yang sangat informatif:

```html
<form class="needs-validation" novalidate>
  <div class="mb-3">
    <label class="form-label">Nama Pengguna</label>
    <input type="text" class="form-control" required>
    
    <!-- Pesan Muncul Jika Validasi Berhasil -->
    <div class="valid-feedback">Format nama sudah sesuai!</div>
    
    <!-- Pesan Muncul Jika Kolom Masih Kosong -->
    <div class="invalid-feedback">Nama pengguna wajib diisi.</div>
  </div>

  <button class="btn btn-primary" type="submit">Kirim Formulir</button>
</form>

<script>
  // Skrip Standar Bootstrap untuk Mencegah Submit Jika Input Tidak Valid
  (() => {
    'use strict'
    const forms = document.querySelectorAll('.needs-validation')
    Array.from(forms).forEach(form => {
      form.addEventListener('submit', event => {
        if (!form.checkValidity()) {
          event.preventDefault()
          event.stopPropagation()
        }
        form.classList.add('was-validated')
      }, false)
    })
  })()
</script>
```
Saat form disubmit, class `.was-validated` ditambahkan ke form, otomatis menyalakan outline hijau atau merah pada masing-masing input.
