Membuat aplikasi web berskala besar menggunakan Bootstrap membutuhkan disiplin arsitektur agar kode CSS kustom tidak menjadi kusut dan komponen tetap mudah dirawat oleh seluruh anggota tim.

## 1. Menerapkan Dark Mode Modern di Bootstrap 5.3+

Di Bootstrap 5.3, Anda tidak perlu lagi merakit class gelap manual. Cukup ubah atribut `data-bs-theme` pada tag teratas `<html>`:

```html
<!-- Mengaktifkan Tema Gelap Penuh di Seluruh Halaman -->
<html lang="id" data-bs-theme="dark">
```

### Logika JavaScript Pengganti Tema Otomatis:
```javascript
// Fungsi Sederhana untuk Berganti Tema
function toggleBootstrapTheme() {
  const currentTheme = document.documentElement.getAttribute('data-bs-theme');
  const targetTheme = currentTheme === 'dark' ? 'light' : 'dark';
  
  document.documentElement.setAttribute('data-bs-theme', targetTheme);
  localStorage.setItem('theme', targetTheme);
}

// Pulihkan preferensi saat halaman dimuat
const savedTheme = localStorage.getItem('theme') || 'light';
document.documentElement.setAttribute('data-bs-theme', savedTheme);
```
Seluruh komponen kartu, tabel, input form, navbar, modal, dan dropdown otomatis menyesuaikan warna gelapnya secara presisi dan konsisten.

## 2. Aturan Emas Menulis CSS Tambahan (*Avoiding CSS Spaghetti*)

Banyak proyek Bootstrap menjadi berantakan karena developer mencampuradukkan penulisan CSS sembarangan. Terapkan prinsip berikut:

1. **Prioritaskan Utilitas Bawaan Dulu**:
   Jika Anda hanya ingin memberi jarak atau mengubah tebal teks, gunakan class bawaan Bootstrap (seperti `mb-4`, `p-3`, `fw-bold`) daripada membuat class baru di CSS.
2. **Jangan Pernah Menimpa Class Inti dengan `!important`**:
   Hindari menulis aturan seperti `.btn-primary { background: red !important; }`. Jika ingin warna merah, gunakan `.btn-danger` atau ubah variabel Sass resminya.
3. **Gunakan Konvensi BEM untuk Komponen Kustom**:
   Jika Anda membuat komponen yang belum ada di Bootstrap (misalnya kartu harga atau timeline riwayat transaksi), buat class kustom mandiri:
   ```html
   <div class="card timeline-card">
     <div class="timeline-card__step">...</div>
   </div>
   ```

## 3. Ekstraksi Komponen di Framework Modern (React / Blade)

Jika Anda menggunakan React, Next.js, atau Laravel Blade, bungkus kombinasi class Bootstrap ke dalam komponen modular:

```jsx
// components/AlertNotification.jsx
export function AlertNotification({ variant = 'info', title, message }) {
  return (
    <div className={`alert alert-${variant} alert-dismissible fade show border-0 shadow-sm rounded-3`} role="alert">
      <strong>{title}</strong> {message}
      <button type="button" className="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
    </div>
  );
}
```

## 4. Panduan Aksesibilitas (Accessibility Checklist)

Bootstrap dirancang agar ramah bagi pengguna pembaca layar (*screen reader*). Pastikan Anda selalu menyertakan atribut ARIA standar:
* **Tombol Silang**: Selalu beri `aria-label="Close"` pada tombol `.btn-close`.
* **Spanduk Alert**: Pastikan terdapat atribut `role="alert"`.
* **Modal Dialog**: Pastikan dialog memiliki atribut `tabindex="-1"` dan `aria-hidden="true"`.
* **Ikon Dekorasi**: Tambahkan atribut `aria-hidden="true"` pada tag ikon agar tidak dibaca sebagai teks acak oleh pembaca layar tunanetra.
