#programming 

Bootstrap menyediakan ratusan class utilitas serbaguna untuk mengatur tipografi, tema warna, dan spasi jarak (*spacing*) tanpa perlu menulis aturan CSS manual.

---

## 1. Tipografi (Typography)

### A. Judul Besar Panggung Utama (*Display Headings*)
Saat ukuran heading standar `<h1>` kurang mencolok untuk halaman muka (*Hero section*), gunakan class display yang memiliki ukuran masif dan proporsi garis huruf yang elegan:

```html
<h1 class="display-1 fw-bold">Display 1 (Paling Besar)</h1>
<h1 class="display-4 fw-semibold">Display 4 (Standar Hero Banner)</h1>
<h1 class="display-6">Display 6 (Ukuran Ringkas)</h1>
```

### B. Paragraf Pengantar (*Lead Paragraph*)
Tambahkan class `.lead` untuk membuat paragraf pembuka artikel terlihat sedikit lebih besar dan menonjol dibandingkan paragraf biasa di bawahnya:

```html
<p class="lead text-secondary">
  Paragraf pengantar yang memikat perhatian pembaca sebelum masuk ke detail artikel.
</p>
```

### C. Utilitas Perataan Teks (*Text Alignment*)
* `text-start` : Rata kiri (menggantikan istilah lama `text-left`).
* `text-center` : Rata tengah.
* `text-end` : Rata kanan (menggantikan istilah lama `text-right`).
* **Varian Responsif**: `text-center text-lg-start` (rata tengah di layar HP, otomatis rata kiri di layar laptop).

## 2. Palet Warna Tematik (*Theme Colors*)

Bootstrap menggunakan 8 warna semantik inti yang mewakili status atau fungsi tertentu:

* **`primary`** (Biru) : Aksi utama, tombol fokus, brand identity.
* **`secondary`** (Abu-abu) : Elemen pendukung sekunder, tombol netral.
* **`success`** (Hijau) : Transaksi berhasil, status online, konfirmasi aman.
* **`danger`** (Merah) : Peringatan error, tombol hapus data permanen.
* **`warning`** (Kuning/Oranye) : Peringatan hati-hati, status verifikasi tertunda.
* **`info`** (Biru Muda/Cyan) : Petunjuk informasi sistem, tips panduan.
* **`light`** (Abu-abu Terang) : Latar belakang terang.
* **`dark`** (Hitam Keabuan) : Latar belakang gelap, teks judul kontras tinggi.

### Warna Halus Modern (*Subtle Colors* di Bootstrap 5.3+)
Di era Bootstrap 5 modern, hindari warna pekat yang terlalu mencolok pada kotak kartu atau badge status. Gunakan varian *subtle*:

```html
<!-- Badge Status Modern Ber-opacity Rendah -->
<span class="badge bg-success-subtle text-success border border-success-subtle px-3 py-2 rounded-pill">
  Terverifikasi Aman
</span>

<div class="alert alert-warning-subtle text-warning-emphasis">
  Pemberitahuan dengan kontras teks yang nyaman di mata.
</div>
```

## 3. Utilitas Jarak (*Spacing Utilities: Margin & Padding*)

Rumus penamaan utilitas spasi Bootstrap:

```text
{property}{sides}-{size}
```

### Huruf Properti:
* `m` : Mengatur `margin`.
* `p` : Mengatur `padding`.

### Huruf Sisi (*Sides*):
* `t` : Top (atas)
* `b` : Bottom (bawah)
* `s` : Start (kiri pada mode LTR, menggantikan `l`)
* `e` : End (kanan pada mode LTR, menggantikan `r`)
* `x` : Horizontal (kiri dan kanan sekaligus)
* `y` : Vertikal (atas dan bawah sekaligus)
* *(tanpa huruf sisi)* : Mengatur keempat sisi sekaligus (contoh: `p-3`).

### Skala Ukuran (*Size*):
* `0` : Menghapus jarak menjadi `0px`.
* `1` : `0.25rem` (4px).
* `2` : `0.5rem` (8px).
* `3` : `1rem` (16px) - Paling sering digunakan.
* `4` : `1.5rem` (24px).
* `5` : `3rem` (48px) - Jarak besar untuk section.
* `auto` : Mengatur nilai `auto` (contoh: `mx-auto` untuk menengahkan container).

```html
<!-- Kartu dengan Padding 16px dan Jarak Bawah 24px -->
<div class="card p-3 mb-4 shadow-sm border-0">
  <div class="card-body">Konten yang tertata rapi.</div>
</div>
```
