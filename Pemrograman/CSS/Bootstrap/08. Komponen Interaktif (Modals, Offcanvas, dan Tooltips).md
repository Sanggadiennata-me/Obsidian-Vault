#programming 

Komponen interaktif di Bootstrap 5 bekerja menggunakan dua pendekatan fleksibel: pendekatan deklaratif tanpa JavaScript menggunakan atribut HTML `data-bs-*`, atau pendekatan terprogram (*programmatic*) menggunakan objek JavaScript `bootstrap.*`.

---

## 1. Jendela Dialog Pop-up (Modals)

Modal adalah jendela melayang di atas konten utama yang memblokir interaksi latar belakang hingga jendela tersebut ditutup.

```html
<!-- Tombol Pemicu Modal -->
<button type="button" class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#konfirmasiModal">
  Buka Modal Dialog
</button>

<!-- Struktur Kotak Modal -->
<div class="modal fade" id="konfirmasiModal" tabindex="-1" data-bs-backdrop="static">
  <div class="modal-dialog modal-dialog-centered">
    <div class="modal-content border-0 shadow-lg rounded-4">
      <div class="modal-header border-bottom">
        <h5 class="modal-title fw-bold">Konfirmasi Hapus Data</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body p-4">
        Apakah Anda yakin ingin menghapus data akun ini secara permanen? Tindakan ini tidak dapat dibatalkan.
      </div>
      <div class="modal-footer border-top bg-light rounded-bottom-4">
        <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Batal</button>
        <button type="button" class="btn btn-danger px-4">Ya, Hapus</button>
      </div>
    </div>
  </div>
</div>
```

### Variasi Opsi Modal:
* **`modal-dialog-centered`** : Menempatkan modal tepat di tengah layar secara vertikal.
* **`modal-dialog-scrollable`** : Jika teks sangat panjang (seperti syarat & ketentuan), hanya bagian body modal yang bisa di-scroll, sementara header dan tombol simpan tetap terlihat.
* **`data-bs-backdrop="static"`** : Mencegah modal tertutup saat pengguna tidak sengaja mengklik area gelap di luar kotak modal.
* **Ukuran**: `.modal-sm` (kecil), `.modal-lg` (lebar), `.modal-xl` (sangat lebar).

## 2. Laci Geser Samping (Offcanvas Drawer)

Komponen modern yang meluncur mulus dari pinggir layar. Sangat populer untuk keranjang belanja (*shopping cart*), menu navigasi samping di HP, atau panel filter toko online.

```html
<!-- Tombol Pembuka Offcanvas -->
<button class="btn btn-outline-primary" type="button" data-bs-toggle="offcanvas" data-bs-target="#offcanvasCart">
  Buka Keranjang Belanja
</button>

<!-- Wadah Offcanvas Meluncur dari Sisi Kanan (offcanvas-end) -->
<div class="offcanvas offcanvas-end" tabindex="-1" id="offcanvasCart">
  <div class="offcanvas-header border-bottom">
    <h5 class="offcanvas-title fw-bold">Keranjang Belanja (3 Item)</h5>
    <button type="button" class="btn-close" data-bs-dismiss="offcanvas"></button>
  </div>
  <div class="offcanvas-body">
    <p class="text-secondary small">Daftar barang yang siap di-checkout.</p>
    <div class="d-grid mt-4">
      <button class="btn btn-success">Lanjut ke Pembayaran</button>
    </div>
  </div>
</div>
```
Arah luncuran ditentukan oleh class posisi: `.offcanvas-start` (dari kiri), `.offcanvas-end` (dari kanan), `.offcanvas-top` (dari atas), atau `.offcanvas-bottom` (dari bawah).

## 3. Tooltips dan Popovers (Wajib Inisialisasi JavaScript)

Berbeda dengan Modal dan Offcanvas yang otomatis aktif lewat atribut HTML, komponen **Tooltip** dan **Popover** sengaja dibuat *opt-in* (tidak aktif otomatis) demi alasan performa memori.

### Langkah 1: Pasang Atribut HTML
```html
<button type="button" class="btn btn-secondary" data-bs-toggle="tooltip" data-bs-placement="top" title="Klik untuk menyalin tautan">
  Salin Tautan
</button>
```

### Langkah 2: Inisialisasi Script di Akhir Dokumen
```html
<script>
  // Aktifkan Semua Tooltip di Seluruh Halaman
  const tooltipTriggerList = document.querySelectorAll('[data-bs-toggle="tooltip"]')
  const tooltipList = [...tooltipTriggerList].map(el => new bootstrap.Tooltip(el))
</script>
```

## 4. Pengendalian Melalui JavaScript API Murni

Jika Anda ingin membuka modal setelah pemrosesan API berhasil atau setelah waktu tertentu (misal popup promosi):

```javascript
// Dapatkan instans objek modal
const myModal = new bootstrap.Modal(document.getElementById('konfirmasiModal'))

// Buka modal secara terprogram
myModal.show()

// Tutup modal secara terprogram
// myModal.hide()
```
