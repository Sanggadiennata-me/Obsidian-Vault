#roadmap 

### Bagian 1: Fundamental & Sistem Grid
1. [01. Pengenalan Bootstrap](01.%20Pengenalan%20Bootstrap.md) : Filosofi Component-First vs Utility-First, evolusi Bootstrap 5, dan penghapusan dependensi jQuery.
2. [02. Instalasi dan Setup](02.%20Instalasi%20dan%20Setup.md) : Integrasi via CDN bundle, package manager NPM, dan struktur Popper.js.
3. [03. Sistem Grid 12 Kolom](03.%20Sistem%20Grid%2012%20Kolom.md) : Container, Row, Col, breakpoint responsif, auto-layout, dan gutter celah `g-*`.

### Bagian 2: Tipografi, Utilitas, & Komponen Dasar
4. [04. Tipografi, Warna, dan Utilities](04.%20Tipografi,%20Warna,%20dan%20Utilities.md) : Display headings, lead text, palet warna tematik (subtle colors), dan utilitas spacing `m-*` / `p-*`.
5. [05. Komponen UI Esensial](05.%20Komponen%20UI%20Esensial.md) : Buttons, Badges, Cards, Alert banners, List Groups, dan Button Groups.
6. [06. Formulir dan Validasi](06.%20Formulir%20dan%20Validasi.md) : Form control, Floating labels, Input groups, Check/Radio kustom, dan feedback validasi `:valid` / `:invalid`.
7. [07. Navigasi dan Header](07.%20Navigasi%20dan%20Header.md) : Navbar responsif dengan tombol hamburger collapse, Nav tabs, Pagination, dan Breadcrumb.

### Bagian 3: Interaktivitas JavaScript & Kustomisasi Lanjutan
8. [08. Komponen Interaktif (Modals, Offcanvas, dan Tooltips)](08.%20Komponen%20Interaktif%20(Modals,%20Offcanvas,%20dan%20Tooltips).md) : Jendela modal pop-up, laci geser offcanvas, popovers, dan inisialisasi JavaScript API.
9. [09. Carousel dan Accordion](09.%20Carousel%20dan%20Accordion.md) : Slider tayangan gambar otomatis (carousel) dan daftar lipat tanya-jawab (accordion).
10. [10. Kustomisasi Tema dengan Sass](10.%20Kustomisasi%20Tema%20dengan%20Sass.md) : Override variabel SCSS `$theme-colors`, penambahan warna merek, dan Utility API Bootstrap 5.
11. [11. Arsitektur Komponen dan Best Practices](11.%20Arsitektur%20Komponen%20dan%20Best%20Practices.md) : Mengelola CSS kustom tanpa merusak Bootstrap, integrasi modern framework (React/Laravel), dan optimasi bundle produksi.

---

### Bagian 4: Proyek Praktikum Mandiri (Hands-on Labs)
Seluruh proyek dapat langsung dibuka di browser tanpa perlu proses build terpisah:

1. [Praktek 01: Company Landing Page](praktek/01-company-landing-page/index.html) : Halaman profil perusahaan lengkap dengan navbar sticky, hero section, 3 kartu layanan grid, dan newsletter.
2. [Praktek 02: Admin Dashboard](praktek/02-admin-dashboard/index.html) : Panel antarmuka admin dengan laci menu offcanvas, dialog modal tambah data, kartu ringkasan KPI, dan tabel interaktif.
