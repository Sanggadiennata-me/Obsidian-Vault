#programming 

Ada beberapa metode untuk mengintegrasikan Bootstrap 5 ke dalam proyek Anda, mulai dari cara termudah menggunakan CDN resmi hingga instalasi profesional menggunakan package manager (NPM).

---

## 1. Metode Instan: CDN (Content Delivery Network)

Metode tercepat dan paling umum digunakan adalah menyisipkan berkas stylesheet dan script JavaScript resmi yang di-host di jsDelivr.

### Struktur Dokumen Starter HTML5
Buat berkas `index.html` dan tempelkan kerangka dasar berikut:

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Belajar Bootstrap 5</title>
  
  <!-- 1. Bootstrap 5 CSS -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
  
  <!-- 2. Bootstrap Icons (Opsional tapi Sangat Direkomendasikan) -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">
</head>
<body class="bg-light p-4">
  <div class="container">
    <div class="card shadow-sm">
      <div class="card-body">
        <h5 class="card-title text-primary"><i class="bi bi-check-circle-fill me-2"></i>Instalasi Berhasil!</h5>
        <p class="card-text text-secondary">Bootstrap 5 siap digunakan untuk membangun antarmuka web.</p>
        <button class="btn btn-primary">Klik Saya</button>
      </div>
    </div>
  </div>

  <!-- 3. Bootstrap 5 JS Bundle (Wajib Diletakkan Sebelum Penutup </body>) -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

### Mengapa Memilih `bootstrap.bundle.min.js`?
Bootstrap menyediakan dua varian berkas JavaScript:
1. `bootstrap.min.js` (hanya kode Bootstrap murni).
2. **`bootstrap.bundle.min.js`** (sudah menyertakan pustaka **Popper.js** di dalamnya).

Komponen seperti Dropdown menu, Popovers, dan Tooltips membutuhkan mesin kalkulasi posisi Popper.js agar tidak tertutup batas layar. Oleh karena itu, **selalu gunakan berkas Bundle** agar seluruh komponen interaktif dapat berjalan lancar tanpa kendala.

## 2. Metode Profesional: Menggunakan NPM

Jika Anda membangun proyek modern berbasis bundler (seperti Vite, Webpack, Laravel, atau Next.js):

```bash
npm install bootstrap @popperjs/core
npm install bootstrap-icons
```

Di dalam berkas JavaScript utama aplikasi Anda (misal `src/main.js`):
```js
// Impor stylesheet CSS Bootstrap
import 'bootstrap/dist/css/bootstrap.min.css';
import 'bootstrap-icons/font/bootstrap-icons.css';

// Impor modul JavaScript Bootstrap
import * as bootstrap from 'bootstrap';
```

---

## 3. Pengecekan Keberhasilan Instalasi

Setelah memasang CDN atau NPM, Anda dapat menguji keberhasilan instalasi melalui dua indikator:
* **Indikator Visual**: Tampilan teks font berubah dari default Times New Roman menjadi sans-serif modern (`system-ui`), serta tombol memiliki sudut melengkung dan warna biru khas `.btn-primary`.
* **Indikator JavaScript**: Buka Console di Developer Tools browser (F12) dan ketik `typeof bootstrap`. Jika mengembalikan nilai `'object'`, maka seluruh interaksi JavaScript telah aktif dengan sempurna.
