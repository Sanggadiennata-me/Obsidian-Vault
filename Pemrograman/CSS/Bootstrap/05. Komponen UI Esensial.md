#programming 

Komponen UI adalah kekuatan utama Bootstrap. Anda tidak perlu merakit tombol, kartu, atau lencana status dari nol; cukup gunakan kombinasi class semantik yang sudah teruji estetika dan aksesibilitasnya.

---

## 1. Tombol (Buttons)

Tombol di Bootstrap selalu diawali dengan class dasar `.btn` diikuti varian warna atau bentuk:

### A. Varian Tombol Solid dan Outline
```html
<!-- Tombol Solid Standar -->
<button class="btn btn-primary">Simpan Data</button>
<button class="btn btn-secondary">Batal</button>
<button class="btn btn-danger">Hapus Permanen</button>

<!-- Tombol Outline (Transparan dengan Garis Tepi) -->
<button class="btn btn-outline-primary">Lihat Profil</button>
<button class="btn btn-outline-success">Unduh PDF</button>
```

### B. Ukuran dan Bentuk Tombol
* **Ukuran**: `.btn-sm` (kecil untuk tabel data), `.btn-lg` (besar untuk banner hero).
* **Bentuk Kapsul**: Tambahkan class `.rounded-pill` untuk membuat kedua ujung tombol melengkung bulat penuh.
* **Tombol Lebar Penuh (*Block Button*)**: Bungkus tombol di dalam parent bertag `.d-grid`:
  ```html
  <div class="d-grid gap-2">
    <button class="btn btn-primary btn-lg">Masuk ke Akun</button>
  </div>
  ```

## 2. Kartu Konten Serbaguna (Cards)

Class `.card` adalah wadah konten paling fleksibel di Bootstrap yang menggantikan panel, sumur (*wells*), dan thumbnail lama:

```html
<div class="card shadow-sm border-0 rounded-4 overflow-hidden" style="max-width: 320px;">
  <!-- Gambar Bagian Atas -->
  <img src="gambar-produk.jpg" class="card-img-top" alt="Produk">
  
  <!-- Badan Kartu -->
  <div class="card-body p-4">
    <div class="badge bg-primary-subtle text-primary mb-2">Unggulan</div>
    <h5 class="card-title fw-bold">Cloud Server Pro</h5>
    <p class="card-text text-secondary small">
      Infrastruktur berkecepatan tinggi dengan jaminan uptime 99.99%.
    </p>
    <a href="#" class="btn btn-primary w-100 rounded-3">Beli Sekarang</a>
  </div>
</div>
```

> **Tips Ketinggian Seragam**: Saat menaruh beberapa kartu di dalam kolom grid, tambahkan class `.h-100` pada kartu agar seluruh kartu di baris yang sama otomatis memiliki tinggi yang rata dan sejajar.

## 3. Lencana Status (Badges)

Badges digunakan untuk menampilkan hitungan notifikasi, tag kategori, atau label status:

```html
<!-- Badge Standar -->
<span class="badge bg-primary">Baru</span>
<span class="badge bg-success">Online</span>

<!-- Badge Bentuk Kapsul (*Pill Badge*) -->
<span class="badge bg-danger rounded-pill">12 Pesan Belum Dibaca</span>

<!-- Badge Subtly Modern Ber-opacity Rendah -->
<span class="badge bg-info-subtle text-info-emphasis border border-info-subtle rounded-pill">
  Sedang Diproses
</span>
```

## 4. Spanduk Pemberitahuan (Alerts)

Digunakan untuk memberikan umpan balik informasi kepada pengguna saat login berhasil, data tersimpan, atau terjadi kesalahan:

```html
<!-- Alert yang Bisa Ditutup Mandiri oleh Pengguna -->
<div class="alert alert-success alert-dismissible fade show border-0 shadow-sm rounded-3" role="alert">
  <strong>Berhasil!</strong> Profil akun Anda telah diperbarui.
  
  <!-- Tombol Silang Penutup Resmi -->
  <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
</div>
```
Penjelasan:
* `alert-dismissible` : Memberikan ruang kosong di sisi kanan untuk tombol silang.
* `fade show` : Memberikan efek animasi memudar yang halus saat tombol silang diklik.
* `btn-close` : Komponen tombol silang bawaan yang otomatis menutup alert tanpa memerlukan kode JavaScript manual.
