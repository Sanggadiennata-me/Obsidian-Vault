#programming 

Header navigasi (*navbar*) adalah elemen pertama yang dilihat oleh pengunjung website. Bootstrap menyediakan komponen navigasi responsif yang otomatis berubah menjadi menu hamburger di layar ponsel dan berjejer rapi di layar komputer.

---

## 1. Anatomi Lengkap Navbar Responsif

Sebuah navbar Bootstrap standar terdiri dari:
1. Pembungkus navbar: `.navbar .navbar-expand-lg`.
2. Logo / Merek: `.navbar-brand`.
3. Tombol Hamburger: `.navbar-toggler`.
4. Konten Lipat: `.collapse .navbar-collapse`.
5. Daftar Tautan: `.navbar-nav .nav-link`.

```html
<nav class="navbar navbar-expand-lg navbar-dark bg-dark sticky-top py-3 shadow-sm">
  <div class="container">
    <!-- Brand Logo -->
    <a class="navbar-brand fw-bold text-primary" href="#">NexusCorp</a>

    <!-- Tombol Hamburger (Otomatis Muncul di Layar Ponsel) -->
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navMenu">
      <span class="navbar-toggler-icon"></span>
    </button>

    <!-- Menu Lipat -->
    <div class="collapse navbar-collapse" id="navMenu">
      <!-- ms-auto Mendorong Tautan ke Sisi Kanan Navbar -->
      <ul class="navbar-nav ms-auto mb-2 mb-lg-0 gap-lg-3">
        <li class="nav-item"><a class="nav-link active" href="#">Beranda</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Layanan</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Harga</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Kontak</a></li>
      </ul>
      <div class="ms-lg-3">
        <a href="#" class="btn btn-primary btn-sm rounded-pill px-3">Daftar</a>
      </div>
    </div>
  </div>
</nav>
```

### Kunci Sukses Navbar:
* **`navbar-expand-lg`** : Menentukan kapan menu hamburger melebar menjadi baris mendatar (pada layar ukuran `lg` / >= 992px). Jika Anda ingin menu melebar lebih awal di layar tablet, ganti menjadi `navbar-expand-md`.
* **`sticky-top`** : Menjaga agar navbar tetap menempel di bagian paling atas layar saat halaman di-scroll ke bawah.
* **`ms-auto`** : Memberikan margin start (kiri) otomatis sehingga link navigasi terdorong rapi ke sisi kanan layar.

## 2. Navigasi Tab Interaktif (*Nav Tabs*)

Memungkinkan pengguna berpindah-pindah panel konten tanpa memuat ulang (*reload*) halaman:

```html
<!-- Tombol Tab Navigasi -->
<ul class="nav nav-pills mb-3" id="pills-tab" role="tablist">
  <li class="nav-item">
    <button class="nav-link active" data-bs-toggle="pill" data-bs-target="#tab1">Profil</button>
  </li>
  <li class="nav-item">
    <button class="nav-link" data-bs-toggle="pill" data-bs-target="#tab2">Keamanan</button>
  </li>
</ul>

<!-- Wadah Konten Tab -->
<div class="tab-content">
  <div class="tab-pane fade show active p-3 bg-white border rounded" id="tab1">
    Konten pengaturan profil pengguna.
  </div>
  <div class="tab-pane fade p-3 bg-white border rounded" id="tab2">
    Konten pengaturan ganti password dan otentikasi 2FA.
  </div>
</div>
```

## 3. Penomoran Halaman (Pagination)

Digunakan di bagian bawah tabel data atau daftar katalog produk:

```html
<nav aria-label="Navigasi Halaman">
  <ul class="pagination pagination-sm justify-content-center">
    <li class="page-item disabled"><a class="page-link" href="#">Sebelumnya</a></li>
    <li class="page-item active"><a class="page-link" href="#">1</a></li>
    <li class="page-item"><a class="page-link" href="#">2</a></li>
    <li class="page-item"><a class="page-link" href="#">3</a></li>
    <li class="page-item"><a class="page-link" href="#">Selanjutnya</a></li>
  </ul>
</nav>
```
* `justify-content-center` : Menengahkan posisi pagination di layar.
* `pagination-sm` / `pagination-lg` : Mengatur ukuran bar navigasi.
