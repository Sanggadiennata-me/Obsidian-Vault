#programming 

Bulma versi 1.0 membawa evolusi arsitektur besar dengan menggabungkan kekuatan kompilasi Sass tradisional dan fleksibilitas CSS Custom Properties (CSS Variables) native. Hal ini memungkinkan penyesuaian tema dilakukan tanpa proses build yang berat, atau disesuaikan secara mendalam melalui SCSS.

## 1. Kustomisasi Instan dengan CSS Variables (Bulma v1.0)

Pada Bulma v1.0, hampir semua token desain (warna, sudut lengkung, spasi, tipografi) diekspos sebagai CSS variable dengan awalan `--bulma-*`. Anda dapat menimpa variabel ini langsung di file CSS reguler tanpa menyentuh compiler Sass.

### Menimpa Variabel Global di Root
```css
/* style.css */
:root {
  /* Mengubah warna primer menjadi ungu modern */
  --bulma-primary: #7c3aed;
  --bulma-primary-h: 262deg;
  --bulma-primary-s: 83%;
  --bulma-primary-l: 58%;

  /* Mengubah radius sudut default */
  --bulma-radius: 12px;
  --bulma-radius-rounded: 9999px;

  /* Menentukan font utama */
  --bulma-body-family: 'Inter', -apple-system, sans-serif;
}
```

Semua komponen yang menggunakan class `.is-primary` (seperti `.button.is-primary` atau `.hero.is-primary`) akan otomatis berubah warna mengikuti nilai baru tersebut secara real-time di browser.

### Kustomisasi Berbasis Komponen Tertentu
Variabel CSS juga dapat ditimpa hanya pada komponen atau wadah tertentu:
```css
/* Mengubah tombol di dalam sidebar agar memiliki sudut ekstra tajam */
.sidebar .button {
  --bulma-radius: 2px;
}
```

## 2. Sistem Tema Gelap Bawaan (Dark Mode)

Bulma v1.0 menyematkan palet warna gelap terkalibrasi secara native. Anda dapat mengontrol tema menggunakan atribut HTML `data-theme`:

```html
<!-- Mengaktifkan mode gelap pada seluruh halaman -->
<!DOCTYPE html>
<html lang="id" data-theme="dark">
<head>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bulma@1.0.4/css/bulma.min.css">
</head>
<body>
  <div class="box">
    <!-- Kotak ini otomatis mendapatkan latar abu-abu gelap dengan teks putih kontras -->
    <h2 class="title">Mode Gelap Aktif</h2>
  </div>
</body>
</html>
```

### Tombol Pengganti Tema (Dark Mode Switcher JavaScript)
```javascript
const tombolTema = document.getElementById('toggle-tema');

tombolTema.addEventListener('click', () => {
  const root = document.documentElement;
  const temaSaatIni = root.getAttribute('data-theme');
  const temaBaru = temaSaatIni === 'dark' ? 'light' : 'dark';
  
  root.setAttribute('data-theme', temaBaru);
  localStorage.setItem('preferensi-tema', temaBaru);
});
```

## 3. Kustomisasi Mendalam Menggunakan Sass / SCSS

Jika Anda membutuhkan optimasi ukuran berkas CSS atau ingin mendefinisikan formula warna baru di tingkat kompilasi, gunakan Sass modular.

### Struktur Proyek Sass

```text
my-bulma-project/
├── node_modules/
│   └── bulma/
├── src/
│   └── styles/
│       └── custom-bulma.scss
└── package.json
```

### Contoh File `custom-bulma.scss`

Di Sass modern, gunakan sintaks `@use` dengan konfigurasi `with`:

```scss
// custom-bulma.scss

// 1. Definisikan variabel baru sebelum Bulma dimuat
@use "bulma/sass" with (
  $primary: #6366f1, // Warna Indigo modern
  $danger: #f43f5e,  // Warna Rose cerah
  $family-sans-serif: ("Plus Jakarta Sans", sans-serif),
  $radius-large: 16px
);

// 2. Tambahkan CSS kustom spesifik aplikasi jika diperlukan
.custom-card-shadow {
  box-shadow: 0 10px 25px -5px rgba(0, 0, 0, 0.08);
}
```

### Mengimpor Modul Bulma Secara Selektif (Pangkas Ukuran Berkas)
Jika proyek Anda hanya membutuhkan sistem kolom dan tombol, Anda tidak perlu mengimpor seluruh Bulma:

```scss
// Mengimpor hanya fondasi utilitas, kolom, dan elemen tombol
@use "bulma/sass/utilities";
@use "bulma/sass/base";
@use "bulma/sass/grid/columns";
@use "bulma/sass/elements/button";
```

Hal ini akan menghasilkan ukuran file CSS final yang sangat ramping (di bawah 15 KB).
