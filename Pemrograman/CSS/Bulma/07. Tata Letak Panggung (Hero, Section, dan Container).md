#programming 

Bulma menyediakan blok arsitektur tata letak berskala besar yang menjadi fondasi kerangka halaman web. Elemen-elemen ini memastikan konsistensi bantalan vertikal, pembatasan lebar horizontal, dan spanduk visual yang menarik.

## 1. Pembatas Lebar Konten (`.container`)

Class `.container` berfungsi membatasi lebar maksimum konten dan memusatkannya secara otomatis di tengah layar (`margin-left: auto` dan `margin-right: auto`).

Tingkatan batas lebar `.container`:
- Pada layar seluler (di bawah 768px): Lebar 100% dengan bantalan tepi.
- Pada tablet (769px ke atas): Maksimal 960px.
- Pada desktop (1024px ke atas): Maksimal 1152px.
- Pada layar widescreen (1216px ke atas): Maksimal 1344px.

Modifier kontainer khusus:
- `.container.is-fluid`: Memberikan margin 32px di sisi kiri dan kanan pada semua ukuran layar tanpa batasan lebar maksimal.
- `.container.is-max-desktop`: Mengunci lebar maksimal hanya sebatas breakpoint desktop meski dibuka di layar televisi ultra lebar.

```html
<div class="container">
  <!-- Konten aplikasi berada rapi di tengah layar -->
  <p>Konten berada di dalam kontainer terpusat.</p>
</div>
```

## 2. Blok Pemisah Halaman (`.section`)

Class `.section` digunakan sebagai kontainer pemisah vertikal antar bagian konten halaman (seperti bagian fitur, bagian testimoni, bagian kontak). Secara default, `.section` memberikan padding vertikal sebesar 3rem (48px) di atas dan di bawah konten.

Varian bantalan vertikal:
- `.section`: Padding vertikal standar (3rem).
- `.section.is-medium`: Padding vertikal lebih lapang (6rem).
- `.section.is-large`: Padding vertikal sangat lapang (9rem atau 144px).

```html
<section class="section">
  <div class="container">
    <h2 class="title">Fitur Unggulan</h2>
    <p class="subtitle">Solusi lengkap untuk kebutuhan otomasi bisnis Anda.</p>
  </div>
</section>
```

## 3. Spanduk Raksasa Utama (`.hero`)

Komponen `.hero` adalah spanduk lebar penuh (full-width banner) yang dirancang untuk menarik perhatian pengguna di bagian paling atas halaman situs (landing page hero section).

### Struktur Anatomi Tiga Bagian Hero
Sebuah hero lengkap dapat memuat tiga lapisan:
1. `.hero-head`: Bagian atas spanduk (biasanya diisi navigasi navbar transparan).
2. `.hero-body`: Bagian tengah spanduk (konten utama hero, judul, tombol CTA).
3. `.hero-foot`: Bagian bawah spanduk (biasanya diisi tab navigasi atau ringkasan).

```html
<section class="hero is-primary is-medium">
  <!-- Area Atas (Navigasi Opsional) -->
  <div class="hero-head">
    <div class="container py-3">
      <span class="has-text-weight-bold">BrandLogo</span>
    </div>
  </div>

  <!-- Area Tengah (Pesan Utama) -->
  <div class="hero-body">
    <div class="container has-text-centered">
      <h1 class="title is-1">Bangun Website Lebih Cepat</h1>
      <p class="subtitle is-4">Kombinasi fleksibilitas Flexbox dan keindahan desain modern tanpa keterikatan JavaScript.</p>
      <button class="button is-white is-outlined is-medium">Mulai Sekarang</button>
    </div>
  </div>

  <!-- Area Bawah (Kaki Spanduk) -->
  <div class="hero-foot">
    <div class="container">
      <nav class="tabs is-boxed is-fullwidth">
        <ul>
          <li class="is-active"><a>Gambaran Umum</a></li>
          <li><a>Dokumentasi</a></li>
          <li><a>Unduhan</a></li>
        </ul>
      </nav>
    </div>
  </div>
</section>
```

### Varian Tinggi Hero
- `is-small`: Spanduk ramping ringkas.
- `is-medium`: Spanduk proporsional untuk landing page standar.
- `is-large`: Spanduk tinggi dengan ruang visual dramatis.
- `is-fullheight`: Spanduk yang mengisi tepat 100% tinggi jendela peramban (100vh).

## 4. Bar Perataan Fleksibel (`.level`)

Class `.level` adalah komponen Flexbox serbaguna untuk menata elemen horizontal dengan dua fungsi utama:

### Pola A: Sisi Kiri dan Kanan Terpisah
Menggunakan `.level-left` dan `.level-right`:
```html
<nav class="level">
  <div class="level-left">
    <div class="level-item">
      <p class="subtitle is-5">Total <strong>128</strong> transaksi hari ini</p>
    </div>
  </div>
  <div class="level-right">
    <div class="level-item">
      <button class="button is-primary">Ekspor Laporan</button>
    </div>
  </div>
</nav>
```

### Pola B: Kartu Metrik Terpusat (Metric Counters)
Menampilkan statistik dengan judul kecil dan angka besar:
```html
<nav class="level">
  <div class="level-item has-text-centered">
    <div>
      <p class="heading">Total Pengguna</p>
      <p class="title">24.500</p>
    </div>
  </div>
  <div class="level-item has-text-centered">
    <div>
      <p class="heading">Tingkat Retensi</p>
      <p class="title">98.2%</p>
    </div>
  </div>
  <div class="level-item has-text-centered">
    <div>
      <p class="heading">Pendapatan Bulanan</p>
      <p class="title">Rp 185 Juta</p>
    </div>
  </div>
</nav>
```

## 5. Area Kaki Halaman (`.footer`)

Tag `<footer>` dengan class `.footer` menyediakan wadah penutup situs dengan warna latar abu-abu netral terstruktur:

```html
<footer class="footer">
  <div class="content has-text-centered">
    <p>
      <strong>Bulma Masterclass</strong> oleh Aryanda. Kode sumber dilisensikan di bawah lisensi MIT.
    </p>
  </div>
</footer>
```
