#programming 

Bulma dapat diintegrasikan ke dalam proyek web dengan beberapa cara fleksibel, mulai dari cara termudah menggunakan CDN resmi hingga penggunaan modul npm terintegrasi dengan bundler modern (Vite, Webpack, Parcel).

## 1. Instalasi Cepat Melalui CDN (Content Delivery Network)

Cara paling instan untuk memulai tanpa konfigurasi build tool adalah dengan menautkan file CSS Bulma terkompresi langsung dari CDN terpercaya seperti jsDelivr.

### Template HTML5 Standar Bulma CDN

Salin kode boilerplate berikut ke dalam file `index.html`:

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Memulai Bulma CSS</title>
  
  <!-- CDN Bulma CSS versi 1.0.4 -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bulma@1.0.4/css/bulma.min.css">
  
  <!-- Font Awesome untuk Dukungan Ikon UI -->
  <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/css/all.min.css">
</head>
<body>
  <section class="section">
    <div class="container">
      <h1 class="title">Halo Dunia Bulma!</h1>
      <p class="subtitle">Aplikasi web pertama saya dengan framework berbasis Flexbox murni.</p>
      <button class="button is-primary">
        <span class="icon"><i class="fas fa-rocket"></i></span>
        <span>Jelajahi Fitur</span>
      </button>
    </div>
  </section>
</body>
</html>
```

## 2. Instalasi Menggunakan NPM (Node Package Manager)

Untuk proyek berskala menengah hingga besar yang memanfaatkan bundler modern seperti Vite, Next.js, Nuxt, atau Laravel, instalasi via NPM memberikan kendali penuh terhadap pemangkasan ukuran file dan penyesuaian variabel Sass.

Jalankan perintah berikut di terminal proyek:

```bash
npm install bulma
```

### Impor Langsung di File JavaScript atau CSS Utama

Jika Anda menggunakan bundler seperti Vite:

```javascript
// main.js atau index.js
import 'bulma/css/bulma.min.css';
import '@fortawesome/fontawesome-free/css/all.min.css';
```

Atau di dalam file CSS root:

```css
/* style.css */
@import "bulma/css/bulma.min.css";
```

## 3. Integrasi Ikon UI (Font Awesome)

Bulma sengaja tidak memaketkan font ikon bawaan untuk menjaga ukuran CSS tetap ringan dan memberikan kebebasan kepada pengembang. Namun, Bulma menyediakan class pembungkus semantik `.icon` yang dirancang presisi untuk bekerja harmonis dengan pustaka ikon Font Awesome.

Aturan hierarki ikon dalam Bulma:
1. Elemen ikon luar menggunakan tag `<span>` dengan class `icon`.
2. Jika ikon berada di dalam tombol atau form, dapat dikombinasikan dengan modifier ukuran seperti `is-small`, `is-medium`, atau `is-large`.
3. Elemen ikon dalam menggunakan tag `<i>` dengan class resmi Font Awesome (`fas fa-*` atau `fab fa-*`).

Contoh ikon di samping teks:
```html
<button class="button is-info">
  <span class="icon is-small">
    <i class="fas fa-envelope"></i>
  </span>
  <span>Kirim Pesan</span>
</button>
```

## 4. Konfigurasi Tema Gelap (Dark Mode di Bulma v1.0)

Mulai Bulma versi 1.0, framework ini telah menyediakan dukungan mode gelap dan variabel CSS secara native tanpa memerlukan plugin eksternal. Anda cukup menambahkan atribut `data-theme` pada tag `<html>`:

```html
<!-- Mengaktifkan tema gelap secara manual -->
<html lang="id" data-theme="dark">
```

Atau biarkan mendeteksi preferensi sistem pengguna secara otomatis melalui media query `prefers-color-scheme`.
