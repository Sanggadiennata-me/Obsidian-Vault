#programming 

Menerapkan Bulma dalam skala produksi membutuhkan pemahaman arsitektur yang bersih, pemisahan tanggung jawab yang jelas antara styling dan logika interaksi, serta optimasi aksesibilitas (a11y) dan performa.

## 1. Pemisahan Logika JavaScript yang Bersih (Clean Decoupling)

Karena Bulma tidak memaksakan JavaScript bawaan, pola arsitektur terbaik adalah menghindari penulisan kode JavaScript inline seperti `onclick="..."` pada tag HTML. Gunakan pendekatan handler berbasis atribut data atau pembungkus kelas seragam.

### Pola Toggle Komponen Universal

```javascript
// ui-controller.js
document.addEventListener('DOMContentLoaded', () => {
  // Tangani semua pemicu modal secara deklaratif
  const pemicuModal = document.querySelectorAll('[data-toggle="modal"]');
  pemicuModal.forEach(tombol => {
    tombol.addEventListener('click', () => {
      const idTarget = tombol.getAttribute('data-target');
      const elemenModal = document.getElementById(idTarget);
      if (elemenModal) {
        elemenModal.classList.add('is-active');
      }
    });
  });

  // Tangani semua tombol penutup modal
  const penutupModal = document.querySelectorAll('[data-dismiss="modal"]');
  penutupModal.forEach(tombol => {
    tombol.addEventListener('click', () => {
      const modalTerbuka = tombol.closest('.modal');
      if (modalTerbuka) {
        modalTerbuka.classList.remove('is-active');
      }
    });
  });
});
```

Dengan pola di atas, tombol HTML cukup ditulis secara deklaratif:
```html
<button class="button is-primary" data-toggle="modal" data-target="modal-konfirmasi">
  Buka Dialog
</button>
```

## 2. Integrasi dengan Ekosistem JavaScript Modern

Bulma sangat cocok dipadukan dengan framework frontend modern karena status visual dikendalikan murni oleh keberadaan class CSS.

### A. Integrasi dengan Alpine.js (Pasangan Paling Ringan)
Alpine.js adalah pendamping paling ideal untuk Bulma karena menambahkan reaktivitas tanpa memerlukan bundler yang rumit:

```html
<!-- Modal interaktif 100% tanpa file JS eksternal menggunakan Alpine.js -->
<div x-data="{ modalBuka: false }">
  <button class="button is-info" @click="modalBuka = true">Buka Modal</button>

  <div class="modal" :class="{ 'is-active': modalBuka }">
    <div class="modal-background" @click="modalBuka = false"></div>
    <div class="modal-card">
      <header class="modal-card-head">
        <p class="modal-card-title">Pemberitahuan</p>
        <button class="delete" @click="modalBuka = false"></button>
      </header>
      <section class="modal-card-body">
        Data berhasil disimpan ke server.
      </section>
      <footer class="modal-card-foot">
        <button class="button is-success" @click="modalBuka = false">Mengerti</button>
      </footer>
    </div>
  </div>
</div>
```

### B. Integrasi dengan React / Next.js
Di React, kendalikan class Bulma menggunakan state:

```jsx
import { useState } from 'react';

export default function DropdownMenu() {
  const [buka, setBuka] = useState(false);

  return (
    <div className={`dropdown ${buka ? 'is-active' : ''}`}>
      <div className="dropdown-trigger">
        <button className="button" onClick={() => setBuka(!buka)}>
          <span>Opsi Pengaturan</span>
        </button>
      </div>
      <div className="dropdown-menu">
        <div className="dropdown-content">
          <a className="dropdown-item" href="#profil">Profil Saya</a>
          <a className="dropdown-item" href="#keamanan">Keamanan</a>
        </div>
      </div>
    </div>
  );
}
```

### C. Integrasi dengan Vue 3
```html
<script setup>
import { ref } from 'vue';
const isActive = ref(false);
</script>

<template>
  <button class="button is-primary" :class="{ 'is-loading': isActive }" @click="isActive = !isActive">
    Simpan Konfigurasi
  </button>
</template>
```

## 3. Standar Aksesibilitas Web (ARIA Compliance)

Bulma menyediakan struktur visual yang indah, namun pengembang bertanggung jawab menyematkan atribut aksesibilitas yang tepat agar ramah bagi pembaca layar (screen reader):

1. **Tombol Hapus (`.delete`)**: Selalu sertakan atribut `aria-label="close"`.
   ```html
   <button class="delete" aria-label="Tutup pemberitahuan"></button>
   ```
2. **Burger Menu Navigasi**: Sertakan `role="button"`, `aria-label="menu"`, dan pantau `aria-expanded="true/false"` secara dinamis via JavaScript saat menu dibuka atau ditutup.
3. **Dropdown**: Berikan atribut `aria-haspopup="true"` dan tautkan atribut `aria-controls` ke id elemen konten dropdown.

## 4. Optimasi Ukuran File Produksi (Production Tree-Shaking)

Jika Anda menyertakan seluruh bundel CSS Bulma (sekitar 200 KB belum terkompresi), Anda dapat memangkas ukuran menjadi kurang dari 20 KB dengan menggunakan alat pembersih CSS seperti PurgeCSS di alur build:

```javascript
// postcss.config.js
module.exports = {
  plugins: [
    require('@fullhuman/postcss-purgecss')({
      content: ['./src/**/*.html', './src/**/*.vue', './src/**/*.jsx'],
      defaultExtractor: content => content.match(/[\w-/:]+(?<!:)/g) || []
    })
  ]
};
```
