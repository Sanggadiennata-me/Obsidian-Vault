#programming 

Bulma menyediakan sistem warna semantik, tipografi terstruktur, dan kelas pembantu (helpers) yang membuat perancangan antarmuka menjadi sangat cepat dan konsisten.

## 1. Palet Warna Semantik

Warna dalam Bulma didefinisikan berdasarkan fungsinya di dalam antarmuka aplikasi:

| Nama Warna | Modifier Class | Karakteristik Penggunaan |
| :--- | :--- | :--- |
| **Primary** | `is-primary` | Warna identitas brand utama (standar: toska kehijauan). |
| **Link** | `is-link` | Warna aksi navigasi atau tautan biru. |
| **Info** | `is-info` | Informasi netral atau tips (biru muda cerah). |
| **Success** | `is-success` | Indikasi keberhasilan atau status positif (hijau). |
| **Warning** | `is-warning` | Peringatan atau kondisi yang memerlukan perhatian (kuning oranye). |
| **Danger** | `is-danger` | Kesalahan fatal, aksi destruktif, atau hapus data (merah). |
| **White / Black** | `is-white` / `is-black` | Warna monokrom netral absolut. |
| **Light / Dark** | `is-light` / `is-dark` | Abu-abu lembut atau abu-abu pekat gelap. |

### Varian Terang dan Gelap (Light and Dark Helpers)
Setiap warna memiliki varian warna lembut (light) dan gelap (dark) untuk latar belakang dan teks:
- `has-background-primary-light`: Menghasilkan warna latar toska pastel yang sangat lembut.
- `has-text-primary-dark`: Menghasilkan teks toska gelap dengan tingkat kontras tinggi terhadap latar terang.

```html
<div class="notification is-success is-light">
  Pemberitahuan: Akun Anda telah berhasil diverifikasi.
</div>
```

## 2. Tipografi: Pasangan `title` dan `subtitle`

Tipografi Bulma memisahkan judul menjadi dua komponen utama: `.title` untuk judul utama dan `.subtitle` untuk keterangan pendukung.

### Skala Ukuran Font (`is-1` hingga `is-6`)
Tersedia 6 tingkatan ukuran yang dapat diterapkan pada judul:
- `is-1`: Ukuran font terbesar (3rem).
- `is-2`: 2.5rem.
- `is-3`: 2rem.
- `is-4`: 1.5rem.
- `is-5`: 1.25rem.
- `is-6`: Ukuran font terkecil untuk judul (1rem).

```html
<h1 class="title is-2">Statistik Penjualan</h1>
<h2 class="subtitle is-5">Ringkasan performa kuartal ketiga tahun ini</h2>
```

> [!NOTE] Perilaku Spasi Otomatis Pasangan Title dan Subtitle
> Jika elemen `.subtitle` diletakkan tepat setelah elemen `.title`, Bulma secara cerdas akan menghilangkan jarak margin bawah pada `.title` dan merapatkan posisi `.subtitle` sehingga keduanya tampak menyatu secara harmonis.

## 3. Utilitas Format Teks (Text Helpers)

### A. Perataan Teks (Alignment)
- `has-text-left`: Rata kiri.
- `has-text-centered`: Rata tengah.
- `has-text-right`: Rata kanan.
- `has-text-justified`: Rata kanan-kiri.

### B. Ketebalan Font (Font Weight)
- `has-text-weight-light`: Bobot 300 (tipis).
- `has-text-weight-normal`: Bobot 400 (normal).
- `has-text-weight-medium`: Bobot 500 (sedang).
- `has-text-weight-semibold`: Bobot 600 (semi tebal).
- `has-text-weight-bold`: Bobot 700 (tebal).

### C. Transformasi Teks
- `is-capitalized`: Mengubah huruf pertama setiap kata menjadi kapital.
- `is-lowercase`: Mengubah seluruh huruf menjadi kecil.
- `is-uppercase`: Mengubah seluruh huruf menjadi kapital.
- `is-italic`: Memberikan gaya miring pada teks.

## 4. Utilitas Spasi (Margin dan Padding)

Bulma menggunakan konvensi penamaan standar untuk jarak luar (margin) dan jarak dalam (padding):

- Properti: `m` untuk margin, `p` untuk padding.
- Arah:
  - `t` (top / atas)
  - `b` (bottom / bawah)
  - `l` (left / kiri)
  - `r` (right / kanan)
  - `x` (horizontal: kiri dan kanan)
  - `y` (vertikal: atas dan bawah)
  - Tanpa arah (semua 4 sisi)
- Nilai skala: `0` sampai `6` (misalnya `p-4`, `mb-5`, `py-3`, `mx-auto`).

Contoh penataan spasi:
```html
<div class="box p-5 mb-6">
  <p class="has-text-weight-bold mb-2">Kotak dengan Padding Lebar</p>
  <p class="has-text-grey">Konten ini memiliki margin bawah sebesar 1.5rem.</p>
</div>
```
