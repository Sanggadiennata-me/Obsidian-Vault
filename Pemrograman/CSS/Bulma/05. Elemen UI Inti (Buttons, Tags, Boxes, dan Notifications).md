#programming 

Bulma menyediakan kumpulan elemen UI murni yang dirancang rapi, siap pakai, dan mudah dikombinasikan untuk membangun antarmuka web modern.

## 1. Tombol Interaktif (`.button`)

Elemen tombol pada Bulma dapat diterapkan langsung pada tag `<button>`, `<a>`, maupun `<input type="submit">`.

```html
<button class="button is-primary">Simpan Perubahan</button>
<button class="button is-link is-outlined">Batal</button>
<button class="button is-danger is-rounded">Hapus Akun</button>
```

### Varian Gaya dan Status Tombol
- **Gaya Garis Tepi (`is-outlined`)**: Latar belakang transparan dengan garis tepi berwarna dan teks berwarna sesuai tema.
- **Bentuk Membulat (`is-rounded`)**: Menghasilkan tombol berbentuk pil kapsul.
- **Status Memuat (`is-loading`)**: Menampilkan animasi spinner pemuatan melingkar otomatis tanpa perlu manipulasi ikon tambahan.
- **Status Statis (`is-static`)**: Mengubah tombol menjadi elemen label statis yang tidak dapat diklik (berguna sebagai pendamping input).

```html
<!-- Tombol dengan status spinner memuat -->
<button class="button is-primary is-loading">Memproses Data</button>
```

### Grup Tombol Pembungkus (`.buttons`)
Untuk mengelompokkan beberapa tombol dengan jarak yang konsisten, bungkus di dalam elemen `.buttons`. Anda juga dapat menerapkan modifier ukuran bersama seperti `are-small` atau `are-medium`:

```html
<div class="buttons are-small">
  <button class="button is-success">Setujui</button>
  <button class="button is-warning">Tinjau</button>
  <button class="button is-danger">Tolak</button>
</div>
```

## 2. Wadah Kotak Konten (`.box`)

Class `.box` adalah kontainer serbaguna berwarna putih dengan sudut melengkung lembut (border-radius), bayangan halus (box-shadow), serta bantalan dalam (padding) yang seimbang.

```html
<div class="box">
  <h3 class="title is-5">Ringkasan Pesanan</h3>
  <p>Paket Langganan Tahunan Pro telah aktif hingga 31 Desember 2026.</p>
</div>
```

## 3. Label dan Lencana (`.tag` dan `.tags`)

Tag digunakan untuk menampilkan status, kategori, atau metadata singkat:

```html
<span class="tag is-primary">Aktif</span>
<span class="tag is-warning is-light">Menunggu Konfirmasi</span>
<span class="tag is-danger is-rounded">Penting</span>
```

### Tag Bergandeng (Tag Addons)
Anda dapat menyatukan dua tag menjadi satu kesatuan lencana menggunakan pembungkus `.tags.has-addons`:

```html
<div class="tags has-addons">
  <span class="tag is-dark">Versi</span>
  <span class="tag is-info">1.0.4</span>
</div>
```

Atau membuat tag dengan tombol hapus:
```html
<div class="tags has-addons">
  <span class="tag is-success">Teknologi: Bulma</span>
  <a class="tag is-delete"></a>
</div>
```

## 4. Kotak Notifikasi (`.notification`)

Class `.notification` menyediakan wadah peringatan atau pengumuman penting. Komponen ini sering dipadukan dengan tombol close `.delete`:

```html
<div class="notification is-danger is-light">
  <button class="delete"></button>
  <strong>Terjadi Kesalahan!</strong> Kata sandi yang Anda masukkan tidak sesuai dengan kriteria keamanan.
</div>
```

## 5. Bilah Progres (`.progress`)

Elemen bar kemajuan yang memanfaatkan tag HTML5 `<progress>` asli dengan penyesuaian gaya Bulma:

```html
<!-- Bar progres dengan persentase 60% -->
<progress class="progress is-primary" value="60" max="100">60%</progress>

<!-- Bar progres tak berujung (animasi berulang saat memuat) -->
<progress class="progress is-small is-info" max="100">Sedang Mengunduh</progress>
```

## 6. Tabel Data Terstruktur (`.table`)

Terapkan class `.table` pada tag `<table>` untuk styling modern instan, serta kombinasikan dengan modifier fungsional:
- `is-bordered`: Memberikan garis batas pada seluruh sel.
- `is-striped`: Memberikan corak warna selang-seling pada baris tabel (zebra striping).
- `is-narrow`: Merapatkan spasi bantalan antar sel.
- `is-hoverable`: Memberikan efek sorotan warna saat baris dilewati kursor mouse.
- `is-fullwidth`: Melebarkan tabel hingga mengisi 100% ruang wadah pembungkus.

```html
<table class="table is-striped is-hoverable is-fullwidth">
  <thead>
    <tr>
      <th>No</th>
      <th>Nama Pelanggan</th>
      <th>Paket Layanan</th>
      <th>Status</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>Aryanda Pratama</td>
      <td>Cloud Enterprise</td>
      <td><span class="tag is-success">Aktif</span></td>
    </tr>
    <tr>
      <td>2</td>
      <td>Budi Santoso</td>
      <td>Starter Pack</td>
      <td><span class="tag is-warning">Tertunda</span></td>
    </tr>
  </tbody>
</table>
```
