#programming 

Bulma menyediakan arsitektur formulir yang sangat terstruktur, semantik, dan modular. Kunci penguasaan formulir Bulma terletak pada pemahaman hirarki pembungkus: `.field` > `.label` > `.control` > elemen input.

## 1. Hirarki Dasar Elemen Form

Setiap satu baris input umumnya dibungkus dalam struktur 4 tingkatan berikut:

```html
<div class="field">
  <!-- 1. Label Teks -->
  <label class="label">Nama Lengkap</label>
  
  <!-- 2. Pembungkus Kontrol -->
  <div class="control">
    <!-- 3. Elemen Input Aktual -->
    <input class="input" type="text" placeholder="Masukkan nama Anda">
  </div>
  
  <!-- 4. Pesan Bantuan atau Pesan Error -->
  <p class="help">Gunakan nama resmi yang sesuai dengan identitas KTP.</p>
</div>
```

## 2. Input dengan Ikon Penyerta (`has-icons-left` / `has-icons-right`)

Untuk menempatkan ikon di dalam kotak input secara presisi, tambahkan modifier `has-icons-left` atau `has-icons-right` pada elemen `.control`, lalu sertakan elemen `<span class="icon is-small is-left">`:

```html
<div class="field">
  <label class="label">Alamat Email</label>
  <div class="control has-icons-left has-icons-right">
    <input class="input is-success" type="email" placeholder="nama@domain.com" value="aryanda@example.com">
    <!-- Ikon Sisi Kiri -->
    <span class="icon is-small is-left">
      <i class="fas fa-envelope"></i>
    </span>
    <!-- Ikon Indikator Keberhasilan di Sisi Kanan -->
    <span class="icon is-small is-right">
      <i class="fas fa-check"></i>
    </span>
  </div>
  <p class="help is-success">Email ini tersedia dan valid.</p>
</div>
```

## 3. Input Bergandeng dengan Tombol atau Awalan (`has-addons`)

Ketika Anda ingin menyatukan input teks dengan tombol pencarian, atau menyematkan awalan domain (prefix) tanpa celah pemisah, gunakan modifier `has-addons` pada pembungkus `.field`:

### Contoh A: Kotak Pencarian Terpadu
```html
<div class="field has-addons">
  <div class="control is-expanded">
    <input class="input" type="text" placeholder="Cari dokumentasi atau modul...">
  </div>
  <div class="control">
    <button class="button is-primary">
      <span class="icon is-small"><i class="fas fa-search"></i></span>
      <span>Cari</span>
    </button>
  </div>
</div>
```

> [!TIP] Utilitas `is-expanded`
> Modifier `is-expanded` pada elemen `.control` membuat input secara otomatis meregang mengisi seluruh sisa ruang horizontal yang tersedia sebelum tombol.

### Contoh B: Input dengan Prefiks Statis
```html
<div class="field has-addons">
  <div class="control">
    <a class="button is-static">https://</a>
  </div>
  <div class="control is-expanded">
    <input class="input" type="text" placeholder="domain-pilihan-anda.com">
  </div>
</div>
```

## 4. Dropdown Pemilihan (`.select`) dan Area Teks (`.textarea`)

### Dropdown Seleksi
Tag `<select>` harus dibungkus dalam wadah `<div class="select">`:

```html
<div class="field">
  <label class="label">Pilih Paket Layanan</label>
  <div class="control">
    <div class="select is-fullwidth">
      <select>
        <option>Pilih salah satu paket</option>
        <option>Paket Dasar (Gratis)</option>
        <option>Paket Profesional (Bulanan)</option>
        <option>Paket Korporat (Tahunan)</option>
      </select>
    </div>
  </div>
</div>
```

### Area Teks Multibaris
```html
<div class="field">
  <label class="label">Catatan Tambahan</label>
  <div class="control">
    <textarea class="textarea" rows="3" placeholder="Tulis instruksi pengiriman khusus di sini..."></textarea>
  </div>
</div>
```

## 5. Kotak Centang (Checkbox) dan Radio Button

Bulma menata tag `<label class="checkbox">` dan `<label class="radio">` agar rapi dan sejajar:

```html
<div class="field">
  <div class="control">
    <label class="checkbox">
      <input type="checkbox"> Saya telah membaca dan menyetujui syarat & ketentuan layanan.
    </label>
  </div>
</div>

<div class="field">
  <div class="control">
    <label class="radio">
      <input type="radio" name="pembayaran" checked> Transfer Bank
    </label>
    <label class="radio">
      <input type="radio" name="pembayaran"> Kartu Kredit
    </label>
    <label class="radio">
      <input type="radio" name="pembayaran"> Dompet Digital (E-Wallet)
    </label>
  </div>
</div>
```

## 6. Formulir Horizontal (`is-horizontal`)

Untuk tata letak formulir klasik di mana label berada di sebelah kiri dan kotak input berada di sebelah kanan pada layar desktop:

```html
<div class="field is-horizontal">
  <div class="field-label is-normal">
    <label class="label">Nama Organisasi</label>
  </div>
  <div class="field-body">
    <div class="field">
      <div class="control">
        <input class="input" type="text" placeholder="Contoh: PT Teknologi Terbuka">
      </div>
    </div>
  </div>
</div>
```
