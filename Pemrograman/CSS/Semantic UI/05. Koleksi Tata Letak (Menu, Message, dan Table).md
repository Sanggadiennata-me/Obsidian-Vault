#programming 

Kategori **Collections** dalam Semantic UI merupakan kelompok komponen yang menyusun struktur tata letak informasi utama, seperti bilah navigasi, kotak pengumuman status, dan penyajian data tabular.

## 1. Bilah Navigasi Menu (`ui menu`)

Komponen menu Semantic UI sangat serbaguna dan dapat beradaptasi menjadi berbagai varian tata letak:

### A. Navigasi Tunjuk Modern (`secondary pointing menu`)
Gaya menu minimalis dengan garis penunjuk aktif di bawah item:

```html
<div class="ui secondary pointing menu">
  <a class="active item">Dasbor Utama</a>
  <a class="item">Pesan Masuk</a>
  <a class="item">Laporan Analitik</a>
  <div class="right menu">
    <div class="item">
      <div class="ui transparent icon input">
        <input type="text" placeholder="Cari...">
        <i class="search link icon"></i>
      </div>
    </div>
    <a class="ui item">Keluar Sesi</a>
  </div>
</div>
```

### B. Menu Bilah Samping Vertikal (`vertical menu`)
Cocok untuk navigasi sidebar admin atau filter katalog:

```html
<div class="ui vertical menu">
  <a class="active teal item">
    Pesan Masuk
    <div class="ui teal left pointing label">12</div>
  </a>
  <a class="item">
    Pemberitahuan
    <div class="ui label">3</div>
  </a>
  <a class="item">
    Arsip Berkas
    <div class="ui label">51</div>
  </a>
</div>
```

### C. Menu Tab Arsip (`tabular menu`)
Digunakan berdampingan dengan komponen `ui tab` untuk beralih antar halaman konten:

```html
<div class="ui top attached tabular menu">
  <a class="active item" data-tab="pertama">Profil</a>
  <a class="item" data-tab="kedua">Keamanan</a>
</div>
<div class="ui bottom attached active tab segment" data-tab="pertama">
  Konten Profil Pengguna
</div>
<div class="ui bottom attached tab segment" data-tab="kedua">
  Konten Pengaturan Kata Sandi
</div>
```

## 2. Kotak Pesan dan Peringatan (`ui message`)

Class `ui message` digunakan untuk memberikan umpan balik langsung kepada pengguna:

```html
<!-- Pesan Informasi Berikon -->
<div class="ui icon info message">
  <i class="info circle icon"></i>
  <div class="content">
    <div class="header">Pembaruan Sistem Dijadwalkan</div>
    <p>Pemeliharaan rutin server akan dilaksanakan pada hari Minggu pukul 02.00 WIB.</p>
  </div>
</div>

<!-- Pesan Kesalahan dengan Tombol Tutup -->
<div class="ui negative message">
  <i class="close icon"></i>
  <div class="header">Gagal Menyimpan Data</div>
  <p>Format alamat surel yang Anda masukkan tidak valid.</p>
</div>
```

Untuk mengaktifkan fungsi penutup pesan silang:
```javascript
$('.message .close').on('click', function() {
  $(this).closest('.message').transition('fade');
});
```

## 3. Tabel Penyajian Data (`ui table`)

Tabel Semantic UI dirancang dengan standar tipografi yang bersih dan beragam modifier struktural:

- **`celled table`**: Menampilkan garis pemisah antar kolom secara tegas.
- **`striped table`**: Memberikan warna selang-seling pada baris tabel (zebra).
- **`selectable table`**: Memberikan efek sorotan warna saat baris dilewati kursor mouse.
- **`compact table`**: Merapatkan ruang vertikal sel untuk menampilkan data dalam jumlah padat.

```html
<table class="ui celled striped selectable table">
  <thead>
    <tr>
      <th>No</th>
      <th>Nama Karyawan</th>
      <th>Departemen</th>
      <th>Status Kerja</th>
      <th>Aksi</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>Aryanda Pratama</td>
      <td>Engineering</td>
      <td><span class="ui green label">Tetap</span></td>
      <td><button class="ui mini blue button">Rincian</button></td>
    </tr>
    <tr>
      <td>2</td>
      <td>Siti Rahma</td>
      <td>Product Design</td>
      <td><span class="ui orange label">Kontrak</span></td>
      <td><button class="ui mini blue button">Rincian</button></td>
    </tr>
  </tbody>
</table>
```
