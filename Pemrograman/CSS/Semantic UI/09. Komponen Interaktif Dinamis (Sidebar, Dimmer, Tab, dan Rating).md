#programming 

Modul interaktif dinamis dalam Semantic UI melengkapi kebutuhan aplikasi web modern seperti panel navigasi tersembunyi (off-canvas), efek sorotan fokus, perpindahan tab tanpa memuat ulang halaman, dan sistem penilaian interaktif.

## 1. Panel Geser Samping (`ui sidebar`)

Sidebar Semantic UI bekerja dengan pola tata letak khusus: seluruh elemen tubuh halaman dibungkus dalam wadah `<div class="pusher">`, dan elemen sidebar diletakkan berdampingan dengannya di dalam wadah `<body class="pushable">`:

```html
<body class="pushable">
  <!-- Elemen Sidebar Tersembunyi -->
  <div class="ui sidebar inverted vertical menu left" id="sidebarMenu">
    <div class="item">
      <b>Menu Navigasi</b>
    </div>
    <a class="item"><i class="home icon"></i> Beranda</a>
    <a class="item"><i class="chart bar icon"></i> Laporan</a>
    <a class="item"><i class="cogs icon"></i> Pengaturan</a>
  </div>

  <!-- Area Konten yang Terdorong (Pusher) -->
  <div class="pusher">
    <div class="ui container" style="padding-top: 30px;">
      <button class="ui teal button" id="btnBukaSidebar">
        <i class="sidebar icon"></i>
        Buka Sidebar
      </button>
      <p class="mt-4">Konten halaman aplikasi akan bergeser secara mulus saat menu terbuka.</p>
    </div>
  </div>
</body>
```

### Logika JavaScript Sidebar
```javascript
$('#btnBukaSidebar').on('click', function() {
  $('#sidebarMenu').sidebar('setting', 'transition', 'overlay').sidebar('toggle');
});
```

Variasi animasi transisi sidebar:
- `overlay`: Menimpa di atas konten tanpa menggesernya.
- `push`: Mendorong konten halaman ke samping.
- `scale down`: Mengecilkan halaman utama saat sidebar meluncur masuk.
- `uncover`: Mengungkapkan sidebar yang berada di balik layar utama.

## 2. Lapisan Peredup Fokus (`ui dimmer`)

Komponen Dimmer digunakan untuk mengaburkan atau meredupkan suatu bagian konten (atau seluruh layar) saat sistem sedang memproses data atau meminta fokus penuh pengguna:

```html
<div class="ui segment" id="panelData">
  <!-- Komponen Dimmer di Dalam Segmen -->
  <div class="ui dimmer">
    <div class="ui text loader">Sedang Menyinkronkan Data Server...</div>
  </div>

  <h3 class="ui header">Panel Ringkasan Transaksi</h3>
  <p>Data transaksi keuangan harian yang tersimpan di basis data cloud.</p>
  <button class="ui button" id="btnMulaiSinkron">Perbarui Data</button>
</div>
```

Pengendalian JavaScript:
```javascript
$('#btnMulaiSinkron').on('click', function() {
  // Tampilkan dimmer pemuatan
  $('#panelData').dimmer('show');

  // Simulasikan pemrosesan jaringan selama 2 detik
  setTimeout(function() {
    $('#panelData').dimmer('hide');
  }, 2000);
});
```

## 3. Navigasi Antar Tab (`ui tab`)

Komponen tab menghubungkan tombol menu dengan panel konten yang bersangkutan menggunakan atribut `data-tab`:

```html
<!-- Tombol Menu Tab -->
<div class="ui top attached tabular menu" id="tabNavigasi">
  <a class="active item" data-tab="tab-ikhtisar">
    <i class="info circle icon"></i>
    Ikhtisar
  </a>
  <a class="item" data-tab="tab-spesifikasi">
    <i class="microchip icon"></i>
    Spesifikasi
  </a>
  <a class="item" data-tab="tab-ulasan">
    <i class="comments icon"></i>
    Ulasan Pembeli
  </a>
</div>

<!-- Isi Panel Tab -->
<div class="ui bottom attached active tab segment" data-tab="tab-ikhtisar">
  <p>Deskripsi umum produk dan cakupan fitur utama.</p>
</div>
<div class="ui bottom attached tab segment" data-tab="tab-spesifikasi">
  <p>Daftar rincian teknis prosesor, memori RAM, dan kapasitas penyimpanan.</p>
</div>
<div class="ui bottom attached tab segment" data-tab="tab-ulasan">
  <p>Daftar testimoni dan ulasan asli dari para pembeli terverifikasi.</p>
</div>
```

Inisialisasi JavaScript satu baris:
```javascript
$('#tabNavigasi .item').tab();
```

## 4. Penilaian Bintang dan Hati Interaktif (`ui rating`)

Komponen rating menyediakan antarmuka visual untuk memberi nilai:

```html
<!-- Rating Bintang Interaktif -->
<div class="ui star rating" id="ratingProduk" data-rating="4" data-max-rating="5"></div>

<!-- Rating Bentuk Hati Suka (Like) -->
<div class="ui heart rating" id="ratingFavorit" data-rating="1" data-max-rating="1"></div>
```

Konfigurasi JavaScript dengan Callback Peristiwa:
```javascript
$('#ratingProduk').rating({
  interactive: true,
  onRate: function(nilaiBaru) {
    console.log('Pengguna memberikan penilaian: ' + nilaiBaru + ' bintang.');
  }
});
```
