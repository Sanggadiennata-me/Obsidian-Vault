#programming 

Semantic UI dan edisi modernnya Fomantic-UI dapat dipasang melalui jaringan pengiriman konten (CDN) untuk kebutuhan belajar cepat, maupun melalui manajer paket npm untuk proyek berskala produksi.

## 1. Pemasangan Instan Melalui CDN

Pustaka Semantic UI terdiri dari dua berkas inti: berkas stylesheet CSS dan berkas JavaScript interaktif. Karena modul interaktifnya memanfaatkan jQuery, pustaka jQuery harus dimuat terlebih dahulu sebelum berkas JavaScript Semantic UI.

### Template HTML5 Standar

Simpan kode boilerplate berikut sebagai berkas `index.html`:

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Memulai Semantic UI</title>

  <!-- Berkas CSS Fomantic-UI (Semantic UI Modern) -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/fomantic-ui@2.9.3/dist/semantic.min.css">
</head>
<body>

  <div class="ui container" style="margin-top: 40px;">
    <h1 class="ui header">
      <i class="gem outline icon text teal"></i>
      <div class="content">
        Halo Dunia Semantic UI!
        <div class="sub header">Merakit antarmuka web dengan sintaksis bahasa manusia.</div>
      </div>
    </h1>

    <div class="ui divider"></div>

    <button class="ui primary button" id="btnSapa">
      <i class="hand peace icon"></i>
      Klik Saya
    </button>
  </div>

  <!-- 1. jQuery Wajib Dimuat Terlebih Dahulu -->
  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

  <!-- 2. Berkas JavaScript Fomantic-UI -->
  <script src="https://cdn.jsdelivr.net/npm/fomantic-ui@2.9.3/dist/semantic.min.js"></script>

  <!-- 3. Skrip Inisialisasi Aplikasi Anda -->
  <script>
    $('#btnSapa').on('click', function() {
      alert('Selamat! Semantic UI telah berhasil terhubung dan siap digunakan.');
    });
  </script>
</body>
</html>
```

## 2. Pemasangan Melalui Node Package Manager (NPM)

Untuk proyek berbasis bundler modern (seperti Webpack, Vite, atau Laravel Vite), Anda dapat memasang paket distribusi terkompilasi melalui npm:

```bash
npm install fomantic-ui-css jquery
```

### Impor di Berkas JavaScript Utama

```javascript
// main.js
import 'fomantic-ui-css/semantic.min.css';
import $ from 'jquery';
import 'fomantic-ui-css/semantic.min.js';

// Pastikan jQuery dapat diakses secara global oleh modul Semantic UI
window.$ = window.jQuery = $;
```

## 3. Pemasangan Sumber Lengkap dengan Build Tool Gulp

Bagi proyek berskala besar yang ingin memanfaatkan sistem kompilasi tema LESS tingkat lanjut milik Semantic UI, instalasi menggunakan build tool Gulp resmi memungkinkan Anda mengompilasi hanya komponen tertentu dan menimpa variabel desain pada level kode sumber:

```bash
npm install -g gulp
npm install fomantic-ui --save
```

Saat proses instalasi berjalan, CLI interaktif Semantic UI akan menanyakan pengaturan folder `semantic/` dan berkas konfigurasi `theme.config`.
