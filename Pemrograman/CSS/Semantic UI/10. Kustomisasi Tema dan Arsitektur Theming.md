#programming 

Semantic UI memiliki salah satu sistem arsitektur tema (*theming system*) paling komprehensif dalam sejarah framework CSS. Sistem ini memisahkan struktur dasar komponen dari detail gaya visualnya, sehingga pengembang dapat mengubah identitas desain tanpa merusak tata letak kode HTML.

## 1. Arsitektur Pewarisan Tema 5 Tingkat

Semantic UI dirancang menggunakan LESS dengan sistem pewarisan bertingkat:

1. **Default Theme**: Nilai dasar bawaan framework yang menentukan struktur ukuran, posisi margin, dan perataan.
2. **Packaged Themes**: Tema siap pakai yang sudah disediakan oleh Semantic UI, seperti tema `github`, `material`, `amazon`, `flat`, atau `twitter`.
3. **Site-Wide Theme (`src/site/globals/`)**: Tempat Anda mendefinisikan warna merek utama perusahaan (`@primaryColor`), font tipografi global, dan skala radius sudut.
4. **Element Overrides (`src/site/elements/`)**: Penyesuaian khusus untuk komponen tertentu, misalnya berkas `button.variables` untuk mengubah bantalan tombol atau `card.overrides` untuk menambahkan efek bayangan kustom.
5. **Packaged Site**: Paket tema mandiri yang dapat didistribusikan antar proyek.

### Berkas Pengendali: `theme.config`

Berkas `theme.config` bertindak sebagai peta penentu tema untuk setiap komponen:

```less
/* theme.config */
@site        : 'my-custom-theme';
@reset       : 'default';

/* Elemen */
@button      : 'material'; // Tombol menggunakan gaya Material Design
@container   : 'default';
@header      : 'my-custom-theme';
@input       : 'default';
@segment     : 'github';   // Segmen menggunakan gaya kartu ala GitHub

/* Views */
@card        : 'material';
```

## 2. Kustomisasi Cepat Menggunakan Variabel CSS (Fomantic-UI)

Pada rilis Fomantic-UI modern, Anda tidak selalu harus mengompilasi berkas LESS melalui Gulp. Anda dapat menimpa warna primer dan token desain langsung di file CSS aplikasi menggunakan variabel CSS native:

```css
/* style.css */
:root {
  /* Mengubah warna primer Semantic UI menjadi Indigo modern */
  --primaryColor: #4f46e5;
  --primaryHoverColor: #4338ca;
  --primaryFocusColor: #3730a3;

  /* Menyesuaikan font bawaan */
  --pageFont: 'Plus Jakarta Sans', -apple-system, sans-serif;
  --borderRadius: 10px;
}
```

## 3. Integrasi dengan Ekosistem JavaScript Modern

Ketika menggunakan Semantic UI dalam ekosistem SPA modern seperti React atau Vue, terdapat pola integrasi yang direkomendasikan:

### A. Integrasi dengan React (Semantic UI React)
Proyek resmi `semantic-ui-react` menyediakan komponen React deklaratif murni yang **tidak membutuhkan dependensi jQuery**:

```jsx
import React from 'react';
import { Button, Card, Icon } from 'semantic-ui-react';

export default function ProductCard() {
  return (
    <Card>
      <Card.Content header="MacBook Pro" />
      <Card.Content description="Laptop kerja berdaya tahan baterai tinggi." />
      <Card.Content extra>
        <Button primary icon labelPosition="left">
          <Icon name="cart" />
          Beli Sekarang
        </Button>
      </Card.Content>
    </Card>
  );
}
```

### B. Integrasi dengan Alpine.js
Jika menggunakan berkas HTML statis dan ingin menghindari penulisan script jQuery berlebih, Alpine.js dapat mengendalikan status class Semantic UI:

```html
<div x-data="{ modalBuka: false }">
  <button class="ui primary button" @click="modalBuka = true">Buka Dialog</button>

  <div class="ui modal" :class="{ 'active': modalBuka }">
    <div class="header">Pemberitahuan</div>
    <div class="content">Operasi pembaruan berhasil diproses.</div>
    <div class="actions">
      <button class="ui positive button" @click="modalBuka = false">Selesai</button>
    </div>
  </div>
</div>
```
