# Praktek Mandiri Semantic UI

Folder ini berisi 2 proyek latihan mandiri untuk mempraktikkan konsep Semantic UI (Fomantic-UI) secara langsung. Seluruh proyek menggunakan distribusi resmi via CDN sehingga dapat dibuka langsung di peramban web tanpa proses instalasi atau bundling terpisah.

---

## 1. Praktek 01: Katalog Produk E-Commerce
- **Lokasi Berkas**: `01-ecommerce-product-catalog/index.html`
- **Konsep Kunci**:
  - `ui borderless inverted menu` dengan kolom input pencarian dan tombol keranjang berlabel lencana.
  - Sistem grid 16 kolom responsif (`ui stackable grid`): filter sisi kiri (`four wide column`) dan area katalog (`twelve wide column`).
  - Menu vertikal `ui vertical menu` dengan indikator jumlah item.
  - Kartu produk `ui three stackable cards` dengan label pita promosi (`ui ribbon label`), harga terformat, dan modul penilaian bintang `ui rating`.
  - Jendela pop-up `ui modal` untuk melihat detail spesifikasi produk.

## 2. Praktek 02: Portal Manajemen Admin
- **Lokasi Berkas**: `02-management-portal/index.html`
- **Konsep Kunci**:
  - Navigasi laci samping `ui sidebar vertical menu` yang dapat dibuka-tutup dengan efek animasi geser.
  - Baris metrik statistik `ui four statistics` untuk memantau performa dan omzet bisnis.
  - Tabel data terstruktur `ui celled striped table` dengan indikator progres CPU interaktif.
  - Formulir `ui form` dengan sistem validasi otomatis bawaan Semantic UI (`rules: [{ type: 'empty' }, { type: 'minLength' }]`).
  - Modal form interaktif untuk pendaftaran operator baru.

---

## Cara Menjalankan Proyek
1. Buka pengelola berkas (File Explorer).
2. Masuk ke direktori lab yang diinginkan.
3. Klik ganda pada berkas `index.html` atau buka menggunakan peramban web modern (Google Chrome, Mozilla Firefox, Microsoft Edge).
