#programming 

Kategori **Elements** dalam Semantic UI merupakan blok bangunan visual fundamental yang membentuk antarmuka pengguna. Memahami karakteristik elemen kunci seperti Button, Segment, Header, dan Icon adalah dasar perancangan antarmuka yang solid.

## 1. Tombol Aksi (`ui button`)

Tombol di Semantic UI memiliki variasi status visual dan interaktif yang sangat kaya.

```html
<button class="ui primary button">Simpan Perubahan</button>
<button class="ui secondary button">Batal</button>
<button class="ui positive button">Setujui</button>
<button class="ui negative button">Hapus Data</button>
```

### Varian Khusus Tombol
- **Tombol Berikon dan Label (`labeled icon button`)**:
  ```html
  <button class="ui left labeled icon primary button">
    <i class="download icon"></i>
    Unduh Berkas
  </button>
  ```
- **Tombol Beranimasi (`animated button`)**:
  Menampilkan teks berbeda saat kursor diarahkan ke tombol:
  ```html
  <div class="ui animated button" tabindex="0">
    <div class="visible content">Lanjutkan Pembayaran</div>
    <div class="hidden content">
      <i class="right arrow icon"></i>
    </div>
  </div>
  ```
- **Tombol Memuat Spinner (`loading button`)**:
  ```html
  <button class="ui blue loading button">Memproses</button>
  ```
- **Grup Tombol (`ui buttons`)**:
  ```html
  <div class="ui buttons">
    <button class="ui positive button">Satu</button>
    <div class="or" data-text="atau"></div>
    <button class="ui button">Dua</button>
  </div>
  ```

## 2. Kontainer Segmen (`ui segment`)

Class `ui segment` adalah kontainer panel berlatar belakang putih dengan garis batas halus untuk mengelompokkan konten terkait.

### Ragam Karakteristik Segmen
- **`raised segment`**: Memberikan bayangan elevasi yang lebih tebal di sisi bawah.
- **`stacked segment`**: Menampilkan efek visual tumpukan beberapa lembar kertas.
- **`piled segment`**: Menampilkan efek lembaran kertas acak di bagian tepinya.
- **`placeholder segment`**: Segmen khusus untuk area kosong (empty state), misalnya sebelum ada data yang diunggah.

```html
<div class="ui placeholder segment">
  <div class="ui icon header">
    <i class="file pdf outline icon"></i>
    Belum Ada Berkas Laporan yang Diunggah
  </div>
  <div class="ui primary button">Unggah Berkas Baru</div>
</div>
```

- **`clearing segment`**: Otomatis membersihkan elemen yang melayang (`floated elements`) di dalamnya tanpa perlu clearfix manual:
  ```html
  <div class="ui clearing segment">
    <h3 class="ui left floated header">Daftar Transaksi</h3>
    <button class="ui right floated primary button">Ekspor CSV</button>
  </div>
  ```

## 3. Tipografi Judul (`ui header`)

Komponen header di Semantic UI dirancang dengan hierarki visual terpadu:

```html
<h2 class="ui header">
  <i class="settings icon"></i>
  <div class="content">
    Pengaturan Akun Pengguna
    <div class="sub header">Kelola profil, kata sandi, dan preferensi notifikasi Anda.</div>
  </div>
</h2>
```

Jika diletakkan pada tag biasa, Anda dapat menggunakan modifier ukuran: `ui huge header`, `ui large header`, `ui medium header`, `ui small header`, atau `ui tiny header`.

## 4. Ikon Grafis (`ui icon`)

Semantic UI menyertakan seluruh pustaka ikon Font Awesome yang terintegrasi secara native ke dalam class `icon`:

```html
<i class="envelope icon"></i>
<i class="large shield alternate icon text green"></i>
<i class="circular inverted blue phone icon"></i>
<i class="spinner loading icon"></i>
```

Modifier ikon yang sering digunakan:
- `loading`: Menambahkan animasi putaran kontinu otomatis (cocok untuk status tunggu).
- `circular`: Membungkus ikon di dalam lingkaran berwarna.
- `bordered`: Memberikan garis tepi persegi di sekeliling ikon.
- `link`: Mengubah kursor menjadi bentuk tangan klik interaktif.
