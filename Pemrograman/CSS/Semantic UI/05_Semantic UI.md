#roadmap 

### Bagian 1: Fundamental & Sistem Grid
1. [01. Pengenalan Semantic UI](01.%20Pengenalan%20Semantic%20UI.md) : Filosofi Human-First Syntax, 5 kategori definisi UI, serta kesinambungan Semantic UI dan Fomantic-UI.
2. [02. Instalasi dan Setup](02.%20Instalasi%20dan%20Setup.md) : Integrasi Fomantic-UI via CDN jsDelivr, dependensi jQuery, dan instalasi via NPM / Gulp build tool.
3. [03. Sistem Grid 16 Kolom](03.%20Sistem%20Grid%2016%20Kolom.md) : Arsitektur 16 kolom, penentuan lebar berbasis kata (`sixteen wide`, `eight wide`, `four wide`), responsivitas `stackable`, dan perataan `centered grid`.

### Bagian 2: Elemen, Koleksi, & Formulir
4. [04. Elemen Antarmuka Esensial (Button, Header, Segment, dan Icon)](04.%20Elemen%20Antarmuka%20Esensial%20(Button,%20Header,%20Segment,%20dan%20Icon).md) : Ragam tombol interaktif (`labeled icon`, `animated`), kontainer serbaguna `ui segment`, tipografi header, dan integrasi ikon.
5. [05. Koleksi Tata Letak (Menu, Message, dan Table)](05.%20Koleksi%20Tata%20Letak%20(Menu,%20Message,%20dan%20Table).md) : Bilah navigasi `ui menu`, kotak informasi alert `ui message`, dan tabel data terstruktur `ui table`.
6. [06. Formulir dan Validasi Otomatis](06.%20Formulir%20dan%20Validasi%20Otomatis.md) : Hierarki `ui form`, field grouping, input bergandeng, serta modul validasi JavaScript otomatis bawaan framework.

### Bagian 3: Views, Modul Interaktif, & Kustomisasi
7. [07. Tampilan Informasi Kompleks (Card, Feed, dan Statistic)](07.%20Tampilan%20Informasi%20Kompleks%20(Card,%20Feed,%20dan%20Statistic).md) : Kartu informasi `ui card` / `ui cards`, ringkasan metrik angka `ui statistic`, dan linimasa interaksi `ui feed`.
8. [08. Modul Interaktif JavaScript (Modal, Dropdown, dan Accordion)](08.%20Modul%20Interaktif%20JavaScript%20(Modal,%20Dropdown,%20dan%20Accordion).md) : Jendela dialog `ui modal`, menu dropdown dengan filter pencarian instan, dan panel lipat tanya-jawab `ui accordion`.
9. [09. Komponen Interaktif Dinamis (Sidebar, Dimmer, Tab, dan Rating)](09.%20Komponen%20Interaktif%20Dinamis%20(Sidebar,%20Dimmer,%20Tab,%20dan%20Rating).md) : Panel laci geser `ui sidebar`, lapisan sorotan gelap `ui dimmer`, navigasi `ui tab`, dan bintang interaktif `ui rating`.
10. [10. Kustomisasi Tema dan Arsitektur Theming](10.%20Kustomisasi%20Tema%20dan%20Arsitektur%20Theming.md) : Sistem hierarki theming bertingkat (`theme.config`, folder `site/`), override variabel desain, dan integrasi dengan framework modern (React / Vue).

---

### Bagian 4: Proyek Praktikum Mandiri (Hands-on Labs)
Seluruh proyek dapat langsung dibuka di browser tanpa perlu proses kompilasi tambahan:

1. [Praktek 01: Katalog Produk E-Commerce](praktek/01-ecommerce-product-catalog/index.html) : Halaman toko online lengkap dengan filter sidebar menu, 16-kolom grid produk, rating bintang, label pita promosi, dan modal dialog spesifikasi.
2. [Praktek 02: Portal Manajemen Admin](praktek/02-management-portal/index.html) : Panel dashboard admin dengan navigasi laci sidebar animasi geser, metrik statistik KPI, tabel data infrastruktur, dan formulir dengan validasi otomatis.
