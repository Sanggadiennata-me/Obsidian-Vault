#programming 

Formulir di Semantic UI dirancang dengan hierarki visual yang jelas dan terintegrasi dengan modul validasi JavaScript otomatis bawaan framework tanpa memerlukan library pihak ketiga.

## 1. Anatomi Dasar Formulir (`ui form`)

Struktur dasar satu formulir dibungkus di dalam tag `<form class="ui form">`:

```html
<form class="ui form">
  <div class="field">
    <label>Nama Pengguna</label>
    <input type="text" name="username" placeholder="Masukkan nama pengguna">
  </div>

  <div class="field">
    <label>Kata Sandi</label>
    <input type="password" name="password" placeholder="Minimal 8 karakter">
  </div>

  <button class="ui primary button" type="submit">Daftar Akun</button>
</form>
```

## 2. Pengelompokan Kolom Input (`fields`)

Untuk menempatkan beberapa kolom input dalam satu baris horizontal:

### A. Pembagian Berdasarkan Kata Jumlah (`two fields`, `three fields`)
```html
<div class="two fields">
  <div class="field">
    <label>Nama Depan</label>
    <input type="text" placeholder="Contoh: Aryanda">
  </div>
  <div class="field">
    <label>Nama Belakang</label>
    <input type="text" placeholder="Contoh: Pratama">
  </div>
</div>
```

### B. Pembagian Kolom Bebas Rata (`equal width fields`)
```html
<div class="equal width fields">
  <div class="field">
    <label>Kota</label>
    <input type="text">
  </div>
  <div class="field">
    <label>Provinsi</label>
    <input type="text">
  </div>
  <div class="field">
    <label>Kode Pos</label>
    <input type="text">
  </div>
</div>
```

## 3. Variasi Input: Ikon, Label, dan Tombol Gandeng

- **Input dengan Ikon (`icon input`)**:
  ```html
  <div class="ui left icon input">
    <i class="envelope icon"></i>
    <input type="email" placeholder="nama@domain.com">
  </div>
  ```
- **Input dengan Label Prefix (`labeled input`)**:
  ```html
  <div class="ui right labeled input">
    <label class="ui label">https://</label>
    <input type="text" placeholder="nama-situs">
    <div class="ui basic label">.id</div>
  </div>
  ```
- **Input dengan Tombol Aksi Bersambung (`action input`)**:
  ```html
  <div class="ui action input">
    <input type="text" placeholder="Masukkan kode kupon...">
    <button class="ui teal button">Klaim</button>
  </div>
  ```

## 4. Modul Validasi Formulir Otomatis Bawaan

Salah satu fitur paling unggul dari Semantic UI adalah modul validasi formulir terpadu. Anda cukup mendeklarasikan aturan validasi dalam bentuk objek JavaScript:

### Markup HTML Form dengan Wadah Error
```html
<form class="ui form" id="formRegistrasi">
  <div class="field">
    <label>Nama Lengkap</label>
    <input type="text" name="nama">
  </div>

  <div class="field">
    <label>Alamat Surel</label>
    <input type="email" name="email">
  </div>

  <div class="field">
    <label>Kata Sandi</label>
    <input type="password" name="password">
  </div>

  <div class="field">
    <div class="ui checkbox">
      <input type="checkbox" name="syarat">
      <label>Saya menyetujui syarat & ketentuan layanan.</label>
    </div>
  </div>

  <!-- Wadah Pesan Kesalahan Otomatis -->
  <div class="ui error message"></div>

  <button class="ui primary button" type="submit">Daftarkan Sekarang</button>
</form>
```

### Konfigurasi JavaScript Validasi
```javascript
$('#formRegistrasi').form({
  on: 'blur', // Validasi saat pengguna berpindah input (blur) atau submit
  fields: {
    nama: {
      identifier: 'nama',
      rules: [
        {
          type: 'empty',
          prompt: 'Nama lengkap wajib diisi.'
        }
      ]
    },
    email: {
      identifier: 'email',
      rules: [
        {
          type: 'email',
          prompt: 'Alamat surel tidak valid.'
        }
      ]
    },
    password: {
      identifier: 'password',
      rules: [
        {
          type: 'minLength[8]',
          prompt: 'Kata sandi minimal berisi 8 karakter.'
        }
      ]
    },
    syarat: {
      identifier: 'syarat',
      rules: [
        {
          type: 'checked',
          prompt: 'Anda harus menyetujui syarat dan ketentuan sebelum melanjutkan.'
        }
      ]
    }
  },
  onSuccess: function(event) {
    event.preventDefault();
    alert('Seluruh data formulir valid! Siap dikirim ke server.');
  }
});
```

Ketika ada kolom yang tidak memenuhi aturan, Semantic UI akan otomatis:
1. Menambahkan class `error` pada elemen `.field` yang bermasalah (memberikan warna merah pada garis batas dan label).
2. Menampilkan daftar pesan kesalahan di dalam elemen `<div class="ui error message"></div>`.
