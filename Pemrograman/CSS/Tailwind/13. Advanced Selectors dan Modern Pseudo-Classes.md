#programming 

Di tingkat mahir, Tailwind tidak hanya menata elemen secara langsung, tetapi juga mendukung selector CSS modern paling kuat seperti selector induk `:has()`, penargetan elemen anak bebas (*arbitrary child*), serta varian aksesibilitas berbasis atribut data dan ARIA.

---

## 1. Selector Induk Modern: `:has()` dengan Varian `has-[...]`

Selector `:has()` sering disebut sebagai *the parent selector* di CSS. Fitur ini memungkinkan Anda mengubah gaya suatu elemen induk berdasarkan kondisi elemen anak yang ada di dalamnya tanpa bantuan kode JavaScript.

### Contoh 1: Radio Card yang Menyala Saat Terpilih
```html
<label class="p-4 border-2 rounded-xl flex items-center justify-between cursor-pointer transition has-[:checked]:border-blue-600 has-[:checked]:bg-blue-50/50 has-[:checked]:shadow-sm">
  <div>
    <div class="font-bold text-slate-900">Metode Transfer Bank</div>
    <div class="text-xs text-slate-500">Konfirmasi otomatis 24 jam</div>
  </div>
  <input type="radio" name="payment" class="accent-blue-600">
</label>
```
Saat tag `<input>` radio di dalam label berubah menjadi `:checked`, maka tag `<label>` induknya otomatis berganti warna border dan background.

### Contoh 2: Menyorot Form yang Memiliki Input Invalid
```html
<div class="p-4 border rounded-lg has-[input:invalid]:border-rose-500 has-[input:invalid]:bg-rose-50/20">
  <input type="email" required placeholder="Masukkan email valid">
</div>
```

## 2. Penargetan Elemen Anak Bebas (*Arbitrary Child Variants*)

Terkadang Anda ingin memberikan gaya seragam kepada seluruh anak elemen di dalam container tanpa harus mengetik class pada masing-masing tag anak (misalnya pada tabel data atau list menu). Gunakan kurung siku dengan simbol ampersand `[&...]`:

```html
<!-- Memberi padding dan garis pemisah pada setiap <th> langsung -->
<thead class="bg-slate-100 text-xs font-semibold [&>tr>th]:py-3 [&>tr>th]:px-4">
  <tr>
    <th>Nama</th>
    <th>Email</th>
    <th>Peran</th>
  </tr>
</thead>

<!-- Memberi jarak bawah pada setiap paragraf di dalam artikel -->
<div class="[&>p]:mb-4 [&>p]:leading-relaxed text-slate-700">
  <p>Paragraf pertama otomatis memiliki margin bawah.</p>
  <p>Paragraf kedua juga rapi tanpa class berulang.</p>
</div>
```

## 3. Integrasi Komponen Headless: Atribut `data-*` dan `aria-*`

Di ekosistem modern (seperti Shadcn UI, Radix UI, atau Headless UI), status terbuka/tertutup komponen disimpan dalam atribut data atau ARIA:

### A. Varian Data Attribute (`data-[...]:`)
```html
<!-- Tab navigasi yang menyala saat atribut data-state='active' -->
<button class="px-4 py-2 border-b-2 border-transparent text-slate-500 data-[state=active]:border-blue-600 data-[state=active]:text-blue-600 font-semibold" data-state="active">
  Ringkasan
</button>
```

### B. Varian ARIA Aksesibilitas (`aria-...:`)
```html
<!-- Ikon panah accordion yang berputar 180 derajat saat terbuka -->
<button aria-expanded="true" class="flex items-center justify-between w-full">
  <span>Pertanyaan Umum</span>
  <span class="transform transition aria-expanded:rotate-180">▼</span>
</button>
```

## 4. Pseudo-Elements Cepat

Tailwind mendukung pseudo-elements langsung dari inline markup:

* **`selection:`** : Mengubah warna highlight teks saat pengguna memblok teks dengan kursor mouse (`selection:bg-blue-600 selection:text-white`).
* **`placeholder:`** : Mengatur warna teks bantuan pada input (`placeholder:text-slate-400 placeholder:italic`).
* **`file:`** : Mengatur tampilan tombol unggah berkas kustom pada `<input type="file">`:

```html
<input type="file" class="block w-full text-sm text-slate-500 file:mr-4 file:py-2 file:px-4 file:rounded-full file:border-0 file:text-xs file:font-semibold file:bg-blue-50 file:text-blue-700 hover:file:bg-blue-100">
```
* **`before:` dan `after:`** : Menambahkan konten dekorasi tanpa elemen HTML tambahan (`before:content-['*'] before:text-rose-500 before:mr-1`).
