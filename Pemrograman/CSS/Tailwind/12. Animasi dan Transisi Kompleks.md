#programming 

Tailwind CSS menyediakan utilitas lengkap untuk transisi halus dan animasi keyframe interaktif yang memberikan umpan balik visual (*micro-interaction*) kepada pengguna tanpa membebani kinerja rendering browser.

---

## 1. Animasi Bawaan Tailwind (*Core Keyframe Animations*)

Tailwind memiliki empat class animasi siap pakai yang paling sering dibutuhkan di aplikasi web:

### A. Indikator Loading Putar (`animate-spin`)
Sangat umum digunakan pada ikon putar di dalam tombol saat proses penyimpanan data atau pemuatan halaman sedang berlangsung.

```html
<button class="inline-flex items-center gap-2 px-4 py-2 bg-blue-600 text-white rounded-lg font-semibold disabled:opacity-50" disabled>
  <svg class="animate-spin h-4 w-4 text-white" xmlns="http://www.w3.org/2000/svg" fill="none" viewBox="0 0 24 24">
    <circle class="opacity-25" cx="12" cy="12" r="10" stroke="currentColor" stroke-width="4"></circle>
    <path class="opacity-75" fill="currentColor" d="M4 12a8 8 0 018-8V0C5.373 0 0 5.373 0 12h4zm2 5.291A7.962 7.962 0 014 12H0c0 3.042 1.135 5.824 3 7.938l3-2.647z"></path>
  </svg>
  <span>Sedang Memproses...</span>
</button>
```

### B. Kerangka Pemuat (*Skeleton Loading*) dengan `animate-pulse`
Membuat elemen berkedip memudar dan menguat secara halus. Pola ini jauh lebih disukai daripada spinner membosankan saat menunggu data dari API:

```html
<div class="p-4 max-w-sm bg-white rounded-xl border space-y-3 animate-pulse">
  <div class="h-40 bg-slate-200 rounded-lg"></div>
  <div class="h-4 bg-slate-200 rounded w-3/4"></div>
  <div class="h-4 bg-slate-200 rounded w-1/2"></div>
</div>
```

### C. Efek Radar Notifikasi (`animate-ping`)
Membuat lingkaran membesar dan memudar ke luar seperti sinyal radar mercusuar. Sangat ideal untuk lencana status aktif atau lonceng notifikasi:

```html
<span class="relative flex h-3 w-3">
  <span class="animate-ping absolute inline-flex h-full w-full rounded-full bg-emerald-400 opacity-75"></span>
  <span class="relative inline-flex rounded-full h-3 w-3 bg-emerald-500"></span>
</span>
```

### D. Indikator Melompat (`animate-bounce`)
Membuat elemen melompat naik-turun berulang kali, cocok untuk panah petunjuk scroll atau ikon perhatian penting:

```html
<div class="animate-bounce p-2 bg-white rounded-full shadow-lg w-fit">
  ↓ Scroll ke Bawah
</div>
```

## 2. Mengatur Kurva dan Jeda Transisi (*Timing & Delay*)

Untuk transisi properti biasa (seperti warna atau ukuran saat di-hover), Tailwind menyediakan kontrol waktu yang presisi:

* **Durasi Waktu (`duration-{ms}`)**: `duration-75`, `duration-150`, `duration-300`, `duration-500`, `duration-1000`.
* **Kurva Kehalusan (*Easing Curve*)**:
  * `ease-linear` : Kecepatan konstan tanpa percepatan.
  * `ease-in` : Mulai lambat lalu melesat cepat.
  * `ease-out` : Mulai cepat lalu melambat anggun di akhir (paling alami untuk interaksi UI).
  * `ease-in-out` : Lambat di awal, cepat di tengah, lambat di akhir.
* **Jeda Bertingkat (`delay-{ms}`)**: `delay-100`, `delay-200`, `delay-500`.

```html
<!-- Kartu dengan Transisi Halus Kurva Alami -->
<div class="transition-all duration-300 ease-out hover:scale-105 hover:shadow-xl">
  Kartu Dinamis
</div>
```

## 3. Menambahkan Animasi Kustom di Konfigurasi

Jika Anda membutuhkan animasi yang unik (misalnya goyangan bel atau gelombang lembut), daftarkan keyframe di `tailwind.config.js`:

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      keyframes: {
        wiggle: {
          '0%, 100%': { transform: 'rotate(-3deg)' },
          '50%': { transform: 'rotate(3deg)' },
        }
      },
      animation: {
        'wiggle': 'wiggle 0.3s ease-in-out infinite',
      }
    }
  }
}
```
Setelah didaftarkan, panggil class langsung di HTML menggunakan `animate-wiggle`.
