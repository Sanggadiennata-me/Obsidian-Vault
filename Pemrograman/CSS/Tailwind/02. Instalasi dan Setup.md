#programming 

Ada beberapa metode untuk mengintegrasikan Tailwind CSS ke dalam proyek Anda, mulai dari cara paling instan untuk belajar (Play CDN) hingga alur kerja profesional menggunakan Tailwind CLI atau bundler modern.

---

## 1. Metode Cepat: Tailwind Play CDN (Khusus Latihan & Prototipe)

Jika Anda ingin langsung mencoba tanpa instalasi Node.js atau pengaturan rumit, cukup pasang tautan script CDN berikut di dalam tag `<head>` berkas HTML Anda:

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Latihan Tailwind</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-slate-100 flex items-center justify-center min-h-screen">
  <div class="p-6 max-w-sm bg-white rounded-xl shadow-lg border border-slate-200">
    <h1 class="text-xl font-bold text-slate-900">Halo Tailwind!</h1>
    <p class="text-slate-500 text-sm mt-2">Berhasil berjalan via Play CDN.</p>
  </div>
</body>
</html>
```

> **Catatan Produksi**: Play CDN tidak disarankan untuk aplikasi produksi skala besar karena seluruh parser dijalankan di browser pengguna dan menghasilkan ukuran unduhan awal yang lebih besar.

## 2. Metode Standar: Menggunakan Tailwind CLI

Ini adalah metode resmi dan paling bersih jika Anda membangun website statis (HTML biasa) dengan performa maksimal.

### Langkah 1: Inisialisasi Proyek Node.js
Buka terminal pada folder proyek Anda dan jalankan:

```bash
npm init -y
npm install -D tailwindcss
npx tailwindcss init
```
Perintah di atas akan menghasilkan berkas konfigurasi baru bernama `tailwind.config.js`.

### Langkah 2: Konfigurasi Path Berkas Template
Buka berkas `tailwind.config.js` dan tentukan lokasi berkas HTML tempat Anda menggunakan class Tailwind:

```js
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: ["./src/**/*.{html,js}", "./*.html"],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

### Langkah 3: Buat Berkas CSS Utama
Buat berkas CSS input, misalnya di `src/input.css`, lalu tambahkan tiga baris direktif wajib Tailwind:

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

### Langkah 4: Jalankan Kompilasi Tailwind
Jalankan perintah build untuk memantau perubahan berkas dan mengompilasi CSS hasil akhir:

```bash
npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch
```

### Langkah 5: Hubungkan ke Dokumen HTML
Tautkan berkas `./dist/output.css` di berkas HTML Anda:

```html
<link rel="stylesheet" href="./dist/output.css">
```

## 3. Integrasi dengan Framework Modern (Vite / Next.js)

Pada ekosistem modern seperti React, Vue, atau Svelte, Tailwind dipasang sebagai plugin PostCSS melalui Vite:

```bash
npm create vite@latest my-project -- --template react
cd my-project
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

Untuk pengalaman terbaik saat mengetik class Tailwind, pasang ekstensi resmi di VS Code:
* **Tailwind CSS IntelliSense**: Memberikan saran otomatis (*autocomplete*), pratinjau kode CSS asli saat kursor diarahkan ke class, serta penanda kesalahan pengetikan syntax.
