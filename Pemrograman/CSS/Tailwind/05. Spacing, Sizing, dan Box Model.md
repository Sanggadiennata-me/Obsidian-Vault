#programming 

Pengaturan jarak (*spacing*), dimensi ukuran (*sizing*), dan kotak elemen (*box model*) merupakan aktivitas yang paling sering dilakukan saat merakit antarmuka web. Tailwind menyederhanakan seluruh aturan ini ke dalam class singkat yang teratur.

---

## 1. Jarak Dalam (Padding) dan Jarak Luar (Margin)

### A. Padding (`p-`)
Padding memberikan ruang kosong di antara konten dan batas tepi (*border*):

* `p-4` : Padding di keempat sisi (atas, kanan, bawah, kiri) sebesar 1rem (16px).
* `px-6` : Padding horizontal (kiri dan kanan) sebesar 1.5rem (24px).
* `py-3` : Padding vertikal (atas dan bawah) sebesar 0.75rem (12px).
* `pt-8`, `pr-4`, `pb-2`, `pl-6` : Padding spesifik satu arah (Top, Right, Bottom, Left).

### B. Margin (`m-`)
Margin memberikan jarak antara kotak elemen dengan elemen lain di luarnya:

* `m-4` : Margin di keempat sisi.
* `mx-auto` : Mengatur margin kiri dan kanan menjadi `auto`. Ini adalah teknik paling umum untuk menengahkan container di layar secara horizontal.
* `my-6` : Margin vertikal atas dan bawah.
* `mb-8` : Margin bawah (sangat sering dipakai untuk memisahkan judul dengan paragraf di bawahnya).

### C. Margin Negatif (`-m-`)
Tambahkan tanda minus di depan nama class untuk menarik elemen mendekat atau menumpuk:

```html
<!-- Menarik elemen ke atas sejauh 16px -->
<div class="-mt-4">...</div>
```

## 2. Mengatur Dimensi Ukuran (Width & Height)

### A. Lebar (`w-`)
* **Ukuran Tetap**: `w-16` (64px), `w-48` (192px), `w-64` (256px), `w-80` (320px).
* **Pecahan Relatif**: `w-1/2` (50%), `w-1/3` (33.3%), `w-2/3` (66.6%), `w-1/4` (25%).
* **Kata Kunci Khusus**:
  * `w-full` : Lebar 100% memenuhi parent container.
  * `w-screen` : Lebar 100vw selebar jendela browser.
  * `w-fit` : Lebar hanya sebesar konten teks di dalamnya (`width: fit-content`).
  * `max-w-md` (28rem), `max-w-xl` (36rem), `max-w-6xl` (72rem) : Membatasi lebar maksimum agar teks tidak terlalu melar di layar desktop.

### B. Tinggi (`h-`)
* `h-10` (40px) : Standar tinggi tombol atau kotak input.
* `h-full` : Tinggi 100% dari parent.
* `h-screen` : Tinggi 100vh memenuhi tinggi layar jendela browser.
* `min-h-screen` : Menjamin halaman web memiliki tinggi minimal 100vh tanpa memotong konten yang panjang.

```html
<div class="max-w-4xl mx-auto px-4 py-8">
  <div class="w-full h-48 bg-slate-200 rounded-xl"></div>
</div>
```

## 3. Garis Tepi (Border) dan Sudut Melengkung (Rounded)

### A. Border
* `border` : Memberikan garis tepi tipis 1px.
* `border-2`, `border-4` : Menentukan ketebalan garis (2px, 4px).
* `border-slate-200` : Menentukan warna garis tepi.
* `border-dashed`, `border-dotted` : Mengubah gaya garis menjadi putus-putus atau titik.

### B. Border Radius (`rounded-`)
* `rounded-sm` : 2px lengkungan kecil.
* `rounded-md` : 6px lengkungan kartu standar.
* `rounded-xl` : 12px lengkungan modern yang elegan.
* `rounded-2xl` : 16px lengkungan besar untuk modal dialog atau kartu utama.
* `rounded-full` : Lengkungan bulat penuh (lingkaran pada avatar atau bentuk kapsul pada tombol).

---

## 4. Efek Bayangan (Box Shadow)

Tailwind menyediakan skala bayangan bertingkat yang telah dihitung elevasi optiknya:

* `shadow-sm` : Bayangan tipis untuk tombol atau kotak input kecil.
* `shadow` : Bayangan dasar untuk kartu konten biasa.
* `shadow-md` : Bayangan menengah untuk elemen interaktif saat melayang.
* `shadow-lg` : Bayangan dalam untuk pop-up dropdown menu.
* `shadow-xl` : Bayangan tebal untuk modal dialog penting.
* `shadow-none` : Menghapus efek bayangan.

```html
<!-- Kartu Modern dengan Kombinasi Box Model Lengkap -->
<div class="max-w-sm p-6 bg-white border border-slate-200 rounded-2xl shadow-md hover:shadow-xl transition">
  <h3 class="font-bold text-lg text-slate-900">Kartu Layanan</h3>
  <p class="text-sm text-slate-600 mt-2">Seluruh jarak dan batas tertata rapi.</p>
</div>
```
