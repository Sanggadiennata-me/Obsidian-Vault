#programming 

Berkas `tailwind.config.js` adalah pusat kendali untuk menyesuaikan sistem desain proyek Anda. Di berkas ini Anda dapat memperluas palet warna perusahaan, menentukan font khusus, mengubah ukuran breakpoint, hingga memasang plugin resmi.

---

## 1. Struktur Standar Berkas Konfigurasi

```js
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    "./src/**/*.{html,js,jsx,ts,tsx,vue}",
    "./index.html"
  ],
  darkMode: 'class',
  theme: {
    extend: {
      // Seluruh kustomisasi tambahan diletakkan di sini
    },
  },
  plugins: [],
}
```

> **Aturan Emas: Gunakan Objek `extend`**:
> Selalu letakkan penambahan kustom di dalam properti `theme.extend`. Jika Anda meletakkannya langsung di dalam `theme` tanpa `extend`, Tailwind akan **menghapus seluruh palet warna bawaan** dan hanya menyisakan warna yang Anda tulis sendiri.

---

## 2. Kustomisasi Palet Warna Merek (*Custom Brand Colors*)

Anda dapat mendaftarkan warna identitas perusahaan agar bisa dipanggil menggunakan sintaks standar seperti `bg-brand-primary` atau `text-brand-dark`:

```js
module.exports = {
  theme: {
    extend: {
      colors: {
        brand: {
          light: '#eff6ff',
          primary: '#2563eb',
          dark: '#1e40af',
          accent: '#f59e0b',
        },
      },
    },
  },
}
```
Setelah disimpan, Anda dapat langsung menggunakannya di HTML:
```html
<button class="bg-brand-primary hover:bg-brand-dark text-white px-4 py-2 rounded-lg">
  Tombol Brand
</button>
```

## 3. Menambahkan Font Kustom (*Google Fonts / Web Fonts*)

Hubungkan font Google (misalnya font *Plus Jakarta Sans*) di HTML `<head>`, lalu daftarkan font tersebut di konfigurasi:

```js
module.exports = {
  theme: {
    extend: {
      fontFamily: {
        sans: ['"Plus Jakarta Sans"', 'sans-serif'],
        code: ['"Fira Code"', 'monospace'],
      },
    },
  },
}
```
Sekarang, seluruh class `font-sans` di aplikasi Anda otomatis menggunakan font Plus Jakarta Sans.

## 4. Menambahkan Animasi Kustom

Tailwind memudahkan pembuatan animasi keyframes langsung dari berkas config:

```js
module.exports = {
  theme: {
    extend: {
      keyframes: {
        float: {
          '0%, 100%': { transform: 'translateY(0px)' },
          '50%': { transform: 'translateY(-10px)' },
        }
      },
      animation: {
        'floating': 'float 3s ease-in-out infinite',
      }
    },
  },
}
```
Penggunaan di HTML:
```html
<div class="animate-floating w-16 h-16 bg-blue-500 rounded-full"></div>
```

## 5. Plugin Resmi Tailwind yang Wajib Diketahui

Tailwind menyediakan kumpulan plugin resmi dari tim inti untuk menyelesaikan kebutuhan umum:

1. **`@tailwindcss/typography` (`prose`)**:
   Otomatis memformat artikel blog bertag Markdown atau HTML mentah (paragraf, kutipan, heading, list) agar tampil rapi dan estetik hanya dengan menambahkan satu class `prose`.
2. **`@tailwindcss/forms`**:
   Mereset gaya input form, checkbox, dan radio button agar tampil modern dan mudah di-styling di semua browser.
3. **`@tailwindcss/aspect-ratio`**:
   Menjaga rasio video YouTube atau gambar produk (seperti 16:9 atau 4:3) agar tidak terdistorsi saat layar menyusut.

Pemasangan plugin di config:
```js
module.exports = {
  plugins: [
    require('@tailwindcss/typography'),
    require('@tailwindcss/forms'),
  ],
}
```
