#programming 

Tailwind CSS menyediakan sistem tipografi dan palet warna yang sangat kaya, terkalibrasi secara profesional untuk menjamin keterbacaan teks dan kontras visual yang harmonis.

---

## 1. Tipografi (Typography)

### A. Ukuran Teks (`text-{size}`)
Tailwind mengatur ukuran teks lengkap dengan *line-height* (tinggi baris) bawaan yang proporsional:

* `text-xs` : 0.75rem (12px) - Cocok untuk label badge kecil atau catatan kaki.
* `text-sm` : 0.875rem (14px) - Standar untuk teks sekunder, tabel, dan caption.
* `text-base` : 1rem (16px) - Ukuran teks paragraf default browser.
* `text-lg` : 1.125rem (18px) - Paragraf pembuka artikel (*lead text*).
* `text-xl` : 1.25rem (20px) - Judul kartu kecil (sub-heading).
* `text-2xl` : 1.5rem (24px) - Judul section (Heading 3).
* `text-3xl` : 1.875rem (30px) - Judul bab halaman (Heading 2).
* `text-4xl` s/d `text-6xl` : 2.25rem ke atas - Judul besar panggung utama (*Hero Title*).

### B. Ketebalan Font (`font-{weight}`)
* `font-light` : 300
* `font-normal` : 400 (standar)
* `font-medium` : 500
* `font-semibold` : 600 (sangat umum untuk tombol dan judul kartu)
* `font-bold` : 700 (standar heading)
* `font-extrabold` : 800

### C. Jarak Huruf dan Kerapatan Baris
* **Spasi Antar Huruf (*Letter Spacing*)**: `tracking-tighter`, `tracking-tight` (sangat bagus untuk judul besar), `tracking-normal`, `tracking-wide`, `tracking-widest`.
* **Tinggi Baris (*Line Height*)**: `leading-none`, `leading-tight`, `leading-normal`, `leading-relaxed` (ideal untuk kenyamanan membaca paragraf panjang).

```html
<h1 class="text-4xl font-extrabold tracking-tight text-slate-900">
  Membangun Antarmuka Modern
</h1>
<p class="text-base text-slate-600 leading-relaxed mt-3">
  Paragraf penjelas yang nyaman dibaca dengan jarak antar baris proporsional.
</p>
```

## 2. Palet Warna (Color Palette)

Palet warna Tailwind memiliki rentang spektrum angka dari **50 (paling terang/pucat)** hingga **950 (paling gelap/pekat)**:

* `50` - `100` : Background tipis, pill badge halus, hover lembut.
* `200` - `300` : Border kartu, garis pembatas tabel (*divider*).
* `400` - `500` : Ikon sekunder, teks penjelas pelengkap.
* `600` - `700` : Warna aksen utama tombol, teks penting, tautan aktif.
* `800` - `900` : Judul teks gelap di mode terang, background gelap di mode malam.
* `950` : Warna kontras maksimal (hitam kebiruan pekat).

Pilihan rumpun warna bawaan meliputi: `slate`, `gray`, `zinc`, `neutral`, `stone`, `red`, `orange`, `amber`, `yellow`, `lime`, `green`, `emerald`, `teal`, `cyan`, `sky`, `blue`, `indigo`, `violet`, `purple`, `fuchsia`, `pink`, dan `rose`.

## 3. Tingkat Transparansi Warna (*Color Opacity Modifier*)

Anda bisa menambahkan nilai transparansi pada warna apa pun secara instan menggunakan tanda garis miring `/`:

```html
<!-- Background biru dengan transparansi 20% -->
<div class="bg-blue-600/20 text-blue-700">Badge Halus</div>

<!-- Teks putih dengan transparansi 80% -->
<p class="text-white/80">Keterangan semi-transparan</p>

<!-- Garis tepi dengan transparansi 10% -->
<div class="border border-slate-900/10">Kotak Bersih</div>
```

## 4. Efek Teks Gradasi Modern (*Gradient Text*)

Kombinasi tiga class berikut menghasilkan teks bergradasi warna tajam yang sangat populer di landing page modern:

```html
<span class="bg-gradient-to-r from-blue-600 via-indigo-600 to-purple-600 bg-clip-text text-transparent font-extrabold text-5xl">
  Solusi Cloud Generasi Baru
</span>
```
Penjelasan:
1. `bg-gradient-to-r` : Membuat gradien latar belakang dari arah kiri ke kanan.
2. `from-... via-... to-...` : Menentukan titik warna awal, tengah, dan akhir gradasi.
3. `bg-clip-text` : Memotong latar belakang agar hanya mengikuti lekukan huruf teks.
4. `text-transparent` : Membuat warna asli teks transparan sehingga warna gradien di belakangnya terlihat.
