#programming 

Tailwind menggunakan sistem *variants* (awalan pengubah) untuk mengontrol tampilan elemen saat terjadi interaksi pengguna, seperti saat kursor melayang di atas tombol (*hover*), input formulir disentuh (*focus*), atau tombol ditekan (*active*).

---

## 1. State Dasar: Hover, Focus, dan Active

Cukup letakkan nama state diikuti tanda titik dua `:` di depan class utilitas yang ingin diubah:

```html
<button class="bg-blue-600 hover:bg-blue-700 active:bg-blue-800 focus:outline-none focus:ring-4 focus:ring-blue-300 text-white font-semibold px-5 py-2.5 rounded-lg transition">
  Tombol Interaktif
</button>
```

Penjelasan Perilaku:
1. `bg-blue-600` : Warna normal saat diam.
2. `hover:bg-blue-700` : Warna berubah lebih gelap saat kursor mouse menyentuhnya.
3. `active:bg-blue-800` : Warna semakin pekat saat tombol sedang ditekan klik kiri.
4. `focus:ring-4 focus:ring-blue-300` : Memunculkan lingkaran halo (*focus ring*) yang ramah aksesibilitas saat tombol dipilih menggunakan tombol Tab keyboard.
5. `transition` : Menganimasikan perpindahan warna secara halus (tidak mendadak kaku).

---

## 2. Pola Induk dan Anak: `group` dan `group-hover`

Sering kali Anda ingin mengubah gaya suatu elemen anak (misalnya warna ikon atau teks kecil) ketika **keseluruhan kartu induknya** di-hover oleh pengguna. Tailwind menyelesaikan ini dengan class `group`:

```html
<!-- Elemen Induk Diberi Tanda "group" -->
<div class="group p-6 bg-white border rounded-2xl shadow-sm hover:border-blue-500 hover:shadow-md transition cursor-pointer">
  <!-- Ikon Berubah Background Saat Induk Di-hover -->
  <div class="w-10 h-10 bg-slate-100 group-hover:bg-blue-600 rounded-lg flex items-center justify-center transition">
    <!-- SVG Ikon Berubah Warna Menjadi Putih -->
    <span class="text-slate-600 group-hover:text-white transition">★</span>
  </div>
  
  <h3 class="font-bold text-slate-900 group-hover:text-blue-600 mt-4 transition">
    Kartu Layanan Interaktif
  </h3>
  <p class="text-sm text-slate-500 mt-1">Arahkan kursor ke kartu ini untuk melihat efeknya.</p>
</div>
```

## 3. Pola Elemen Saudara: `peer` dan `peer-focus`

Class `peer` memungkinkan sebuah elemen berganti gaya berdasarkan kondisi elemen saudara kandungnya (*sibling*). Ini sangat populer untuk membuat label mengambang (*floating label*) atau checkbox kustom tanpa JavaScript sama sekali:

```html
<div class="relative">
  <input type="text" id="nama" placeholder=" " class="peer w-full px-4 py-3 border border-slate-300 rounded-lg focus:border-blue-600 focus:outline-none">
  
  <!-- Label ini otomatis naik ke atas saat input di-focus -->
  <label for="nama" class="absolute left-4 top-3 text-slate-400 text-sm transition-all pointer-events-none peer-focus:-top-2.5 peer-focus:text-xs peer-focus:text-blue-600 peer-focus:bg-white peer-focus:px-1">
    Nama Lengkap Anda
  </label>
</div>
```

## 4. Efek Transformasi Halus (*Micro-Interactions*)

Mengombinasikan state variant dengan properti transformasi akan membuat antarmuka terasa hidup dan responsif:

* `transition` : Mengaktifkan transisi standar berdurasi 150 milidetik.
* `duration-200`, `duration-300` : Mengatur durasi waktu animasi.
* `hover:-translate-y-1` : Mengangkat elemen ke atas sejauh 4px saat disentuh.
* `hover:scale-105` : Membesarkan ukuran elemen sebesar 5%.
* `active:scale-95` : Menciutkan sedikit tombol saat diklik (memberikan umpan balik fisik seperti tombol mekanik).

```html
<button class="bg-indigo-600 text-white px-6 py-2 rounded-xl transition transform hover:-translate-y-0.5 hover:shadow-lg active:scale-95">
  Simpan Perubahan
</button>
```
