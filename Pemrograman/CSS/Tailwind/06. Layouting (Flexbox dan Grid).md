#programming 

Tailwind menyediakan utilitas lengkap untuk dua model tata letak paling canggih di CSS modern: **Flexbox** (tata letak satu dimensi) dan **CSS Grid** (tata letak dua dimensi).

---

## 1. Tata Letak dengan Flexbox

Cukup pasang class `flex` pada elemen pembungkus untuk mengaktifkan flexbox.

### A. Arah dan Pembagian Jarak
```html
<!-- Baris Mendatar dengan Jarak Antara (Navbar Pattern) -->
<header class="flex justify-between items-center h-16 px-6 bg-white border-b">
  <div class="font-bold">Logo Perusahaan</div>
  <nav class="flex gap-4">
    <a href="#" class="text-sm text-slate-600">Fitur</a>
    <a href="#" class="text-sm text-slate-600">Harga</a>
  </nav>
</header>
```

### B. Daftar Class Utama Flex Container
* **Arah (*Direction*)**: `flex-row` (horizontal), `flex-col` (vertikal).
* **Sumbu Utama (*Justify Content*)**:
  * `justify-start` : Rapat ke kiri/awal.
  * `justify-center` : Berkumpul di tengah.
  * `justify-end` : Rapat ke kanan/akhir.
  * `justify-between` : Tersebar ke ujung kiri dan ujung kanan dengan jarak rata di tengah.
  * `justify-evenly` : Jarak antar elemen dan batas dinding persis sama.
* **Sumbu Silang (*Align Items*)**:
  * `items-center` : Tengah secara vertikal.
  * `items-start`, `items-end`, `items-stretch`.
* **Celah Antar Elemen (*Gap*)**: `gap-2` (8px), `gap-4` (16px), `gap-6` (24px).
* **Pembungkusan (*Wrap*)**: `flex-wrap` (pindah baris jika sempit), `flex-nowrap`.

### C. Mengatur Elemen Anak (*Flex Items*)
* `flex-1` : Mengembang mengisi seluruh sisa ruang kosong (`flex: 1 1 0%`).
* `flex-none` : Mencegah elemen membesar atau mengecil dari ukuran aslinya.
* `grow` / `grow-0` : Mengizinkan atau menolak pembesaran.

```html
<!-- Form Pencarian Fleksibel -->
<div class="flex gap-2">
  <input type="text" placeholder="Cari data..." class="flex-1 px-4 py-2 border rounded-lg">
  <button class="flex-none px-6 py-2 bg-blue-600 text-white rounded-lg">Cari</button>
</div>
```

## 2. Tata Letak dengan CSS Grid

CSS Grid sangat ideal saat Anda ingin membagi halaman menjadi sistem kolom dan baris yang kaku, seperti galeri gambar atau kartu analitik dashboard.

### A. Menentukan Jumlah Kolom (`grid-cols-{n}`)
Tailwind memiliki sistem pembagian 1 hingga 12 kolom:

```html
<!-- Grid 3 Kolom Rata dengan Jarak 24px -->
<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">
  <div class="p-6 bg-white rounded-xl shadow">Kartu 1</div>
  <div class="p-6 bg-white rounded-xl shadow">Kartu 2</div>
  <div class="p-6 bg-white rounded-xl shadow">Kartu 3</div>
</div>
```

### B. Mengatur Bentangan Kolom (*Column Span*)
Sebuah item dapat dibentangkan melintasi beberapa kolom sekaligus menggunakan `col-span-{n}`:

```html
<div class="grid grid-cols-12 gap-4">
  <!-- Sidebar menghabiskan 3 kolom dari 12 -->
  <aside class="col-span-12 md:col-span-3 bg-slate-100 p-4 rounded-lg">
    Menu Navigasi
  </aside>

  <!-- Konten utama menghabiskan 9 kolom sisanya -->
  <main class="col-span-12 md:col-span-9 bg-white p-6 rounded-lg">
    Artikel Utama
  </main>
</div>
```

## 3. Kapan Memilih Flexbox vs Grid?

| Kebutuhan Tata Letak | Solusi Rekomendasi | Alasan Teknis |
| :--- | :--- | :--- |
| Navbar, deretan tombol, badge dengan ikon | **Flexbox** | Alur satu dimensi yang membutuhkan perataan fleksibel berdasarkan isi teks. |
| Form pencarian (input melebar + tombol tetap) | **Flexbox (`flex-1`)** | Pembagian sisa ruang dinamis dalam satu baris. |
| Dashboard kartu, galeri foto, tabel perbandingan | **CSS Grid (`grid-cols-n`)** | Dua dimensi yang membutuhkan keseragaman ukuran kolom dan baris terstruktur. |
| Struktur tata letak halaman (Sidebar + Main + Footer) | **CSS Grid (`grid-cols-12`)** | Pembagian zona layout layar besar yang presisi. |
